How it works

Three steps, no friction.

Open a course

Every course is a single self-contained page. No install, no account, no waiting.

Read & interact

Scroll through lessons, run the labs, answer the knowledge checks as you go.

Track yourself

Progress is measured on the page itself — nothing is sent anywhere.

Questions

The short answers.

Do I need an account?

No. There is no login, no sign-up and no email. Open the page and start learning.

Is my progress saved?

Progress is tracked live on each course page while you read. Nothing is uploaded or stored on a server.

Does it work offline?

Yes. Each course is a single HTML file with no external dependencies, so it works without an internet connection.

Can I add my own course?

Yes — drop a self-contained HTML course file into this folder and link it from the courses grid above.
