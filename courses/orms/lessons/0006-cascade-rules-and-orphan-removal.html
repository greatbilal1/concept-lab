Cascade rules and orphan removal

What happens when you delete an order from memory? Master ORM cascade options (save-update, delete, all) and orphan removal without corrupting relationships.

Time ~10 min Win Configure ORM cascade options and orphan removal to manage dependent object lifecycles Mission link Prevents in-memory object graphs from drifting out of sync with database foreign keys

1Cascading operations through the object graph

In an object model, entities contain collections of other entities: an Order contains a list of LineItems. When you add a new LineItem to order.items, should you have to explicitly call session.add(line_item)?

ORM Cascades propagate operations from parents to children across the in-memory object graph. With cascade="all, delete-orphan", adding an item to the collection saves it automatically, and removing an item from the collection deletes it from the database!

Key idea ORM cascades propagate persist, merge, and delete operations across in-memory object relationships.
