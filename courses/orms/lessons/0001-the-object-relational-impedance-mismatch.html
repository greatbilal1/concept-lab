The Object-Relational Impedance Mismatch

Why is mapping objects to tables so painful? Discover the Object-Relational Impedance Mismatch: relational sets versus object graphs, pointers, and inheritance.

Time ~10 min Win Articulate the fundamental structural differences between relational sets and object graphs Mission link Explains why every ORM involves fundamental design trade-offs

1Two different mental models

Object-Oriented Programming (OOP) and Relational Databases (RDBMS) were designed for two completely different purposes based on different mathematical paradigms. This tension is known as the Object-Relational Impedance Mismatch.

Objects have identity and memory pointers; relational tables have keys and values. Objects use encapsulation and inheritance; relational databases use normalization and foreign keys. An ORM is a bridge over this chasm, but the bridge is never completely seamless.

Key idea OOP deals with bidirectional pointer graphs; relational databases deal with normalized sets and foreign keys.
