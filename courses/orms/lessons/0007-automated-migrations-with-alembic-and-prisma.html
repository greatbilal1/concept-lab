Lesson 07 · Migrations & Trade-offs

Automated migrations with Alembic and Prisma

Code is in models; schema is in SQL. Learn how tools like Alembic, Prisma Migrate, and Django Migrations autogenerate DDL scripts by diffing models against databases.

Time ~10 min Win Generate, review, and execute automated database migrations using ORM tooling Mission link Bridges Python/TypeScript model declarations and persistent SQL table schemas

1Autogenerating schema diffs

Writing manual ALTER TABLE scripts for every model change is tedious and error-prone. Modern ORM ecosystems provide migration tools (like Alembic in Python, Prisma Migrate in TypeScript, or Django Migrations).

These tools inspect your code models, inspect your live database catalog, calculate the mathematical schema diff, and autogenerate an incremental migration script. However: You must ALWAYS review autogenerated migrations before running them! Autogenerators can mistake a column rename for a DROP and ADD, destroying production data!

Key idea Migration tools generate schema diffs automatically, but developers must always review generated scripts.
