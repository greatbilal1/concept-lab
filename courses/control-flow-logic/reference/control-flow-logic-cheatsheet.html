Control Flow & Logic Cheat Sheet

The facts you will reach for every day, compressed. Print this, or keep it open beside your editor. Every snippet is runnable Python 3.

Truth Comparing Logic Short-circuit if / else elif chains while for break / continue Keeping it flat

1Truth

See Lesson 01 — Truth and falsity

Only a few values are falsy
bool(0)          # False
bool("")         # False
bool([])         # False
bool(None)       # False
bool("0")        # True  — non-empty string
bool([0])        # True  — non-empty list

2Comparing

See Lesson 02 — Comparing values

Six operators, and chaining
3 == 3      # True   equal
3 != 4      # True   not equal
3 < 4       # True   less than
3 >= 3      # True   greater or equal
0 <= 5 < 10 # True   chained comparison
1 == 1.0    # True   equal across types

3Logic

See Lesson 03 — Combining conditions

and, or, not
True and False   # False — both must be true
True or False    # True  — at least one true
not True         # False — flips the value

# De Morgan
not (a and b) == (not a or not b)
not (a or b)  == (not a and not b)

4Short-circuit

See Lesson 04 — Short-circuit evaluation

Python stops as soon as the answer is known
False and expensive()   # expensive() never runs
True or expensive()     # expensive() never runs

# the guard clause
if user and user.active:
    print("ok")         # safe: user checked first

5if / else

See Lesson 05 — Choosing a path

Indentation is the block
if temperature > 30:
    print("hot")
else:
    print("mild")

# one-line form, for very short branches
label = "hot" if temperature > 30 else "mild"

6elif chains

See Lesson 06 — Many branches

First match wins — order matters
if score >= 90:   grade = "A"
elif score >= 80: grade = "B"
elif score >= 70: grade = "C"
else:             grade = "F"

# exactly one branch runs; later tests are skipped

7while

See Lesson 07 — Repeating work

Repeat while a condition holds
count = 3
while count > 0:
    print(count)
    count = count - 1   # something must change

# checked before every pass → can run zero times

8for

See Lesson 08 — Looping over things

Walk any iterable
for fruit in ["apple", "pear"]:
    print(fruit)

for n in range(3):      # 0, 1, 2 — stop excluded
    print(n)

total = 0               # the accumulator pattern
for n in [4, 8, 15]:
    total = total + n

9break / continue

See Lesson 09 — Leaving a loop early

Steering a loop from the inside
for n in [3, 7, 12]:
    if n > 10:
        break           # leave the loop entirely
    if n % 2 == 0:
        continue        # skip this pass only
    print(n)
else:
    print("no break")   # runs only without break

10Keeping it flat

See Lesson 10 — Putting it together

Early exits, sentinels, state machines
# early exit — handle failures first
if not user: return
if not user.active: return
ship()

# sentinel — a special value meaning stop
while True:
    n = read_number()
    if n == -1: break

# state machine — behaviour depends on state
state = "idle"
while state != "done":
    event = next_event()
    if state == "idle" and event == "start":
        state = "running"
