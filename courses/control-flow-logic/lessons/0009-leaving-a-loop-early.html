Lesson 09 · Loops

Leaving a loop early

Sometimes you already have the answer and there is no reason to keep looking. This lesson is about break and continue — the two statements that let you steer a loop from the inside.

Time ~10 min Win Search a list and stop at the first match Mission link Loops that respond to what they find

1break: stop the loop

break ends the nearest enclosing loop immediately. Not the current pass — the whole loop. Execution continues at the first line after the loop. 

for n in [3, 7, 12, 5]:
    if n > 10:
        print("Found", n)
        break
    print("Checked", n)

That prints Checked 3, Checked 7, then Found 12 — and stops. The 5 is never looked at, because the loop is already over.

2continue: skip this pass

continue is gentler. It abandons the rest of the current pass and jumps straight to the next one. The loop itself keeps going. 

for n in [1, 2, 3, 4, 5]:
    if n % 2 == 0:
        continue
    print(n)          # 1, 3, 5

The even numbers are skipped, but the loop still visits every item. Use continue when you want to ignore some items rather than stop looking.

Key idea break leaves the loop. continue skips one pass. Both affect only the nearest loop — inside a nested loop, they do not touch the outer one.

3The loop else clause

Python has a feature most languages lack: a loop can carry an else block. It runs only if the loop finished without hitting break. 

for n in [3, 7, 12]:
    if n > 10:
        print("Found", n)
        break
else:
    print("Nothing over ten")

Read it as "if we never broke out". It is the natural way to express a search that reports failure — and it is why break is not just an optimisation.

Watch out The loop else is not an "if the loop was empty" clause, and it is not a fallback for the loop body. It is specifically "the loop ran to completion without a break".
