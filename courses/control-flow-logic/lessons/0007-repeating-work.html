Lesson 07 · Loops

Repeating work

A branch decides once. A loop decides again and again, until the answer changes. This lesson is about the while loop — the simplest way to make a program repeat itself, and the easiest way to make it never stop.

Time ~10 min Win Write a loop that counts down and stops Mission link Repetition without repetition

1Repeat while true

A while loop has the same shape as an if: keyword, condition, colon, indented block. The difference is what happens after the block finishes — Python jumps back to the condition and asks again. 

count = 3
while count > 0:
    print(count)
    count = count - 1
print("Liftoff")

That prints 3, 2, 1, then Liftoff. The condition is checked before every pass, so if it is false to begin with, the block never runs at all.

2Something must change

A while loop only ends if something inside it moves the condition toward false. In the countdown, that something is count = count - 1. Remove that line and the loop runs forever. 

count = 3
while count > 0:
    print(count)          # count never changes
                          # this never stops

An infinite loop is not a crash — the program is doing exactly what you told it. It just never finishes. In a terminal you stop it with Ctrl+C; in a browser tab it will freeze the page.

Watch out Before you write a while, ask: which line makes this condition false? If you cannot point at it, you have written an infinite loop.

3Loops and branches together

The real power comes from putting a branch inside a loop. The loop repeats, and the branch decides what to do on each pass. This is the shape of almost every program you will ever write. 

n = 1
while n <= 10:
    if n % 2 == 0:
        print(n, "even")
    else:
        print(n, "odd")
    n = n + 1

The loop supplies the repetition; the branch supplies the decision. Neither is complicated on its own, and together they can express almost anything.

Key idea A while loop is an if that keeps asking. The condition is re-evaluated before every pass, and the loop ends the first time it is false.
