Lesson 05 · Branching

Choosing a path

You can now produce a boolean and combine booleans. This lesson is where that finally changes what the program does: the if statement, which runs a block of code only when a condition holds.

Time ~10 min Win Write your first real branch Mission link The first statement that decides

1The shape of an if

An if statement has three parts: the keyword, a condition, and a colon. Everything indented underneath runs only when the condition is true. 

if temperature > 30:
    print("It is hot")
    print("Drink water")

Both print lines are inside the branch. If the condition is false, neither runs and the program continues after the block.

2Indentation is the block

In most languages a block is marked with braces. Python uses indentation instead, and this is not a style preference — it is the syntax. The indented lines are the block.

That means a stray space changes the meaning of your program. Dedent one line and it leaves the branch; indent one line too many and it becomes a nested block. Python will raise an IndentationError when the structure is ambiguous, which is a feature: the error catches the mistake before it becomes a silent bug.

Key idea A block is a group of statements that run together. In Python, a block is defined by indentation — four spaces per level, by convention.

3The else clause

Most decisions have a fallback. else gives you the path taken when the condition is false, so the two branches together cover every possibility. 

if score >= 50:
    print("Pass")
else:
    print("Try again")

Exactly one of those two lines runs. There is no third option and no way to reach neither — which is what makes if/else a complete decision.

Watch out else is not "otherwise if". It takes no condition at all. If you find yourself wanting to test something in the else, you want elif — which is the next lesson.
