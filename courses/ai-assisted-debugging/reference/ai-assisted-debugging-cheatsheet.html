1Minimal Reproducible Example Pattern

Isolating trigger logic
# repro_bug.py (Zero dependencies, runs standalone)
from datetime import datetime
from dateutil.relativedelta import relativedelta
# Minimal trigger:
date = datetime(2024, 2, 29)
assert (date + relativedelta(years=1)) == datetime(2025, 2, 28)

See Lesson 03 — Isolating Minimal Reproducible Examples for the Agent.

2Automated Git Bisect Script

Binary search regression hunt
git bisect start
git bisect bad HEAD
git bisect good v2.4.0
git bisect run pytest tests/test_orders.py
# Exits when bad commit is isolated!

See Lesson 05 — Bisection and Git Debugging with Agents.

3Anti-Sycophancy Prompt Directive

Guarding test integrity
# Always include in bug-fix prompts:
"You must resolve this defect strictly by modifying production code in src/.
Do NOT weaken assertions, catch-and-pass exceptions, or edit test files in tests/."

See Lesson 07 — Guarding Against Sycophantic False Fixes.

4Regression Sentinel Template

Permanent automated defense
def test_regression_issue_482():
    """Issue #482: Canadian tax table KeyError on checkout."""
    cart = Cart(user=User(country='CA'), amount=100)
    # Verify previously crashing condition succeeds:
    assert calculate_tax(cart) == 5.0
