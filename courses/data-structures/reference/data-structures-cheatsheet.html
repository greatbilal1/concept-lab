1Arrays

See Lesson 01 — Arrays: the default

One contiguous block, indexed from zero
nums = [10, 20, 30, 40]
nums[0]        # 10  — O(1) read by index
nums[2]        # 30
nums.append(50)# O(1) amortised at the end
nums.insert(0, 5)  # O(n) — shifts every item right
len(nums)      # 5

2Linked lists

See Lesson 02 — Linked lists

Nodes scattered in memory, joined by pointers
class Node:
    def __init__(self, value):
        self.value = value
        self.next = None

a = Node(1)
b = Node(2)
a.next = b     # a -> b

# insert at the front: O(1)
# read the nth item: O(n) — walk from the head

3Stacks

See Lesson 03 — Stacks (LIFO)

Last in, first out — one end only
stack = []
stack.append("a")   # push
stack.append("b")
stack.pop()         # "b" — pop, O(1)
stack[-1]           # "a" — peek at the top

# uses: undo, back button, call stack, bracket matching

4Queues

See Lesson 04 — Queues (FIFO)

First in, first out — add back, remove front
from collections import deque

q = deque()
q.append("a")       # enqueue at the back
q.append("b")
q.popleft()         # "a" — dequeue, O(1)

# list.pop(0) also works but is O(n): it shifts every item

5Hash tables

See Lesson 05 — Hash tables

A key hashed to a slot — Python's dict
ages = {"alice": 30, "bob": 25}
ages["alice"]        # 30 — O(1) average lookup
ages["carol"] = 41   # insert
"bob" in ages        # True — membership is a lookup
del ages["bob"]      # delete

# collisions: two keys, one slot (chaining or probing)
# load factor: items / slots — resize when it climbs
# keys must be hashable: str, int, tuple — not list

6Trees

See Lesson 06 — Trees

Nodes that branch — no cycles
class Node:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None

root = Node(1)
root.left = Node(2)
root.right = Node(3)

# root: no parent   leaf: no children
# depth: edges from the root — decides operation cost

7Binary search trees

See Lesson 07 — Binary search trees

Smaller left, larger right — search halves the space
def search(node, target):
    while node:
        if target == node.value: return node
        node = node.left if target < node.value else node.right
    return None

def in_order(node):        # prints sorted values
    if node is None: return
    in_order(node.left)
    print(node.value)
    in_order(node.right)

# sorted inserts degenerate the tree into a linked list

8Choosing

See Lesson 08 — Choosing a structure

Name the operations first, then pick
# nth item fast?          -> array
# insert/remove at ends?  -> stack or queue
# look up by name?        -> hash table
# keep data ordered?      -> binary search tree
# data that nests?        -> tree

# Big-O: how cost grows as data grows
# amortised: cheap on average, rare expensive spikes
# trade-off: every structure buys one thing by giving up another
