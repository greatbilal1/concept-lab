Queues (FIFO)

A queue is a stack's opposite. Where a stack touches one end, a queue touches two: you add at the back and remove from the front. That gives you first in, first out — the rule of every real line you have ever stood in.

Time ~10 min Win Spot the O(n) trap in a list-based queue Mission link The same structure, two different costs

1Two ends, one order

A queue has a front and a back. New items join at the back (enqueue) and leave from the front (dequeue). Nothing is ever inserted or removed in the middle.

The result is FIFO — First In, First Out. Items leave in exactly the order they arrived, which is what makes a queue fair.

Key idea A stack reverses order; a queue preserves it. Same underlying list, different rule about which end you touch.

2The trap: list.pop(0)

The obvious way to build a queue in Python is to append at the end and pop from the front: 

queue = []
queue.append("a")   # enqueue
queue.append("b")
queue.pop(0)        # "a" — dequeue, but O(n)!

That pop(0) is a trap. Removing the first item of a list leaves a gap, so Python must shift every remaining item one slot to the left. One dequeue costs O(n), and a loop of n dequeues costs O(n²).

Watch out list.pop(0) inside a loop is one of the most common performance bugs in beginner Python. It looks O(1) and is actually O(n).

3The right tool: deque

Python ships a queue-ready structure in the standard library: collections.deque (pronounced "deck"). It is a doubly linked list of blocks, so adding or removing at either end is O(1): 

from collections import deque

queue = deque()
queue.append("a")       # enqueue at the back
queue.append("b")
queue.popleft()         # "a" — dequeue from the front, O(1)

Same behaviour, different cost. This is the lesson of the whole course in miniature: the structure you choose decides the price you pay.

4Where queues show up

  • Print spoolers — jobs print in the order they were submitted.
  • Task schedulers — workers take the oldest waiting job first.
  • Breadth-first search — you visit nodes in the order you discovered them.
  • Message queues — a producer enqueues, a consumer dequeues.

✓ Your win for today

You can build a queue, explain FIFO, and — most importantly — recognise that list.pop(0) is O(n) while deque.popleft() is O(1). You now choose the structure by its cost, not by habit.
