Binary search trees

Last lesson the tree had no order — any value could sit anywhere. Add one rule and everything changes: keep smaller values on the left and larger on the right, and the tree becomes a search structure that halves its work at every step.

Time ~10 min Win Search a BST and explain why it is fast Mission link Order turns a tree into a search tool

1The ordering rule

A binary search tree is a binary tree with one extra invariant: for every node, all values in its left subtree are smaller, and all values in its right subtree are larger.

That rule holds at every node, not just the root. It is what lets you decide, at each step, which half of the tree to ignore.

Key idea The ordering rule is a promise about the whole subtree, not just the immediate children. Every value under a node's left branch is smaller than that node.

2Searching

To find a value, start at the root and compare. Smaller? Go left. Larger? Go right. Equal? Found it. Each comparison throws away an entire subtree.

On a balanced tree this halves the remaining nodes at every step, so search costs O(log n) — the same trick as binary search on a sorted array, but without needing the array to stay sorted.

Watch out Insert values in sorted order and the BST degenerates into a linked list, where search costs O(n). The speed depends on the tree staying balanced, not on the rule alone.

3Traversal

A traversal visits every node in a defined order. The three depth-first orders differ only in when you visit the node itself:

  • In-order — left, node, right. On a BST this yields sorted output.
  • Pre-order — node, left, right. Useful for copying a tree.
  • Post-order — left, right, node. Useful for deleting a tree.
def in_order(node):
    if node is None:
        return
    in_order(node.left)
    print(node.value)
    in_order(node.right)

4Where BSTs show up

  • Ordered maps — dictionaries that keep keys sorted.
  • Range queries — "all values between 10 and 20".
  • Databases — indexes are tree-shaped for exactly this reason.
  • Autocomplete — prefix search walks down a tree.

✓ Your win for today

You can state the BST ordering rule, search a tree by comparing and branching, and name the three depth-first traversals. You also know why a BST is only fast while it stays balanced.
