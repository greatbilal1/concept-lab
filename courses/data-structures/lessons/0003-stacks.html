Stacks (LIFO)

A stack is the simplest restriction you can put on a list: you may only touch one end. That single rule — last in, first out — turns out to describe undo buttons, function calls, and the way your browser walks back through history.

Time ~10 min Win Build a stack and explain why only the top moves Mission link Restricting a structure makes it predictable

1One end only

Picture a stack of plates. You add a plate on top, and you take a plate off the top. You never slide one out of the middle — that would be a different structure. A stack is exactly that: a list where push adds to the top and pop removes from the top.

Because only one end is ever touched, the operations are trivial. There is no shifting, no searching, no index arithmetic — just a pointer to the top.

Key idea A stack is a restriction, not an addition. It takes a list and forbids most of what you could do with it, and that restriction is what makes it useful.

2Last in, first out

The rule has a name: LIFO — Last In, First Out. The most recent item you pushed is the first one you pop. Push a, then b, then c, and popping gives you c, then b, then a.

Notice that the order reverses. That is the whole trick: a stack is a reverser. Anything you push and then pop comes back in the opposite order, which is why stacks show up wherever order needs flipping.

3Building one in Python

You do not need a class. A Python list already has the two operations you need: append pushes onto the end, and pop removes from the end. Treat the end of the list as the top of the stack: 

stack = []
stack.append("a")   # push
stack.append("b")   # push
stack.pop()         # "b" — the top
stack.pop()         # "a" — now the top

# peek without removing
stack[-1] if stack else None

Both operations are O(1) — constant time, no matter how tall the stack grows. That is the payoff of only touching one end.

Watch out Popping an empty stack raises IndexError. Check if stack: first, or catch the error — an empty stack is a normal state, not a bug.

4Where stacks show up

Once you know the shape, you start seeing it everywhere:

  • Undo — every action is pushed; undo pops the most recent one.
  • The call stack — each function call is pushed; returning pops it.
  • Bracket matching — push every opening bracket, pop on each closing one.
  • Browser history — the back button pops the page you just left.

✓ Your win for today

You can build a stack from a plain list, explain LIFO in one sentence, and name three places the pattern appears. You also know why restricting a structure to one end makes both operations constant time.
