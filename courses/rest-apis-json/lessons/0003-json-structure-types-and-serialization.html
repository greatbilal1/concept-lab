Lesson 03 · JSON & Data Representations

JSON structure, types, and serialization

JSON is the universal payload format of the web. Learn the six data types supported by ECMA-404, escaping rules, and how to safely serialize and parse data.

Time ~10 min Win Serialize, parse, and validate JSON payloads across clients and servers Mission link The primary data interchange format across all modern web APIs

1The six native JSON types

Defined in ECMA-404, JSON (JavaScript Object Notation) is a text format containing exactly six data types: string (double-quoted), number (integer or floating point), boolean (true or false), null, object (key-value dictionary), and array (ordered list).

Notice what is missing: JSON has no native Date, RegExp, or Function types. Dates must be serialized as ISO 8601 strings (e.g. "2026-10-03T12:00:00Z") and parsed explicitly by the receiver.

Key idea JSON supports only six types; dates and binary buffers must be serialized as strings.
