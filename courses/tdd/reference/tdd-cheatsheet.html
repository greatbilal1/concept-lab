The TDD Micro-Loop Triangulation Example Bug Fix TDD Workflow Refactoring Discipline

1The TDD Micro-Loop

Red -> Green -> Refactor
# 1. RED: Write failing test
def test_add(): assert add(2, 3) == 5

# 2. GREEN: Simplest passing code
def add(a, b): return a + b

# 3. REFACTOR: Clean up without changing behavior

See Lesson 01 — The TDD Rhythm: Red, Green, Refactor.

2Triangulation Example

Generalizing from multiple tests
# Test 1: assert parse('1') == 1  -> return 1 (fake)
# Test 2: assert parse('2') == 2  -> return int(s) (generalize)

See Lesson 03 — The Simplest Thing That Could Possibly Work.

3Bug Fix TDD Workflow

Reproduce then eliminate
# 1. Write test reproducing customer ticket #842
def test_reproduce_null_discount():
    assert apply_discount(100, None) == 100 # FAILS
# 2. Fix code to handle None -> PASS
# 3. Bug is permanently prevented from regressing

See Lesson 08 — When TDD Shines and When to Prototype.

4Refactoring Discipline

Clean structure under green tests
# Rule: Only refactor when all tests pass.
# Run tests after EVERY small rename, extraction, or cleanup.

See Lesson 04 — The Refactor Step: Improving Without Breaking.
