1Event Loop & Timers

Phases of asynchronous execution
// Microtasks (run immediately after current operation):
process.nextTick(() => console.log("nextTick"));
Promise.resolve().then(() => console.log("promise microtask"));

// Macrotasks (run in event loop phases):
setTimeout(() => console.log("timer phase"), 0);
setImmediate(() => console.log("check phase"));

See Lesson 01 — The Event Loop & Libuv Architecture.

2Buffers & File System

Asynchronous binary I/O
import fs from "node:fs/promises";

// Allocating and converting binary buffers
const buf = Buffer.from("Hello Node.js", "utf-8");
console.log(buf.length, buf.toString("hex"));

// Safe non-blocking file read
const content = await fs.readFile("./config.json", "utf-8");

See Lesson 03 — File System, Buffers & Binary Data.

3Streams & Backpressure

Memory-efficient data pipelines
import fs from "node:fs";
import { pipeline } from "node:stream/promises";
import zlib from "node:zlib";

// Pipe readable file stream through gzip into destination
await pipeline(
  fs.createReadStream("large-input.log"),
  zlib.createGzip(),
  fs.createWriteStream("large-input.log.gz")
);

See Lesson 04 — Streams & Piping Large Datasets.

4Express & Middleware

Composable request pipeline
import express from "express";

const app = express();
app.use(express.json()); // parse JSON body

// Custom logging middleware
app.use((req, res, next) => {
  console.log(req.method, req.url);
  next(); // pass to next handler
});

app.get("/api/health", (req, res) => res.json({ ok: true }));
app.listen(3000);

See Lesson 06 — Express & Middleware.
