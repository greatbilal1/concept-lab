Lesson 05 · HTTP Servers & REST APIs

Native HTTP Server & Request Handling

Understand what happens before Express: Node's native node:http module parses HTTP connections directly.

Time ~10 min Win Create an HTTP server from scratch using node:http and parse URLs, methods, and JSON bodies Mission link Understand the raw HTTP engine underpinning every Node.js web framework

1The node:http module

Before installing Express or Fastify, every Node.js web server builds upon the native node:http module. Calling http.createServer((req, res) => { ... }) registers an event listener that fires whenever a client initiates an HTTP request.

Inside the callback, req is an instance of http.IncomingMessage (a Readable stream of the request body), and res is an instance of http.ServerResponse (a Writable stream for the response).

Key idea The native HTTP request is a Readable stream; the response is a Writable stream.

2Parsing headers, URLs, and streaming bodies

To parse incoming JSON bodies natively, you accumulate chunks from req into an array of buffers, concatenate them upon the 'end' event, and call JSON.parse().
