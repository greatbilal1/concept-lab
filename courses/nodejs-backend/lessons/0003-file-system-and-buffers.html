Lesson 03 · Asynchronous I/O, Buffers & Streams

File System, Buffers & Binary Data

Node.js handles raw binary data outside V8 memory using Buffers. Learn safe asynchronous file manipulation.

Time ~10 min Win Read, write, and manipulate binary data and files using Buffer and fs/promises Mission link Process images, files, and network sockets without memory corruption or blocking I/O

1What is a Buffer?

In standard browser JavaScript, strings handle text, but raw binary data (like images, network packets, or compressed archives) was historically awkward. Node.js introduced the global Buffer class.

A Buffer represents a fixed-size chunk of binary memory allocated outside the V8 heap in native C++ memory. Once allocated, its size cannot be changed.

Key idea Buffers represent raw chunks of binary memory allocated outside the V8 JavaScript garbage collection heap.

2Modern file operations with fs/promises

Never use synchronous methods like fs.readFileSync() in a request handler because they lock the entire server. Always prefer the promise-based API in node:fs/promises.
