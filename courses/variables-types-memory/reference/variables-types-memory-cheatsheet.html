Variables, Types & Memory Cheat Sheet

The facts you will reach for every day, compressed. Print this, or keep it open beside your editor. Every snippet is runnable Python 3.

Binding Types Numbers & text Mutable Identity Memory Copying Naming

1Binding

See Lesson 01 — A name for a value · Lesson 02 — Assignment is a binding

A name is a label, not a box
x = 5            # bind the name x to the value 5
x = x + 1        # evaluate right side, then rebind x
a, b = b, a      # swap: right side evaluated first

2Types

See Lesson 03 — Types are rules

A type is a set of allowed operations
type(5)                 # <class 'int'>
isinstance(5, int)      # True
int("3") + 2            # 5   — convert, then add
2 + "3"                 # TypeError — no shared meaning

3Numbers & text

See Lesson 04 — Numbers and text

Exact integers, approximate floats, immutable strings
10 // 3          # 3    — integer division
10 % 3           # 1    — remainder
0.1 + 0.2        # 0.30000000000000004
0.1 + 0.2 == 0.3 # False — rounding error
s = "hi"; s.upper()   # "HI" — a new string

4Mutable & immutable

See Lesson 05 — Mutable and immutable

Which values can change in place
# immutable: int, float, str, bool, tuple
# mutable:   list, dict, set

items = [1, 2, 3]
items.append(4)      # mutates the list in place

5Identity

See Lesson 05 — Mutable and immutable · Lesson 06 — References, not copies

== compares values, is compares identity
a = [1, 2]; b = [1, 2]
a == b      # True  — same contents
a is b      # False — different lists

c = a
a is c      # True  — the same list, two names

6Memory

See Lesson 07 — The stack and the heap · Lesson 08 — Garbage and lifetime

Stack holds frames, heap holds objects
def make():
    items = [1, 2, 3]   # list lives on the heap
    return items        # reference escapes the frame

data = make()           # the list survived the call
a = [1, 2, 3]
a = None                # last reference gone → garbage

7Copying

See Lesson 09 — Copying and sharing

Share, shallow copy, or deep copy
import copy
a = [[1, 2], [3, 4]]

b = a                  # shared — one value
c = a.copy()           # shallow — new outer, shared inner
d = copy.deepcopy(a)   # deep — fully independent

8Naming

See Lesson 10 — Naming for humans

Conventions that make code read itself
user_name = "Ada"        # variable — lowercase_with_underscores
MAX_RETRIES = 3          # constant — ALL_CAPS
_internal_cache = {}     # leading underscore — internal use
