Copying and sharing

Now that you know names are references, you can decide deliberately: share a value, or copy it. The choice is not always obvious, because a shallow copy copies the container but not what is inside it.

Time ~11 min Win Choose share or copy on purpose Mission link Why a copy still shares inner lists

1Sharing is the default

Assignment shares. b = a gives you two names for one value. That is often what you want — passing a large list to a function without copying it is efficient. But when you need independence, you must copy explicitly. 

a = [1, 2, 3]
b = a            # shared — one list
c = a.copy()     # copied — two lists
c.append(4)
print(a)         # [1, 2, 3] — a is untouched
print(c)         # [1, 2, 3, 4]

2Shallow copy: the container only

a.copy() is a shallow copy. It creates a new outer container, but the items inside are still shared. If those items are themselves mutable, changing one through the copy is visible through the original. 

a = [[1, 2], [3, 4]]
b = a.copy()      # new outer list, same inner lists
b[0].append(99)
print(a)          # [[1, 2, 99], [3, 4]] — a changed!

The outer list was copied, so b[0] = something would not affect a. But b[0] and a[0] are the same inner list, so mutating it is shared.

3Deep copy: everything

A deep copy copies the container and everything inside it, recursively. The result shares nothing with the original, so changes never leak across. It costs more, but it is fully independent. 

import copy
a = [[1, 2], [3, 4]]
b = copy.deepcopy(a)
b[0].append(99)
print(a)          # [[1, 2], [3, 4]] — a is untouched
Key idea A shallow copy duplicates the outer container but shares the items. A deep copy duplicates everything, recursively, so nothing is shared.

4Choosing deliberately

The right choice depends on intent. Share when the other code should see your changes, or when copying would be wasteful. Shallow-copy when you want a new container but the items are immutable or safe to share. Deep-copy when you need total independence and the structure is nested.
