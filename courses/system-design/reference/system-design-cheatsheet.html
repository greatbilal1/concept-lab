1Back-of-the-Envelope QPS & Storage Formulas

Universal system design constants
# 1 Day = 86,400 seconds (Approx 100k for mental math)
# QPS = Total Daily Requests / 86,400
# Peak QPS = Average QPS * 2 (or * 3 for surges)
# Storage/Year = Daily Requests * Size_per_Request * 365

2Cache-Aside with Explicit Invalidation

Safe high-throughput caching pattern
async def get_user(uid):
    cached = await redis.get(f'user:{uid}')
    if cached: return json.loads(cached)
    data = await db.fetch_user(uid)
    await redis.set(f'user:{uid}', json.dumps(data), ex=3600)
    return data

async def update_user(uid, updates):
    await db.update_user(uid, updates)
    await redis.delete(f'user:{uid}') # Invalidate immediately!

3SRE Error Budget Calculation
