1The Sandwich Prompting Pattern

Overcoming attention drop-off
[TOP]: Primary goal, roles, and non-negotiable invariants.
[MIDDLE]: Retrieved documentation, file snippets, and schemas.
[BOTTOM]: 'Remember: Return only valid JSON. Do not modify User.py.'
