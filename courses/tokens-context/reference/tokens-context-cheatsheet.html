1Client-Side Token Counting with Tiktoken

Exact local token calculation
import tiktoken
enc = tiktoken.get_encoding("cl100k_base")
def count_tokens(text: str) -> int:
    return len(enc.encode(text))

3Map-Reduce Parallel Summarizer

Scaling past context limits
import asyncio
# Map: Summarize 20 chunks concurrently
summaries = await asyncio.gather(*[call_llm(f"Summarize: {c}") for c in chunks])
# Reduce: Combine intermediate summaries into final report
final_report = await call_llm(f"Synthesize these summaries:\n" + "\n".join(summaries))
