1The Universal Box Reset

Predictable sizing everywhere
*, *::before, *::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

See Lesson 02 — Box-sizing: border-box versus content-box.

2Flexbox Quick Reference

One-dimensional alignment
.flex-container {
  display: flex;
  flex-direction: row;          /* main axis: horizontal */
  justify-content: space-between;/* main axis alignment */
  align-items: center;          /* cross axis alignment */
  gap: 1rem;                    /* spacing between items */
}

See Lesson 05 — Flexbox: one-dimensional layout.

3CSS Grid Quick Reference

Two-dimensional matrix layout
.grid-container {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
  gap: 1.5rem;
}

See Lesson 06 — CSS Grid: two-dimensional layout.

4Responsive Sizing

Fluid typography and clamping
/* clamp(min, preferred, max) */
font-size: clamp(1rem, 2.5vw, 2rem);
max-width: min(90vw, 1200px);

See Lesson 07 — Media queries and responsive units.
