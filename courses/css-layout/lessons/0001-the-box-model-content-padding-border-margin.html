Lesson 01 · The Box Model

The box model: content, padding, border, margin

In CSS, everything is a box. Master the four concentric layers — content, padding, border, and margin — that govern all element geometry.

Time ~10 min Win Calculate element dimensions and account for margin collapsing Mission link The foundation of all layout geometry and spacing on the web

1The four concentric boxes

Every element rendered on a web page is composed of four concentric nested rectangles: Content (the text or image), Padding (clear space inside the border), Border (the outline around padding), and Margin (clear space outside the border separating neighboring elements).

A critical rule: Vertical margins collapse. If one paragraph has margin-bottom: 20px and the next has margin-top: 30px, the space between them is not 50px — it collapses to the largest value, 30px.

Key idea The box model nests Content within Padding, Border, and Margin; vertical margins collapse.
