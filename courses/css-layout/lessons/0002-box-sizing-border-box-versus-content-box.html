Lesson 02 · The Box Model

Box-sizing: border-box versus content-box

Why does adding padding make your element wider than 100%? Learn why the universal border-box reset is the first line of CSS every professional writes.

Time ~10 min Win Apply the universal border-box reset to eliminate unexpected layout overflow Mission link Eliminates the #1 source of horizontal scrollbars in web layouts

1The historical content-box flaw

By default, browsers use box-sizing: content-box. In this mode, when you write width: 100%; padding: 20px;, the browser sets the content to 100% and then adds 40px of padding on top. The result: an element 100% + 40px wide that overflows the screen and creates a horizontal scrollbar.

With box-sizing: border-box, your declared width: 100% is the total outer width. The browser automatically absorbs padding and borders inwardly, keeping your layout predictable.

Key idea border-box absorbs padding and borders inwardly so declared widths remain exact.
