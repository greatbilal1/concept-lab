Debugging CSS layout bugs

Why is there a mystery horizontal scrollbar on mobile? Why did that element collapse to zero height? Master visual debugging techniques and DevTools overlays.

Time ~10 min Win Diagnose and fix layout overflow, z-index clipping, and collapse bugs using DevTools Mission link The essential troubleshooting skill for production frontend CSS craft

1The mystery horizontal scrollbar

The most common bug on mobile web pages is an unexpected horizontal scrollbar allowing the page to wobble sideways. This is almost always caused by an element whose width plus margins, padding, or fixed pixel dimension exceeds 100vw.

Instead of guessing, use the outline debugging trick: * { outline: 1px solid red !important; }. Every element's boundary box is highlighted, immediately exposing which rogue element is protruding past the viewport boundary.

Key idea Use outline or DevTools overflow inspection to instantly identify rogue elements causing horizontal scroll.
