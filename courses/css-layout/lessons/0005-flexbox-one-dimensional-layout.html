Flexbox: one-dimensional layout

Centering things in CSS used to be a meme; Flexbox made it trivial. Master the main axis, cross axis, space distribution, and alignment.

Time ~10 min Win Build flexible, responsive one-dimensional component layouts using Flexbox Mission link The primary tool for navigation bars, card rows, and component layouts

1The two axes of Flexbox

Flexbox is a one-dimensional layout model: it lays items out along a single primary axis at a time. The main axis is defined by flex-direction: row (horizontal, default) or column (vertical). The cross axis runs perpendicular to it.

All flexbox properties map to these two axes: justify-content aligns items along the main axis; align-items aligns items across the cross axis. Learn the axes, and you master Flexbox.

Key idea justify-content controls the main axis; align-items controls the cross axis.
