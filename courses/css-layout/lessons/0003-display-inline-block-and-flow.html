Lesson 03 · Normal Flow & Positioning

Display: inline, block, and normal flow

How does the browser decide where elements go before you style them? Master inline versus block elements, normal flow, and formatting contexts.

Time ~10 min Win Differentiate block, inline, and inline-block formatting behaviors Mission link Explains default browser document layout algorithms

1Block versus inline flow

In normal document flow, elements behave in one of two fundamental ways: block or inline.

Block elements (like <div>, <p>, <h1>) start on a new line and expand horizontally to fill 100% of their container's width. Inline elements (like <span>, <a>, <strong>) flow along with text, ignoring top/bottom margins and declared width/height.

Key idea Block elements take full width on a new line; inline elements flow like words inside text.
