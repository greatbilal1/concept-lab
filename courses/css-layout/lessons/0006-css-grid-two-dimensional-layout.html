Lesson 06 · Modern Layout (Flex/Grid)

CSS Grid: two-dimensional layout

Flexbox does lines; CSS Grid does matrices. Master two-dimensional layouts, fractional fr units, auto-fit repeaters, and named grid areas.

Time ~10 min Win Design responsive two-dimensional grid layouts with auto-fit and minmax Mission link The most powerful layout engine built into modern web browsers

1Two-dimensional matrix control

Flexbox excels at one-dimensional rows or columns, but coordinating rows and columns simultaneously in Flexbox requires awkward nested divs. CSS Grid is a true two-dimensional layout system.

You define rows and columns on the container, and child items place themselves into the resulting matrix. The fr (fractional) unit represents a fraction of remaining free space, making responsive grids effortless.

Key idea CSS Grid coordinates rows and columns simultaneously using fractional units.

2The holy grail responsive grid line

The single most powerful line of modern CSS: a fully responsive auto-fitting grid that needs zero media queries.

3Tracing the responsive auto-fit calculation

Trace how repeat(auto-fit, minmax(250px, 1fr)) adapts across screen resizing without media queries.

4Practice

Test your memory of CSS Grid syntax.

✓ Your win for today

You can build fluid, multi-column card grids that adapt to any screen size without writing media queries.

5Do this next

  1. Create a card grid using grid-template-columns: repeat(auto-fit, minmax(280px, 1fr)).
  2. Inspect the grid tracks using the Grid overlay in Chrome or Firefox DevTools.
  3. Define named grid areas for a page header, sidebar, main, and footer.
