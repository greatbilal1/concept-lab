1Transaction Syntax

All-or-nothing execution block
BEGIN;
UPDATE accounts SET balance = balance - 100 WHERE id = 1;
UPDATE accounts SET balance = balance + 100 WHERE id = 2;
-- If any error occurs:
-- ROLLBACK;
-- Otherwise:
COMMIT;

See Lesson 01 — The ACID guarantees explained.

2Isolation Levels

ANSI SQL concurrency levels
SET TRANSACTION ISOLATION LEVEL READ COMMITTED;   -- Default: prevents dirty reads
SET TRANSACTION ISOLATION LEVEL REPEATABLE READ;  -- Snapshot: prevents non-repeatable reads
SET TRANSACTION ISOLATION LEVEL SERIALIZABLE;     -- Strict: prevents all concurrency anomalies

See Lesson 03 — The four ANSI isolation levels.

3Pessimistic Locking

SELECT FOR UPDATE
BEGIN;
-- Lock the specific row against concurrent modifications
SELECT balance FROM accounts WHERE id = 1 FOR UPDATE;

UPDATE accounts SET balance = balance - 50 WHERE id = 1;
COMMIT; -- lock released upon commit or rollback!

See Lesson 05 — Locking: pessimistic versus optimistic.

4Optimistic Locking

Version column pattern
-- 1. Read current version
SELECT id, balance, version FROM accounts WHERE id = 1;

-- 2. Update with version guard
UPDATE accounts 
SET balance = balance - 50, version = version + 1
WHERE id = 1 AND version = 3;

-- If rows affected == 0, another transaction won; retry!

See Lesson 06 — Deadlocks: detection and prevention.
