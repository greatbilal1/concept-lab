Lesson 01 · The ACID Properties

The ACID guarantees explained

What happens when the server loses power midway through a balance transfer? Discover the four ACID guarantees that keep enterprise data correct.

Time ~10 min Win Explain the four ACID database guarantees and group operations into atomic transactions Mission link The fundamental trust contract between application developers and database storage

1All or nothing: The bank transfer

Consider transferring $100 from Account 1 to Account 2. This requires two operations: 1. Deduct $100 from Account 1, and 2. Add $100 to Account 2. What happens if the server loses power or crashes between step 1 and step 2?

Without transactions, $100 vanishes into thin air! A Transaction wraps both statements into an atomic unit: BEGIN; ... COMMIT;. If an error or crash occurs anywhere before COMMIT, the database automatically rolls back step 1, leaving the database completely uncorrupted.

Key idea A transaction guarantees atomicity: all operations succeed together, or all fail together.
