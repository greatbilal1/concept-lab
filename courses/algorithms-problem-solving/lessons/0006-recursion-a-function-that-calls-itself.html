Lesson 06 · Recursion

Recursion: a function that calls itself

Merge sort sorted a list by sorting two smaller lists the same way. That is recursion: a function that solves a problem by calling itself on a smaller version of the same problem. Today you learn the two parts every recursive function needs, and you trace one call by hand.

Time ~12 min Win Write and trace a recursive function with a correct base case Mission link Recursion is the engine inside divide and conquer

1The idea: solve a smaller copy

Think of Russian nesting dolls. To find the smallest doll you open the outer one and repeat the same action on what is inside. You do not need a new technique for each layer — you need the same technique, applied to something smaller, until there is nothing left to open.

A recursive function works the same way. It handles the current case by calling itself on a smaller input, trusting that the smaller call will come back with the right answer. That trust is the whole trick: you describe the problem in terms of itself.

Key idea Recursion solves a problem by calling the same function on a smaller version of the problem, and trusting that smaller call to return the right answer.

2Base case and recursive case

Every correct recursive function has exactly two parts. The base case is the smallest input, answered directly with no further calls — for a countdown, that is zero. The recursive case handles everything else by calling itself on something closer to the base case.

The base case is not optional. Without it, the function keeps calling itself on inputs that never shrink, and the program runs out of room and crashes. The recursive case must always move toward the base case, or the recursion never ends.

4Reading a recursive function

When you meet a recursive function, ask three questions in order. What is the base case? What smaller input does the recursive case use? Does that smaller input always move toward the base case? If you can answer all three, you can trust the function without tracing every call.

This is the same reasoning you used for merge sort: you did not trace every merge, you trusted that sorting the halves worked and checked only the combine step.

✓ Your win for today You can write a recursive function with a correct base case, and you can explain what goes wrong when the base case is missing.

5Do this next

  1. Write a recursive countdown from 5 that prints each number and stops at zero.
  2. Write a recursive sum of a list by adding the first item to the sum of the rest.
  3. Break your countdown on purpose by removing the base case, and describe what happens.
