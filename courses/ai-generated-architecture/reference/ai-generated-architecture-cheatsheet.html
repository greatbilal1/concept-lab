1Clean Inward Dependency Rule

Architectural layer contract
# ALLOWED: Infrastructure -> Application -> Domain
# FORBIDDEN: Domain importing SQLAlchemy, FastAPI, or Redis!
# Rule: Domain models must be pure dataclasses / classes.

See Lesson 02 — Enforcing Module Boundaries and Dependency Directions.

2Strict Pydantic Contract

Guarding against hallucinated keys
from pydantic import BaseModel, ConfigDict, Field

class CreateOrderSchema(BaseModel):
    model_config = ConfigDict(strict=True, extra='forbid')
    sku: str = Field(min_length=3)
    quantity: int = Field(gt=0)

See Lesson 04 — Schema and Contract Discipline.

3Automated Architectural Fitness Check

import-linter contract (.importlinter)
[importlinter:contract:1]
name = Pure Domain Boundary
type = forbidden
source_modules = src.domain
forbidden_modules = src.infrastructure, src.api, sqlalchemy

See Lesson 07 — Architectural Fitness Functions and Linting.

4Production Hardening Checklist

Bridging prototype to production
1. TIMEOUTS: Ensure all HTTP calls have timeout=5.0.
2. CONFIG: Move magic numbers to environment variables.
3. LOGS: Emit structured JSON logs with request_id.
4. ERRORS: Replace generic except with explicit handlers.

See Lesson 06 — Refactoring AI Prototyped Code into Production Shape.
