1Core principles of Pre-Prompt and Post-Prompt Detection Classifiers

Prompt engineering alone cannot solve prompt injection; probabilistic models can always be coaxed by novel linguistic phrasing. To achieve enterprise reliability, you must deploy Dedicated Safety Classifiers around the model.

Key idea Machine-learning defense: fine-tuned injection classifiers (Llama Guard, DeBERTa), perplexity filtering, and dual-gate inspection.

3Perplexity Anomaly Detection

  • 1. Pre-Prompt Classifier (Input Perimeter): A lightweight, highly fine-tuned classification model (e.g. DeBERTa-v3 or Llama Guard 3) evaluates the input string in under 25 milliseconds. It outputs an `adversarial_probability` score ($0.0$ to $1.0$). If score $> 0.85$, block the request immediately!
  • 2. Perplexity & Token Entropy Anomaly Filters: Adversarial attacks (like GCG suffix attacks: ! ! ! describing \n\n write ...) often have bizarre token distributions with high perplexity. Anomaly filters flag high-perplexity inputs instantly.
  • 3. Post-Prompt Classifier (Output Egress): Inspects the generated response before returning it to the user. Did the model emit forbidden system phrases, leaked instructions, or harmful payloads?

    # Primary Model Generation
    response_text = await target_model.generate(user_prompt)
