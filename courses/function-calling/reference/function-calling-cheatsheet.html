1OpenAI Tool Definition Schema

    "type": "function",

        "parameters": {
            "type": "object",
            "properties": {

2Complete Agent Tool Execution Loop

Iterative while loop
while True:
    res = client.chat.completions.create(model="gpt-4o", messages=messages, tools=tools)
    msg = res.choices[0].message
    messages.append(msg)
    if res.choices[0].finish_reason == "stop": break
    for call in msg.tool_calls:
        result = dispatch(call.function.name, json.loads(call.function.arguments))
        messages.append({"role": "tool", "tool_call_id": call.id, "content": json.dumps(result)})

3Parallel Tool Execution with AsyncIO

Concurrent execution
import asyncio
# Execute multiple tool calls concurrently:
tasks = [dispatch_async(c.function.name, json.loads(c.function.arguments)) for c in tool_calls]
results = await asyncio.gather(*tasks)

4Self-Correcting Tool Error Return
