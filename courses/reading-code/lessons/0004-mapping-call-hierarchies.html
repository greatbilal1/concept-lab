Lesson 04 · Tracing Data & Call Paths

Mapping call hierarchies

Code is a web of calls. Use your editor's language server and grep to navigate caller-callee relationships without losing your place.

Time ~10 min Win Map incoming and outgoing call hierarchies using LSP tools and ripgrep Mission link Prevents disorientation while traversing multi-file function chains

1Callers and callees

When looking at a function, two questions matter: 'Who calls this?' (incoming calls) and 'What does this call?' (outgoing calls).

Language Server Protocol (LSP) tools provide 'Find All References' and 'Show Call Hierarchy'. When LSP is unavailable, fast text search tools like ripgrep (rg) let you search for function names and import statements across thousands of files in milliseconds.

Key idea Incoming calls show where behavior is used; outgoing calls show how behavior is implemented.

2Navigating with bookmarks

When descending deeply into call chains, use editor navigation marks or jump stacks (e.g. Ctrl-O / Ctrl-I) so you can return to your origin without getting lost.

3Call stack traversal

Trace how a developer steps through nested call sites while keeping track of the root caller.

4Practice

Review call hierarchy navigation habits.

✓ Your win for today

You can navigate up and down call trees across dozens of files while always knowing your way back.

5Do this next

  1. Use 'Find All References' on a central utility function in your codebase.
  2. Practice using editor jump keys (Ctrl-O / Ctrl-I or equivalent) to navigate back and forth.
  3. Map a 3-level call tree on a sheet of paper for an important business transaction.
