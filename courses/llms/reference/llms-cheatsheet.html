1Tokenization Inspection with Tiktoken

Analyzing token sequences
import tiktoken
enc = tiktoken.get_encoding("cl100k_base")
tokens = enc.encode("Hello world!")
print(tokens)  # [9906, 1917, 0]
print([enc.decode([t]) for t in tokens])
