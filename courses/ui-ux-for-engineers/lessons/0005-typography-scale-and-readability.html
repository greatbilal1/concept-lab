Typography Scales & Readability

Typography accounts for 90% of web design. Learn to configure mathematical type scales, line heights, and comfortable line lengths.

Time ~10 min Win Establish an accessible typographic scale and optimize line length and line height for comfortable reading Mission link Turn difficult, unreadable text walls into effortless, scannable reading experiences

1The Golden Rules of Web Readability

Most websites fail at basic reading mechanics. If reading your content causes physical eye fatigue, users will bounce. Three universal rules govern typography:

  • Line Length (Measure): An ideal reading line is between 45 and 75 characters (including spaces). Lines longer than 85 characters cause readers to lose their place when tracking back to the next line. Set max-width: 65ch; on article text!
  • Line Height (Leading): Body text line-height should be roughly 1.5 to 1.6. Tight line heights cause text lines to collide; excessively loose line heights make lines feel disconnected. Headings should be tighter: 1.1 to 1.2.
  • Font Size: Never use body text smaller than 16px.
Key idea Restrict body text line length to 45–75 characters (max-width: 65ch) and set line-height to 1.5.

2The mathematical type scale

Never choose arbitrary font sizes like 15px, 19px, 23px. Use a modular type scale where each step is multiplied by a fixed ratio (e.g. Major Third 1.250 or Perfect Fourth 1.333):

  • 12px: Captions, helper text.
  • 14px: Secondary text, metadata.
  • 16px: Standard base body text.
  • 20px: Large body, card titles (h4).
  • 24px: Subsection headers (h3).
  • 32px: Section titles (h2).
  • 40px+: Page hero titles (h1).
