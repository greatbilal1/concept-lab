Layout Composition & Cognitive Load

Do not overwhelm users with 50 options on one screen. Master progressive disclosure, chunking, and cognitive load reduction.

Time ~10 min Win Structure layouts to minimize cognitive load using chunking, progressive disclosure, and responsive composition Mission link Increase user conversion rates and task completion speed by reducing mental friction

1Cognitive Load Theory in UI

Human working memory is severely limited: people can only hold roughly 4 to 7 items in active memory at once (Miller's Law). When an interface presents 30 unorganized form fields or 15 competing buttons, the user experiences cognitive overload and abandons the task.

Great UX reduces cognitive load through two strategies:

  • Chunking: Breaking large amounts of information into small, digestible visual groups (e.g. formatting a 10-digit phone number as (555) 123-4567, or grouping a long form into distinct steps).
  • Progressive Disclosure: Showing only the information necessary for the immediate decision, revealing advanced settings only upon request.
Key idea Break complex tasks into small visual chunks and disclose advanced options only when needed.

2Hick's Law: Fewer choices, faster decisions

Hick's Law states: The time it takes to make a decision increases logarithmically with the number and complexity of choices.

If your pricing page displays 8 different plans, users freeze in analysis paralysis. If you offer 3 plans with one highlighted as "Most Popular", decision time plummets and conversion surges.
