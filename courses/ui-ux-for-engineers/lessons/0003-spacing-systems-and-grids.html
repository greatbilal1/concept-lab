Spacing Systems & The 8pt Grid

Stop guessing random pixel margins like 13px or 27px. Master the mathematical consistency of the 8pt spacing grid.

Time ~10 min Win Implement a consistent 8pt/4pt spacing scale across component padding, margins, and layout gaps Mission link Eliminate visual clutter and maintain pixel-perfect spatial consistency across development teams

1The problem of random numbers

Look at an amateur website's CSS and you will see chaos: margin-top: 13px; padding: 22px; gap: 7px;. Every developer guesses numbers by trial and error. The result looks subtly 'off', disjointed, and messy.

Professional interfaces rely on a strict spacing system. The universal industry standard is the 8pt Spacing Grid: all dimensions, paddings, margins, and gaps are multiples of 8 pixels (8, 16, 24, 32, 48, 64), with a 4px half-step for micro-spacing.

Key idea Never guess margins; restrict all spatial values to a fixed mathematical scale based on multiples of 8 and 4.

2The standard spacing token scale

Instead of hardcoding pixels, define standard CSS custom property tokens:

  • --space-1: 4px; (Micro-gaps: between icons and text, borders).
  • --space-2: 8px; (Compact padding: chips, badges, list item gaps).
  • --space-4: 16px; (Standard card padding, default form input height gaps).
  • --space-6: 24px; (Between distinct components on a card).
  • --space-8: 32px; (Major section separations).
  • --space-12: 48px; (Page layout hero margins).

5Do this next

  1. Audit a CSS stylesheet and replace all arbitrary pixel margins with standard spacing tokens (--space-2, --space-4, etc.).
  2. Verify that all icon dimensions are sized to multiples of 8 (e.g. 16px, 24px, 32px).
  3. Refactor a crowded table layout by increasing cell padding to 12px or 16px.
