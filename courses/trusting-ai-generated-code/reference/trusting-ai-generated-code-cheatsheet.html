1Trust Calibration Risk Matrix

Scrutiny by blast radius
LOW RISK (CSS, docs, helpers):     High agent autonomy, fast review.
MODERATE RISK (CRUD, caching):       Standard unit tests & PR review.
HIGH RISK (Auth, billing, crypto):   ZERO TRUST: Line-by-line audit & 2 approvals!

See Lesson 01 — Calibrating Trust: High-Risk vs Low-Risk Code.

2Constant-Time Token Comparison

Defeating timing attacks
import hmac
# NEVER use: token == secret_token
# ALWAYS use constant-time verification:
is_valid = hmac.compare_digest(user_token, secret_token)

See Lesson 05 — Verifying Cryptography, Security, and Edge Cases.

3The Hierarchy of Verification Truth

Terminal reality over model claims
Level 0 (Zero Authority):   Agent claims in chat ('Tests pass!')
Level 1 (Deterministic):    Ruff / ESLint (Syntax & formatting)
Level 2 (Higher Truth):     Mypy / TypeScript (Type contracts)
Level 3 (Supreme Truth):    Terminal Pytest Exit Code 0

See Lesson 03 — Trusting the Compiler, Linter, and Tests Over the Agent.

Pilot in command principle

# 3. You are 100% accountable for the safety of your software.
