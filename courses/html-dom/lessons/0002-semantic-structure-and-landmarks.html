Lesson 02 · Markup & Semantic Structure

Semantic structure and landmarks

Stop building websites out of meaningless div soup. Learn how header, nav, main, article, and section give rich meaning to machines and assistive tools.

Time ~10 min Win Structure web documents using standard HTML5 landmarks and heading hierarchies Mission link Improves accessibility and search engine readability automatically

1Div soup versus semantic landmarks

A <div> tag has zero semantic meaning: it is a completely generic visual wrapper. When you build a page out of nested divs, screen readers and search engines see an undifferentiated blob of text.

HTML5 introduced Landmark Elements: <header>, <nav>, <main>, <article>, <aside>, and <footer>. Screen reader users use these landmarks to jump straight to main content or navigation with a single keystroke.

Key idea Semantic landmarks transform visual layouts into navigable structural blueprints for assistive technology.
