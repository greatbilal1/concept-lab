Lesson 04 · The Document Object Model

Nodes, elements, and relationships

Not every node in the DOM is an element. Understand the difference between Nodes and Elements, and navigate parent, child, and sibling relationships.

Time ~10 min Win Traverse the DOM tree accurately using element navigation properties Mission link Prevents subtle whitespace bugs when navigating tree structures

1Nodes versus Elements

In the DOM, everything is a Node: text chunks, comments, and tags. An Element is a specific subtype of Node (nodeType === 1) that represents an actual HTML tag.

This distinction matters when traversing: childNodes includes invisible whitespace text nodes between tags, whereas children returns only element tags. Always use element-specific traversal properties (children, nextElementSibling) unless you specifically need raw text nodes.

Key idea Use element-specific properties (children, parentElement) to avoid traversing invisible whitespace text nodes.
