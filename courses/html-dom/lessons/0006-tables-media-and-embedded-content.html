Tables, media, and embedded content

Images, video, and tabular data require structured markup. Learn how to serve responsive images with picture and srcset, and build accessible data tables.

Time ~10 min Win Implement responsive media with srcset and author accessible data tables with th and scope Mission link Optimizes image bandwidth performance and accessible tabular presentations

1Accessible tabular data

Tables are not for page layout; they are for structured, two-dimensional tabular data. An accessible table requires clear headers: <th scope="col"> for column headers and <th scope="row"> for row headers.

Screen readers use the scope attribute to announce the matching column and row header as users navigate between individual cells, preventing complete loss of context in large grids.

Key idea Use th with scope attributes so screen readers announce context for every table cell.
