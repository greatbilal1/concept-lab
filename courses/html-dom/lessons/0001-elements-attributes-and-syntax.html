Elements, attributes, and syntax

HTML is the skeleton of the web. Learn the exact anatomy of tags, void elements, and attributes that make up valid markup.

Time ~10 min Win Write well-formed HTML5 elements with appropriate attributes and syntax rules Mission link The syntactic building blocks of every page on the World Wide Web

1The anatomy of an HTML element

An HTML element typically consists of an opening tag (e.g. <p>), content, and a closing tag (</p>). Inside the opening tag, attributes supply configuration metadata as name="value" pairs.

Some elements cannot hold children (like <img>, <input>, or <meta>). These are called void elements and never have closing tags in HTML5.

Key idea Elements wrap content; attributes configure elements inside their opening tag.
