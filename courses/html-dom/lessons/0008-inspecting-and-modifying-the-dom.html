Lesson 08 · Accessibility & Inspection

Inspecting and modifying the DOM

Browser DevTools are your microscope into the living page. Master DOM inspection, live attribute editing, console selectors, and programmatic mutations.

Time ~10 min Win Inspect, debug, and mutate DOM elements using DevTools and standard DOM APIs Mission link The primary day-to-day diagnostic skill for frontend web development

1The Elements panel as a microscope

Right-clicking an element and selecting 'Inspect' opens the DevTools Elements panel. This shows the live, current DOM tree — complete with JavaScript mutations, active pseudo-states (:hover), and computed CSS styles.

You can edit attributes in real time, reorder nodes by dragging, trigger breakpoint pauses on DOM mutations, and reference the currently selected element in the console using the magic variable $0.

Key idea The Elements panel reveals the live runtime DOM state, not the static initial HTML source file.

2Modern programmatic DOM APIs

Learn the standard, performant JavaScript methods for querying and updating DOM nodes.

3Tracing live DOM mutation

Trace how JavaScript constructs a new element node and attaches it into the document tree.

4Practice

Test your memory of DOM manipulation tools.

✓ Your win for today

You can diagnose layout anomalies, inspect live properties, and safely manipulate the DOM using browser developer tools and modern APIs.

5Do this next

  1. Open DevTools on any website, select an element, and inspect it using $0 in the console.
  2. Add a CSS class to an element interactively using the .cls button in the Elements panel.
  3. Observe the DOM mutation breakpoint feature (Break on subtree modifications).
Primary source Chrome DevTools Documentation: *Get Started with Viewing and Changing the DOM* (developer.chrome.com).
