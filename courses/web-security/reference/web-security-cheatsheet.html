1AsyncPG Parameterized SQL Query

100% SQL injection immunity
# Code and data are strictly separated:
row = await db.fetchrow(
    "SELECT id, email, role FROM users WHERE email = $1 AND is_active = $2",
    untrusted_user_input, True

2Secure Session Cookie Holy Trinity

Maximum browser cookie protection
response.set_cookie(
    key="session_token", value=secure_token,
    httponly=True,  # Blocks XSS JavaScript read access
    secure=True,    # Requires HTTPS transmission
    samesite="Lax"  # Blocks CSRF cross-origin POSTs
)

See Lesson 04 — Cross-Site Request Forgery (CSRF) and SameSite Cookies.

3DOMPurify Rich Text Sanitization

Client-side XSS prevention
import DOMPurify from 'dompurify';
// Strips <script>, onerror, and dangerous attributes:
const cleanHtml = DOMPurify.sanitize(userContent);
document.getElementById('bio').innerHTML = cleanHtml;

See Lesson 03 — Cross-Site Scripting (XSS): Stored, Reflected, and DOM-Based.

4Hardened Security Headers Middleware

FastAPI browser defense headers
@app.middleware("http")
async def add_security_headers(request, call_next):
    res = await call_next(request)
    res.headers["Content-Security-Policy"] = "default-src 'self'"
    res.headers["Strict-Transport-Security"] = "max-age=31536000; includeSubDomains"
    res.headers["X-Frame-Options"] = "DENY"
    res.headers["X-Content-Type-Options"] = "nosniff"
    return res

See Lesson 06 — Security Headers (CSP, HSTS, CORS) and Modern Browser Defenses.
