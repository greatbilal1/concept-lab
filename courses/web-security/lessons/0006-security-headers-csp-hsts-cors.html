1Core principles of Security Headers (CSP, HSTS, CORS) and Modern Browser Defenses

Modern web browsers are sophisticated security operating systems with powerful built-in defense sandboxes. However, the browser will only activate these defenses if your server explicitly instructs it to do so using HTTP Security Headers.

Key idea Browser defense in depth: Content Security Policy (CSP), HTTP Strict Transport Security (HSTS), and Cross-Origin Resource Sharing (CORS).

The Four Essential Browser Security Headers:

3CORS vs Same-Origin Policy

  • 1. Content Security Policy (CSP): Restricts trusted sources of executable code: Content-Security-Policy: default-src 'self'; script-src 'self' https://trusted-cdn.com. Blocks injected inline scripts and rogue third-party tracking scripts!
  • 2. HTTP Strict Transport Security (HSTS): Instructs the browser never to use unencrypted HTTP for this domain for the next year: Strict-Transport-Security: max-age=31536000; includeSubDomains; preload. Prevents SSL-stripping attacks.
  • 3. Cross-Origin Resource Sharing (CORS): Governs which external origins are allowed to read API responses in JavaScript. Never use `Access-Control-Allow-Origin: *` with credentials!
  • 4. X-Content-Type-Options: X-Content-Type-Options: nosniff. Prevents browsers from guessing (MIME-sniffing) file types and executing uploaded images as JavaScript!
# Complete Security Headers Middleware in Python (FastAPI):
@app.middleware("http")
async def add_security_headers(request: Request, call_next):
    response = await call_next(request)
    response.headers["Content-Security-Policy"] = "default-src 'self'; script-src 'self'"
    response.headers["Strict-Transport-Security"] = "max-age=31536000; includeSubDomains"
    response.headers["X-Content-Type-Options"] = "nosniff"
    response.headers["X-Frame-Options"] = "DENY" # Blocks Clickjacking iframe attacks!
    return response
