# Mission — Python Fundamentals

## Why this course exists

Most beginners bounce off Python because every tutorial assumes a dozen things
they have not been told: what a value is, why a name is not a box, why a
function has its own world of names. This course removes that fog. It walks a
complete beginner from "I have never run a line of code" to "I can read and
write small Python programs and explain what each line does" — in ten short,
self-contained lessons that build strictly on each other.

## What the learner can do at the end

- Run Python both interactively (REPL) and as a file, and read a traceback to
  find the failing line.
- Name and use the core types — `int`, `float`, `bool`, `None`, `str`, `list` —
  and convert between them deliberately.
- Write `if`/`elif`/`else` decisions and `for`/`while` loops, including
  `break`, `continue`, and `range`.
- Define functions with parameters, defaults, keyword arguments, and return
  values, and explain scope with the LEGB lookup order.
- Split code into modules, import from the standard library, and use the
  `if __name__ == "__main__"` guard.

## What this course is NOT

- Not a data-structures course — lists appear, but dicts, sets, tuples and
  algorithmic complexity are out of scope.
- Not object-oriented — classes, objects and inheritance are a later course.
- Not a tooling course — no virtual environments, packaging, pip, or testing
  frameworks.
- Not a library tour — only a handful of standard-library modules are named.

## Success looks like

The learner can open a blank file, write a small program that reads values,
makes a decision, loops, and calls a function they defined, then run it and fix
any error a traceback points at — without copying from a tutorial. They can also
explain, in their own words, why a name assigned inside a function is not
visible outside it.
