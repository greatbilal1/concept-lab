Lesson 05 · Types

Lists and indexing

One value is rarely enough. A list holds many values in order, and indexing lets you reach any of them. This lesson covers creating lists, reading and changing items, slicing, and the one big difference from strings: lists can change.

Time ~13 min Win Index, slice and mutate a list Mission link Lists are the first collection every program needs

1A list is an ordered collection

A list is written with square brackets and commas. It keeps its items in order, and it can hold any mix of types — though in practice you usually keep one kind per list. 

scores = [90, 85, 77]
names = ["Ada", "Grace", "Alan"]
mixed = [1, "two", 3.0, True]     # legal, but rarely wise
empty = []

The order is part of the value. [1, 2] and [2, 1] are different lists, even though they hold the same items.

Key idea A list is a sequence: every item has a position, called an index, and the first position is always 0.

2Indexing from zero

Square brackets after a list read one item. Indexing starts at 0, so the first item is [0] and the last is [len - 1]. Negative indexes count from the end. 

names = ["Ada", "Grace", "Alan"]
names[0]      # "Ada"
names[2]      # "Alan"
names[-1]     # "Alan"  — last item
names[3]      # IndexError: list index out of range

An out-of-range index raises IndexError. This is a runtime error, so it only happens when that line actually runs.

3Slicing

A slice reads a range of items and returns a new list. The syntax is [start:stop], and the stop index is excluded. 

nums = [10, 20, 30, 40, 50]
nums[1:3]     # [20, 30]
nums[:2]      # [10, 20]   — from the start
nums[3:]      # [40, 50]   — to the end
nums[::2]     # [10, 30, 50] — every second item

The excluded stop is the detail that trips people up. nums[1:3] gives two items, not three, because index 3 is not included.

4Lists can change

Unlike strings, lists are mutable. You can change an item in place, add items, or remove them — and the original list is affected. 

nums = [10, 20, 30]
nums[0] = 99          # [99, 20, 30]
nums.append(40)       # [99, 20, 30, 40]
nums.remove(20)       # [99, 30, 40]
len(nums)             # 3
Common trap append() changes the list and returns None. Writing nums = nums.append(40) rebinds nums to None and loses your list.
