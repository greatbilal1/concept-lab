Lesson 03 · Types

The core types

Every value in Python has a type, and the type decides what you can do with it. Four types cover most of what you will write: integers, floats, booleans and None. This lesson shows you how to name them, check them, and convert between them.

Time ~12 min Win Identify and convert the four core types Mission link Types are the vocabulary of every later lesson

1Values have types

A type is a category that tells Python what a value is and what it can do. The number 3 and the text "3" look similar on screen, but they are different types and behave differently. 

3 + 4        # 7      — int plus int
"3" + "4"    # "34"   — str plus str concatenates
3 + "4"      # TypeError: unsupported operand type(s)

That last line is the whole point of types. Python refuses to guess what you meant, so it raises a TypeError instead of silently doing something surprising.

Key idea The type of a value determines which operations are legal. Mixing types without converting is the most common beginner error.

2The four core types

You will meet many types, but four carry most of the weight in early code. 

count = 42          # int   — whole numbers, any size
price = 19.99       # float — numbers with a decimal point
ready = True        # bool  — exactly True or False
result = None       # NoneType — "no value here yet"

int has no size limit in Python — it grows as needed. float is a 64-bit double, so it can lose precision: 0.1 + 0.2 is 0.30000000000000004, not 0.3. That is not a bug; it is how binary floating point works.

3Checking and converting

The built-in type() function tells you what a value is. The conversion functions int(), float(), str() and bool() turn one type into another. 

type(42)          # <class 'int'>
type("42")        # <class 'str'>

int("42")         # 42
float("3.5")      # 3.5
str(42)           # "42"
bool(0)           # False
bool("")          # False
bool("0")         # True  — a non-empty string is truthy

That last pair is a classic trap. bool("0") is True, because the string "0" is not empty. Only 0, 0.0, "", None and empty collections are falsy.

4None is not zero

None is a real value that means "nothing here". It is not 0, not False, and not the empty string. It is the value Python gives back when a function has nothing to return. 

result = None
print(result is None)     # True
print(result == 0)        # False
print(result == False)    # False
Common trap Test for None with is None, not == None. is asks "is this the same object?", which is exactly what you mean.
