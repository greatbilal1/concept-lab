Lesson 08 · Functions

Defining functions

A function packages a piece of work behind a name. You write it once, call it many times, and give it inputs so it can do slightly different things each time. This lesson covers def, parameters, arguments and return.

Time ~13 min Win Define and call your own function Mission link Functions are how programs stay small

1Why functions exist

Copying the same five lines to three places is a trap: fix a bug in one copy and the others still have it. A function gives that work one name and one home. 

def greet():
    print("Hello, world!")

greet()      # Hello, world!
greet()      # Hello, world!

def defines the function; the indented block is its body. Nothing runs until you call it by writing its name followed by parentheses.

Key idea Defining a function does not run it. The body runs only when the function is called.

2Parameters and arguments

A parameter is a name in the definition. An argument is the value you pass in when you call. They let one function handle many cases. 

def greet(name):
    print(f"Hello, {name}!")

greet("Ada")      # Hello, Ada!
greet("Grace")    # Hello, Grace!

The parameter name is a local name inside the function. Each call binds it to whatever argument you pass, then the body runs.

3return sends a value back

print() shows a value on screen. return hands a value back to the caller so it can be used. They are not the same thing. 

def add(a, b):
    return a + b

total = add(2, 3)     # total is 5
print(total)          # 5

return also ends the function immediately. A function with no return returns None — which is why print() itself returns None.

4Docstrings

The first string inside a function is its docstring. It documents what the function does, and tools can read it. 

def add(a, b):
    """Return the sum of a and b."""
    return a + b

help(add)     # shows the docstring
Common trap print and return are easy to confuse. A function that prints but does not return gives back None, so total = add(2, 3) would be None if add only printed.
