Lesson 07 · Control flow

Loops and repetition

Computers are good at doing the same thing many times. A loop is how you ask for that. This lesson covers for and while, range(), and the two keywords that change a loop's course: break and continue.

Time ~13 min Win Repeat work with for and while Mission link Loops are the second half of control flow

1for: repeat over a sequence

A for loop takes each item from a sequence in turn and runs the body once per item. The loop variable is rebound to each item as it goes. 

for name in ["Ada", "Grace", "Alan"]:
    print(name)

for ch in "abc":
    print(ch)

You do not manage an index. Python hands you the items directly, which is both shorter and less error-prone than counting yourself.

Key idea for x in seq means "for each item in seq, bind it to x and run the body". The loop ends when the sequence runs out.

2range() for counting

When you need numbers, range() produces them lazily. range(n) counts from 0 up to but not including n. 

range(3)          # 0, 1, 2
range(1, 4)       # 1, 2, 3
range(0, 10, 2)   # 0, 2, 4, 6, 8

for i in range(3):
    print(i)      # prints 0, then 1, then 2

The stop value is excluded, exactly like a list slice. That is why range(3) gives three numbers, not four.

3while: repeat until a condition fails

A while loop keeps running as long as its condition stays true. Use it when you do not know in advance how many times you will loop. 

count = 0
while count < 3:
    print(count)
    count += 1

Something inside the loop must move the condition toward false, or the loop never ends. Forgetting count += 1 gives an infinite loop.

4break and continue

break leaves the loop immediately. continue skips the rest of the current iteration and moves to the next one. 

for n in range(10):
    if n == 5:
        break          # stop entirely at 5
    if n % 2 == 0:
        continue       # skip even numbers
    print(n)           # prints 1, 3
Common trap A while loop whose condition never becomes false hangs the program. If your terminal stops responding, check the loop's exit condition first.
