Strings and f-strings

Text is everywhere: names, messages, file paths, user input. Python's string type is rich, and f-strings make building text from values almost effortless. This lesson covers how strings are written, why they are immutable, and how to format them.

Time ~12 min Win Build and format text with f-strings Mission link Output and messages run through strings

1Writing a string

A string is a sequence of characters. You write one with single or double quotes — they are equivalent, so pick one and be consistent. 

name = "Ada"
greeting = 'Hello'
quote = "She said \"hi\""     # escape the inner quotes
multi = """line one
line two"""                    # triple quotes span lines

Triple-quoted strings keep their line breaks, which makes them useful for longer blocks of text. A backslash escapes a character that would otherwise end the string.

Key idea Quotes are not part of the value. "Ada" and 'Ada' produce the same string; the quotes only tell Python where the text starts and stops.

2Strings are immutable

Once a string exists, it cannot be changed. Every "modifying" method returns a new string and leaves the original alone. 

s = "hello"
s.upper()        # returns "HELLO"
print(s)         # still "hello" — s was never changed
s = s.upper()    # rebind s to the new string

This is the same label-versus-value idea from Lesson 2. The method produces a new value; you decide whether to rebind the name to it.

3f-strings: text with values inside

An f-string is a string prefixed with f. Anything inside curly braces is evaluated and inserted into the text. It is the clearest way to build a message from values. 

name = "Ada"
age = 36
print(f"{name} is {age}")            # Ada is 36
print(f"Next year: {age + 1}")       # Next year: 37
print(f"{name.upper()}!")            # ADA!

You can put any expression inside the braces, not just a name. You can also control formatting: f"{price:.2f}" rounds to two decimal places, and f"{n:>5}" pads to a width of five.

4Useful string methods

Strings come with a large toolbox. These are the ones you will reach for first. 

"  hi  ".strip()          # "hi"      — trim whitespace
"a,b,c".split(",")        # ["a","b","c"]
"-".join(["a","b"])       # "a-b"
"Hello".lower()           # "hello"
"hello".startswith("he")  # True
"hello".replace("l","L")  # "heLLo"
Common trap split() returns a list, and join() takes a list. Mixing them up — calling join on a list — is a frequent error. The separator is the string you call join on.
