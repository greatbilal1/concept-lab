Union & Intersection Types

Compose flexible and expressive types using union (|) and intersection (&) operators, combining distinct data structures.

Time ~10 min Win Combine types with unions and intersections to express complex domain states Mission link Prevent invalid states and enable flexible API contract composition

1Unions: One of several types

A union type (A | B) models a value that can be either type A or type B. It is TypeScript's way of expressing "OR".

When accessing properties on a raw union value before narrowing, TypeScript only allows properties that are shared by all members of the union.

Key idea A union A | B represents values that are either A or B; only shared properties can be accessed without narrowing.

2Intersections: Combining all properties

An intersection type (A & B) combines multiple types into one. A value of type A & B must satisfy all properties of A and all properties of B. It is TypeScript's way of expressing "AND".
