Lesson 02 · Basic Types & Type Inference

Type Inference & Safe Types

You do not need to annotate every variable. TypeScript's inference engine automatically calculates types, while unknown and any control type safety.

Time ~10 min Win Rely on type inference where appropriate and use unknown instead of any for unvalidated data Mission link Prevent unsafe code from sneaking into type-checked codebases

1The power of type inference

TypeScript is smart: when you declare a variable with an initial value, the compiler automatically deduces its type. Writing let score = 100; infers number without requiring let score: number = 100;.

Over-annotating code adds clutter. The standard best practice is: let TypeScript infer local variable types; explicitly annotate function parameters and public APIs.

Key idea Let TypeScript infer local variable types from assignments; annotate function boundaries and complex returns.

2any versus unknown versus never

Understanding the top and bottom types is crucial:

  • any: Disables all type checking. It is an escape hatch that allows calling arbitrary methods and assigning to anything. Avoid using it!
  • unknown: Represents a value of any type, but you cannot use or call properties on it until you narrow its type (e.g. via typeof or assertion).
  • never: Represents a state that can never exist (e.g. a function that always throws, or unreachable code branches).
