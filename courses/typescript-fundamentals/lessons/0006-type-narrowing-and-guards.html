Type Narrowing & Guards

Type narrowing turns broad union types into specific, safe types using runtime checks and discriminated unions.

Time ~10 min Win Narrow union types using typeof, instanceof, in operator, and discriminated unions Mission link Write bulletproof branch logic that guarantees type safety across every execution path

1How TypeScript narrows types

Type narrowing is the process where TypeScript analyzes your JavaScript control flow statements (like if, switch, and ternary operators) to refine a broad type into a narrower, more specific type inside that block.

Standard JavaScript operators serve as built-in type guards: typeof (for primitives), instanceof (for class instances), and the in operator (for property existence).

Key idea TypeScript traces runtime condition checks to narrow types automatically inside conditional blocks.

2Discriminated unions: the gold standard

A discriminated union (or tagged union) is an architectural pattern where each object type in a union shares a common literal property—called the discriminant (e.g. kind, type, or status).

When you switch on this property, TypeScript narrows the exact shape in each case block with zero casting.
