Lesson 07 · Generics & Utility Types

Generics & Type Parameters

Generics allow you to write reusable, flexible functions and classes while preserving full type information.

Time ~10 min Win Author generic functions and interfaces with type parameters and constraints Mission link Build reusable libraries and utilities without sacrificing type safety or resorting to any

1Why generics exist

Imagine writing a function that returns the first item of an array. If you accept any[] and return any, all type safety is lost. If you write separate functions for number[] and string[], you duplicate code.

Generics solve this by introducing type parameters (conventionally named T, U, V). They act as variables for types, capturing the input type and flowing it to the output.

Key idea Generics capture and preserve the exact type of data passed into reusable functions and classes.

2Generic constraints: extends keyword

Sometimes a generic must guarantee certain properties. You can constrain a generic type parameter using T extends Shape.

For example, function logLength<T extends { length: number }>(item: T) guarantees that item.length is valid, accepting strings, arrays, or custom objects with a length property, while rejecting numbers or booleans.
