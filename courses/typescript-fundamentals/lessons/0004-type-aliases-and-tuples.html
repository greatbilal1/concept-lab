Lesson 04 · Interfaces & Type Aliases

Type Aliases & Tuples

Type aliases give a name to any type—including unions, primitives, and tuples. Learn how they complement interfaces.

Time ~10 min Win Create type aliases for custom types and define fixed-length, typed tuples Mission link Represent complex primitive combinations and structured return values cleanly

1Type aliases: naming any shape

While interface is specifically designed for object structures, a type alias (declared with type Name = ...) can name any valid type: primitives, unions, intersections, functions, or tuples.

For example: type ID = string | number; cannot be expressed with an interface. Type aliases are indispensable when modeling domain types and functional signatures.

Key idea Use interface for open, extensible object models; use type alias for unions, primitives, tuples, and function signatures.

2Tuples: fixed-length, ordered arrays

A tuple is a specialized array with a fixed number of elements where each position has a specific type. A classic example is a coordinate pair [number, number] or React's useState return value [state, setState].
