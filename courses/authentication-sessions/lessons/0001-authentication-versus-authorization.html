Lesson 01 · Identity & Password Security

Authentication versus authorization

Who are you versus what can you do? Learn the vital architectural boundary between Authentication (AuthN) and Authorization (AuthZ).

Time ~10 min Win Differentiate between authentication identity checks and authorization permission models Mission link The primary conceptual distinction for all security architectures

1AuthN versus AuthZ

Security architecture is divided into two distinct gates: Authentication (AuthN) answers 'Who are you?'. It verifies proof of identity via passwords, biometric passkeys, or multi-factor codes.

Authorization (AuthZ) answers 'What are you allowed to do?'. Once identity is proven, authorization checks whether that user possesses permission to view a document, delete an order, or access an admin panel.

Key idea Authentication proves who you are; authorization decides what you are allowed to do.

Observe how requests pass through authentication before being evaluated by authorization policies.
