1Semantic Router Utterance Matcher

12ms vector space intent dispatch
from semantic_router import Route, RouteLayer
from semantic_router.encoders import OpenAIEncoder
code_route = Route(name="code", utterances=["fix KeyError", "write python code"])
router = RouteLayer(encoder=OpenAIEncoder(), routes=[code_route])
choice = router("Syntax error in line 42")
if choice.name == 'code': dispatch_to_sonnet()

3Circuit Breaker Failover Logic

Instant failover on degradation
for provider in [primary, backup_1, backup_2]:
    if breaker[provider.id].is_open(): continue
    try:
        return await provider.call(prompt)
    except (RateLimitError, APIConnectionError):
        breaker[provider.id].record_failure()

See Lesson 04 — Provider Fallbacks and Circuit Breakers.

4EWMA Latency Update Calculation

Real-time rolling latency tracker
ALPHA = 0.3
def update_ewma(current_ewma, latest_latency_ms):
    return (ALPHA * latest_latency_ms) + ((1.0 - ALPHA) * current_ewma)
