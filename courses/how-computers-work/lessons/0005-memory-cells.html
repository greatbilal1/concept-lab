Lesson 05 · Logic

Memory cells

Every circuit so far has been forgetful. Feed it inputs, get an output, and the moment the inputs change the past is gone. To compute anything interesting, the machine needs to remember. This lesson builds memory out of gates.

Time ~10 min Win Trace a bit being stored Mission link How state exists at all

1The problem with pure logic

An AND gate has no memory. Give it 1, 1 and it says 1. Change the inputs and the output changes instantly. There is no "before".

But a program needs a before. A counter needs to know what it counted to. A running loop needs to know where it is. So we need a circuit whose output depends on its own past — a circuit with feedback.

Key idea Memory is not a new component. Memory is a gate whose output is wired back into its own input. The circuit holds itself in place.

2The flip-flop

Cross-couple two NAND gates — each one's output feeds the other's input — and you get a flip-flop. It has two stable states, and it will sit in whichever one you put it in, indefinitely, as long as power is on.

The two outputs are always opposites. Call them Q and Q̄. If Q is 1, the cell stores a 1. If Q is 0, it stores a 0. That is one bit of memory, made of two gates.

3Writing and holding

A flip-flop has two jobs: write a value, and hold it. The write happens by briefly pulling one input low; the hold happens by doing nothing at all, letting the feedback loop keep the value alive. 

set   →  Q becomes 1, and stays 1
reset →  Q becomes 0, and stays 0
hold  →  Q keeps whatever it had

Notice that "hold" is the default. The circuit is stable; you only disturb it when you want to change the bit. This is why memory is cheap in energy terms — holding a value costs almost nothing.

The clock If a circuit changes state whenever it likes, coordinating thousands of them is chaos. So we add a clock: a signal that ticks, and gates only update on the tick. The clock is the heartbeat that makes the whole machine synchronous.

4From one bit to a register

One flip-flop stores one bit. Put eight side by side, sharing a clock, and you have a register — a place to hold a byte. Put billions together with addressing logic and you have RAM.

Here is the win. Trace a single bit through a write and a read: 

1. clock low,  data = 1   →  cell still holds old value
2. clock ticks            →  cell latches the 1
3. clock low,  data = 0   →  cell still holds 1  (input ignored)
4. read                   →  Q outputs 1

Step 3 is the whole point. The input changed, and the stored value did not. That is memory.

✓ Your win for today

You can now explain how a circuit remembers something, and you have traced a bit through a write and a read. You have built state out of pure logic — which means the machine can now hold a value between clock ticks, and that is the difference between a calculator and a computer.

6Do this next

  1. Draw two NAND gates with each output feeding the other's input. Label the outputs Q and Q̄ and convince yourself they must always be opposites.
  2. Explain in one sentence why a plain AND gate cannot store a bit. The answer is about feedback, not about gates.
  3. Work out how many flip-flops you need to store the word "cat" in ASCII. Each character is one byte, so count the bits.
