Lesson 02 · Numbers

Hexadecimal

Binary is honest but unreadable. Nobody wants to write 11010110 00111100 when they could write D63C. This lesson is about the notation programmers actually use to talk to machines.

Time ~10 min Win Read a colour code and a memory dump Mission link The notation every later lesson uses

1The problem with long binary

A 32-bit memory address in binary is thirty-two characters of 0 and 1. One transposed digit and you are pointing at the wrong place in memory. Humans are bad at this.

So we need a notation that is compact but still maps cleanly onto bits. Decimal fails: 10 in decimal is 1010 in binary, which does not line up with anything. We need a base that is a power of two.

Key idea Base 16 works because $16 = 2^4$. One hex digit is exactly four bits. That is the entire reason hexadecimal exists.

2Sixteen symbols

Base 16 needs sixteen distinct symbols, but we only have ten digits. So we borrow letters: A through F stand for ten through fifteen.

Four bits — one nibble — maps to exactly one hex digit:

0000 = 0      0100 = 4      1000 = 8      1100 = C
0001 = 1      0101 = 5      1001 = 9      1101 = D
0010 = 2      0110 = 6      1010 = A      1110 = E
0011 = 3      0111 = 7      1011 = B      1111 = F

Learn this table and you never convert hex by arithmetic again. You just read four bits at a time.

3Reading a byte in hex

A byte is eight bits, which is exactly two hex digits. So any byte is written as two characters, and you can convert it by splitting it in half: 

binary:  1101 0110
         ↓    ↓
hex:      D    6      →  D6

That is why hex is everywhere. A memory dump, a colour value, a hash, a network packet — all of them are just bytes, and hex shows you each byte as two tidy characters.

You already use this A CSS colour like #67e8f9 is three bytes: 67 red, e8 green, f9 blue. Each pair is one byte, 0–255. You have been reading hex this whole time without knowing it.

4Negative numbers: two's complement

There is one more thing hex makes visible. How does a machine store -1? It cannot put a minus sign in a bit.

The trick is two's complement: flip every bit, then add one. For an 8-bit number: 

 1  =  0000 0001
flip =  1111 1110
+1   =  1111 1111   =  FF  =  -1

The beautiful consequence: subtraction becomes addition. The CPU does not need a subtract circuit at all — it just adds a negative number. That is a real engineering win, and it is why the trick survived.

✓ Your win for today

You can now convert between binary, hex and decimal in your head, and you can read a colour code or a memory dump without flinching. From here on, every address, every instruction encoding and every byte in this course will be written in hex — and you will be able to read it.

6Do this next

  1. Convert 10110101 to hex. Split it into nibbles first: 1011 then 0101.
  2. Open your browser's developer tools, inspect any element, and find a hex colour. Work out its three bytes and roughly what colour that is.
  3. Work out the 8-bit two's complement of -5. Start from 0000 0101, flip, add one, and write the answer in hex.
