1Pass@1 Benchmark Calculation

First-attempt success rate
resolved = sum(1 for task in results if task.test_exit_code == 0)
pass_at_1 = resolved / len(results)
print(f"Agent Pass@1: {pass_at_1 * 100:.1f}%")

4Trajectory Redundancy Check

Detecting wasted tool calls
# Detect identical consecutive tool calls:
redundant = sum(1 for i in range(1, len(trajectory))
    if trajectory[i].tool == trajectory[i-1].tool and trajectory[i].args == trajectory[i-1].args)
print(f"Redundant Action Rate: {redundant / len(trajectory) * 100:.1f}%")
