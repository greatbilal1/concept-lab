1Complete GitHub Actions CI Workflow

Linting, typing, and testing pipeline
name: CI
on: [pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: "3.12", cache: "pip" }
      - run: pip install -r requirements.txt
      - run: ruff check . && pyright src/ && pytest

See Lesson 02 — GitHub Actions Core Concepts: Workflows, Jobs, and Steps.

2Concurrency Cancel-in-Progress Configuration

Terminating obsolete PR runs
concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

See Lesson 05 — Artifacts, Dependency Caching, and Pipeline Acceleration.

3Cross-Platform Matrix Test Configuration

Multi-OS and multi-version grid
strategy:
  fail-fast: false
  matrix:
    os: [ubuntu-latest, macos-latest, windows-latest]
    python: ["3.11", "3.12"]
runs-on: ${{ matrix.os }}
steps:
  - uses: actions/setup-python@v5
    with: { python-version: ${{ matrix.python }} }

See Lesson 04 — Matrix Builds and Cross-Platform Testing.

4Trivy Security Scanning in GitHub Actions

Failing CI on Critical vulnerabilities
- name: Scan Docker Image for Vulnerabilities
  uses: aquasecurity/trivy-action@master
  with:
    image-ref: 'company/api:${{ github.sha }}'
    exit-code: '1'
    severity: 'CRITICAL,HIGH'
