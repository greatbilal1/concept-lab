1DNS Query Tools

Inspecting domain resolution
dig example.com A             # query A record
dig example.com +trace        # trace recursive resolution from root
dig @8.8.8.8 example.com TXT  # query specific DNS resolver
nslookup example.com          # simple lookup

See Lesson 02 — The DNS resolution hierarchy.

2Core DNS Record Types

Record syntax and usage
A       example.com.      300 IN A     93.184.216.34
AAAA    example.com.      300 IN AAAA  2606:2800:220:1:248:1893:25c8:1946
CNAME   www.example.com.  300 IN CNAME example.com.
MX      example.com.      300 IN MX    10 mail.example.com.
TXT     example.com.      300 IN TXT   "v=spf1 include:_spf.google.com ~all"

See Lesson 03 — Record types: A, CNAME, MX, and TXT.

3TLS Diagnostic Tools

Inspecting certificates and handshakes
# Inspect remote TLS certificate chain
openssl s_client -connect example.com:443 -servername example.com

# View local certificate details
openssl x509 -in cert.pem -text -noout

See Lesson 07 — The TLS handshake step-by-step.

4Security Headers

Enforcing HTTPS
# HTTP Strict Transport Security (HSTS)
Strict-Transport-Security: max-age=63072000; includeSubDomains; preload

See Lesson 08 — HTTPS and browser security indicators.
