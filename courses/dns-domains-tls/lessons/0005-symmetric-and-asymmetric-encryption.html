Lesson 05 · Encryption & Certificates

Symmetric and asymmetric encryption

How do two strangers on the internet create a secret conversation in plain sight of eavesdroppers? Discover the mathematics of public and private keys.

Time ~10 min Win Explain the complementary roles of asymmetric key exchange and symmetric bulk ciphers Mission link The cryptographic cornerstone of all internet security and privacy

1The problem of key exchange

If Alice and Bob want to send secret messages, they can use symmetric encryption (like AES-256): the same secret key encrypts and decrypts the data. It is blazing fast and mathematically unbreakable.

But how do Alice and Bob agree on the secret key if Eve is eavesdropping on the network cable? Sending the key in plaintext destroys security. This is the central problem solved by asymmetric cryptography.

Key idea Symmetric encryption is fast but requires a shared key; asymmetric encryption solves key sharing.

2The hybrid encryption model

Modern systems use hybrid encryption: asymmetric cryptography negotiates a session key, which symmetric ciphers use to encrypt bulk data.

3Tracing the Diffie-Hellman key exchange

Trace how Diffie-Hellman calculates a shared secret over a public wire without ever transmitting the secret.

4Practice

Test your memory of cryptographic primitives.

✓ Your win for today

You can articulate how hybrid cryptosystems combine asymmetric key exchange with symmetric ciphers to protect web communications.

5Do this next

  1. Generate an asymmetric RSA or Ed25519 key pair using ssh-keygen.
  2. Inspect the public key (.pub) and verify it can be shared openly.
  3. Explain why your private key must never leave your machine.
