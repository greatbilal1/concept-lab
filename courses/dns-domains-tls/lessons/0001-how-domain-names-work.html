Lesson 01 · Domain Names & Resolution

How domain names work

Computers talk in numbers; humans think in words. Discover the distributed tree hierarchy that turns human names into network coordinates.

Time ~10 min Win Explain the domain name tree structure from root dot to top-level domains Mission link The starting point for understanding all internet identity

1The inverted tree of names

A domain name like blog.example.com is not a flat string. It is a hierarchical path read from right to left, rooted at an invisible trailing dot: blog.example.com.

At the top sits the Root Zone (.), managed by ICANN. Below the root are Top-Level Domains (TLDs) like .com, .org, and country codes like .uk. Below TLDs are Second-Level Domains (SLDs) like example, followed by subdomains like blog.

Key idea Domain names are hierarchical trees read from right to left, starting at the root dot.

Observe the administrative levels that divide authority across the global domain name tree.
