Functions & Modular Thinking Cheat Sheet

The facts you will reach for every day, compressed. Print this, or keep it open beside your editor. Every snippet is runnable Python 3.

1Defining

See Lesson 01 — Naming a block of work

A definition gives a block of work a name
def greet():
    print("Hello")

# def creates the function; it does not run it
# the body runs only when the function is called

2Calling

See Lesson 02 — Calling a function

A call runs the body, then comes back
def greet():
    print("Hello")

greet()      # runs the body once
greet()      # runs it again — a call is repeatable

# the call site is where the name is used with ()

3Parameters

See Lesson 03 — Parameters and arguments

One body, many values
def greet(name, greeting):
    print(greeting + ", " + name)

greet("Ada", "Hello")            # positional
greet(greeting="Hi", name="Ada") # keyword

# parameter = the name in the def
# argument  = the value in the call

4Defaults

See Lesson 04 — Default values

Optional parameters — and the mutable trap
def greet(name, greeting="Hello"):
    print(greeting + ", " + name)

greet("Ada")            # Hello, Ada
greet("Ada", "Hi")      # Hi, Ada

# required parameters must come first
# NEVER default to a list, dict or set:
def add(item, basket=None):   # the safe pattern
    if basket is None:
        basket = []
    basket.append(item)
    return basket

5Return

See Lesson 05 — Returning a value

Hand a value back to the call
def add(a, b):
    return a + b

total = add(2, 3)        # total is 5
print(add(2, 3) * 10)    # 50 — the result is usable

# return also stops the function immediately
# print shows a value; return hands it to the program

6None

See Lesson 06 — Multiple returns and None

Several exits, and the implicit None
def sign(n):
    if n > 0: return "positive"
    if n < 0: return "negative"
    return "zero"        # every path should return

def show(x):
    print(x)             # no return

show(5)                  # prints 5
print(show(5))           # None — the implicit return

7Call stack

See Lesson 07 — The call stack

Paused calls, and reading a traceback
def double(n): return n * 2
def quad(n):   return double(double(n))

quad(3)   # stack:  > quad > double > double

# Traceback (most recent call last):
#   File "app.py", line 8, in <module>
#   File "app.py", line 5, in quad
#   File "app.py", line 2, in double
# TypeError: ...
# read it bottom-up — the last frame is the failure

8Scope

See Lesson 08 — Scope: local and global

Local names, global names, shadowing
count = 0            # global

def bump():
    count = 1        # local — shadows the global
    print(count)     # 1

bump()
print(count)         # 0 — the global is untouched

# an assignment anywhere makes the name local
# everywhere in that body → UnboundLocalError
# prefer passing in and returning out over global

9Contracts

See Lesson 09 — Contracts: docstrings and hints

Docstring and type hints
def area(width: float, height: float) -> float:
    """Return the area of a rectangle.

    width and height are positive numbers in metres.
    """
    return width * height

# docstring = what it does, in words
# hints     = expected types in and out
# hints are not enforced at runtime

10Splitting

See Lesson 10 — Splitting a program

One job per function
def average(numbers):
    """Return the mean of a list of numbers."""
    return sum(numbers) / len(numbers)

def result(avg):
    """Return 'pass' or 'fail' for an average."""
    return "pass" if avg >= 70 else "fail"

def report(scores):
    """Print a report for a list of scores."""
    avg = average(scores)
    print("Scores:", scores)
    print("Average:", avg)
    print("Result:", result(avg))

report([88, 92, 79, 95, 61])

# split by job, not by line count
# if you cannot describe it without "and", split it
