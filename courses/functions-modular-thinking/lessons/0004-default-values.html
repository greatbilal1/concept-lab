Default values

Most of the time a caller wants the usual behaviour, and only sometimes wants to change it. A default value lets a parameter be optional — and hides one of the nastiest traps in Python.

Time ~10 min Win Write a function with an optional parameter Mission link Make the common case easy

1Make a parameter optional

A default value is written in the definition with an equals sign. If the caller supplies that argument, the default is ignored; if they leave it out, the default is used. 

def greet(name, greeting="Hello"):
    print(greeting + ", " + name)

greet("Ada")                 # Hello, Ada
greet("Ada", "Good morning") # Good morning, Ada

The common case — a plain hello — needs no second argument. The unusual case still works. That is the whole point of a default: it makes the frequent call short without removing the option.

2Order matters

A parameter with a default must come after every parameter without one. Python needs to know which arguments are required before it can match the optional ones. 

def greet(greeting="Hello", name):   # SyntaxError
    ...

def greet(name, greeting="Hello"):   # fine
    ...

Read the rule as: required first, optional last. It matches how you read a call — the values you must give come first.

3The mutable default trap

Here is the trap. A default value is evaluated once, when the definition runs — not on every call. If that default is a mutable object like a list, every call shares the same list. 

def add_item(item, basket=[]):   # the trap
    basket.append(item)
    return basket

add_item("apple")   # ['apple']
add_item("pear")    # ['apple', 'pear']  — not ['pear']!

The second call did not start with an empty basket. It started with the basket the first call left behind, because there is only one basket. The fix is to use None as the default and build a fresh list inside the body. 

def add_item(item, basket=None):
    if basket is None:
        basket = []
    basket.append(item)
    return basket
Watch out Never use a list, dict or set as a default value. Use None and create the object inside the body. The default is created once; the body runs every call.

✓ Your win for today

You can now make a parameter optional, and you know the one rule that keeps defaults safe: they are created once, so they must never be mutable. That rule will save you from a bug that is famously hard to find, because the function looks completely innocent.
