Lesson 01 · Defining

Naming a block of work

A function is the smallest unit of reuse in a program: a block of code with a name. This lesson is about the def line — how you give a piece of work a name, and why that name is the most valuable thing you will write today.

Time ~10 min Win Define a function and call it twice Mission link Give work a name

1Work without a name

You already know how to make a program repeat work: a loop. But a loop repeats work in one place. If you need the same three lines in two different parts of a program, a loop cannot help — you copy the lines. 

# the same greeting, twice, copied
print("Hello, Ada")
print("Welcome aboard")

# ... forty lines later ...

print("Hello, Grace")
print("Welcome aboard")

The two blocks are identical except for one name. That is the smell. The work has no name, so you cannot refer to it — you can only repeat it.

2Give it a name

A function is a named block of code. You write def, a name, a pair of parentheses, a colon, and then an indented body — exactly the shape of an if or a while, but with a name instead of a condition. 

def greet():
    print("Hello, Ada")
    print("Welcome aboard")

That is a definition. It does not print anything yet. It only says: the name greet now refers to this block of work. To actually run it, you call it by writing its name and parentheses. 

greet()
greet()

Two calls, two greetings. The body was written once and run twice. That is the whole idea, and everything else in this course is a refinement of it.

Key idea A definition names work; a call does work. Writing def greet(): runs nothing. Only greet() runs the body.

3The name is the point

The value of a function is not that it saves typing — it is that it gives the work a name you can think with. Once the block is called greet, the rest of the program can say greet() and mean "do the greeting", without caring how the greeting is done.

This is the first real act of abstraction in programming: hiding the details behind a name. You will do it again and again, at larger and larger scales, for the rest of your career.
