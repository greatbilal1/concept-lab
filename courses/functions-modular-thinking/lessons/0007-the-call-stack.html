Lesson 07 · Scope & the stack

The call stack

When one function calls another, the first is not finished — it is paused, waiting. The call stack is the record of all those paused calls, and reading it is how you find the line that actually failed.

Time ~10 min Win Read a traceback to the failing line Mission link Find the real bug

1Functions calling functions

A function body can call another function. When it does, the first call is not over — it is suspended at the call line, waiting for the inner call to finish. 

def double(n):
    return n * 2

def quadruple(n):
    return double(double(n))

print(quadruple(3))   # 12

To compute quadruple(3), Python calls double(3), gets 6, then calls double(6), gets 12, and finally returns. At the deepest moment, three calls are alive at once.

2The stack of frames

Each active call gets a frame: a record of its parameters, its local names, and the line it is currently on. The frames stack up, newest on top, and each return pops one off.

The call stack is that stack. The top frame is the call running right now; the frames below it are the calls waiting for it to finish. When the top frame returns, the one below resumes exactly where it left off.

3Reading a traceback

When an error escapes a function, Python prints a traceback: the stack of frames from the outermost call down to the line that failed. Read it bottom-up — the last line is where the error actually happened. 

Traceback (most recent call last):
  File "app.py", line 8, in <module>
    print(quadruple(3))
  File "app.py", line 5, in quadruple
    return double(double(n))
  File "app.py", line 2, in double
    return n * 2
TypeError: unsupported operand type(s) for *: 'str' and 'int'

The bottom frame is the real failure: n * 2 inside double. The frames above it are the path that got there. This is the single most useful debugging skill in Python.

Key idea The call stack is the list of calls that are still running. A traceback is that list printed at the moment of an error — read it bottom-up to find the failing line.
