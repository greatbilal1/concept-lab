Parameters and arguments

A function with no inputs can only ever do one thing. The moment you add a parameter, the same body can do its work on any value you hand it. This lesson is about the two ends of that hand-off.

Time ~10 min Win Write a function that greets any name Mission link Make work reusable

1One body, many values

In Lesson 01 the greeting was hard-coded: print("Hello, Ada"). To greet Grace you had to copy the function. The fix is to leave a hole in the body and fill it at the call. 

def greet(name):
    print("Hello, " + name)

greet("Ada")
greet("Grace")

One definition, two different greetings. The hole is called a parameter; the value you drop into it is called an argument.

2Parameter vs argument

These two words are used loosely in conversation, but they name two different things, and the distinction is worth keeping:

The parameter is the name in the definition — name. The argument is the value at the call — "Ada". At the moment of the call, Python binds the argument to the parameter, and the body runs with that binding in place.

3Position and name

When a function has more than one parameter, you can supply the arguments in two ways. Positional arguments are matched left to right. Keyword arguments are matched by name, so order does not matter. 

def describe(name, age):
    print(name, "is", age)

describe("Ada", 36)          # positional
describe(age=36, name="Ada") # keyword — same result

Keyword arguments are clearer at the call site, especially when a function takes several values of the same type. Use them when the meaning of an argument is not obvious from its position.

Key idea A parameter is a name in the definition; an argument is a value at the call. The call binds one to the other, and the body runs with that binding.

✓ Your win for today

You have turned a one-trick function into a reusable one: the same body now works on any value you pass. That is the difference between a function that does a thing and a function that does a kind of thing — and it is what makes a function worth naming.
