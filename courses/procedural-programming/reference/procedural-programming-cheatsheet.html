Procedural Programming Cheat Sheet

The facts you will reach for every day, compressed. Print this, or keep it open beside your editor. Every snippet is runnable Python 3.

1Sequence

See Lesson 01 — A program is a sequence

Top-level code runs top to bottom
print("first")
print("second")
print("third")

# a program is a sequence of steps, run in order

2Defining

See Lesson 02 — Naming a step

def, name, parentheses, body
def print_banner():
    """Print a boxed title above a report."""
    print("=" * 20)
    print("  REPORT  ")
    print("=" * 20)

print_banner()   # call it by name

# PEP 8: lowercase_with_underscores for names

3Parameters

See Lesson 03 — Passing data in

Positional, default, keyword
def greet(name, greeting="Hello"):
    print(greeting + ", " + name)

greet("Ada")                  # Hello, Ada
greet("Ada", "Hi")            # Hi, Ada
greet("Ada", greeting="Hey")  # Hey, Ada

# positional arguments match left to right

4Return

See Lesson 04 — Getting data out

Hand a value back, and exit early
def add(a, b):
    return a + b

total = add(2, 3)   # 5

def show(a, b):
    print(a + b)

show(2, 3)          # prints 5
print(show(2, 3))   # None — no return

def safe_divide(a, b):
    if b == 0:
        return None   # leave early
    return a / b

5One job

See Lesson 05 — One job per procedure

Split a do-everything procedure
# before — three jobs, one name
def process():
    prices = [4, 8, 15]
    total = 0
    for p in prices:
        total = total + p
    print("Total:", total)

# after — one job each
def load_prices():
    return [4, 8, 15]

def total(prices):
    result = 0
    for p in prices:
        result = result + p
    return result

def print_report(total):
    print("Total:", total)

print_report(total(load_prices()))

6Globals

See Lesson 06 — Shared state and globals

Pass it in, return it out
# avoid — hidden dependency
total = 0
def add_price(price):
    global total
    total = total + price

# prefer — explicit data contract
def add_price(total, price):
    return total + price

total = 0
total = add_price(total, 4)
total = add_price(total, 8)   # 12

7Modules

See Lesson 07 — Grouping steps into a module

A file is a module; the guard separates run from import
# prices.py
def load():
    return [4, 8, 15]

def total(prices):
    result = 0
    for p in prices:
        result = result + p
    return result

if __name__ == "__main__":
    print(total(load()))   # runs only when run directly

8Imports

See Lesson 08 — Importing and reusing

Two forms, and an alias
import prices                 # prices.total(...)
from prices import total      # total(...)
import prices as pr           # pr.total(...)

# module-prefixed form keeps the origin visible
data = prices.load()
print(prices.total(data))

# circular imports: two modules importing each other
# fix by moving the shared procedure into a third module

9Program shape

See Lesson 10 — Putting it together

A short entry point, a pipeline of steps
def load_prices():
    return [4, 8, 15]

def total(prices):
    result = 0
    for p in prices:
        result = result + p
    return result

def print_report(total):
    print("Total:", total)

def main():
    print_report(total(load_prices()))

if __name__ == "__main__":
    main()

10Limits

See Lesson 09 — Where procedural breaks down

The signs of strain
# data clump — values that always travel together
def send_welcome(name, email, plan): ...
def send_invoice(name, email, plan): ...

# coupling — procedures that know each other's shape
def load_user():
    return {"name": "Ada", "plan": "pro"}

def send_invoice(user):
    print(user["name"], user["plan"])   # must match exactly

# the procedural limit: data and its behaviour live apart
# the next course, OOP, ties them together
