Lesson 06 · Structure

Shared state and globals

Once a program has several procedures, they need to share data. The easy way is a global variable — and it is also the way that quietly breaks the promise each procedure made in Lesson 05.

Time ~10 min Win Replace a global with a parameter and a return Mission link Reduce reliance on globals

1What a global is

A global variable is a variable defined at the top level of the file, outside any procedure. Every procedure in the file can read it, and with the global statement, write it too. 

total = 0

def add_price(price):
    global total
    total = total + price

add_price(4)
add_price(8)
print(total)   # 12

It works, and it is short. But look at add_price: its name says it adds a price, yet it also changes something outside itself. That is a hidden effect, and it is the problem.

2Why globals hurt

A procedure that reads or writes a global is no longer a self-contained step. To understand it, you must also read the top of the file. To test it, you must set up the global first. And two procedures that share a global are now coupled through it. 

# to understand add_price, you must also read this
total = 0

def add_price(price):
    global total
    total = total + price

This is a hidden dependency: the procedure depends on something that is not in its parameter list. The dependency is real, but it is invisible at the call site.

Watch out A global makes a procedure's behaviour depend on the order of calls. Call add_price twice and you get a different answer than calling it once — even though the argument is the same.

3Pass it in, return it out

The fix is the data contract from Lessons 03 and 04: pass the state in as a parameter, and return the new state. Now the procedure is honest about what it needs and what it produces. 

def add_price(total, price):
    return total + price

total = 0
total = add_price(total, 4)
total = add_price(total, 8)
print(total)   # 12

The procedure no longer touches anything outside itself. Its name, its parameters, and its return value tell the whole story. The state still exists — it is just passed explicitly instead of hidden.
