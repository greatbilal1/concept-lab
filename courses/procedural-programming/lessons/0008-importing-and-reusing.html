Lesson 08 · Modules

Importing and reusing

A module is only useful if another file can use it. import is how one file reaches into another — and how the same procedure gets reused across a whole program instead of being copied.

Time ~10 min Win Import a module and call its procedures Mission link Reuse steps across files

1import brings a module in

import prices makes the whole module available under its name. You then reach its procedures through the module name, which keeps the origin of each call visible. 

# main.py
import prices

data = prices.load()
print(prices.total(data))

prices.total says exactly where total came from. That clarity is the reason to prefer this form over pulling names in directly.

2from ... import, and aliases

from prices import total brings one name in directly, so you call total(data) without the module prefix. An alias renames the module on import, which is handy for long names. 

from prices import total
import prices as pr

print(total([4, 8, 15]))     # 27
print(pr.load())             # [4, 8, 15]

Both forms work. The trade-off is clarity: from ... import is shorter, but it hides where the name came from. When two modules define the same name, that hiding causes real confusion.

Watch out from prices import total copies the name into your file. If two modules both export total, the second import silently wins. The module-prefixed form avoids this entirely.

3Circular imports

A circular import happens when two modules import each other. Python starts loading one, hits the import of the other, which imports the first again before it has finished — and the name is not there yet. 

# a.py
import b
def use_b():
    return b.helper()

# b.py
import a          # circular!
def helper():
    return a.use_b()

The fix is almost always structural: the two modules are too tangled. Move the shared procedure into a third module that both can import, so the dependency points one way.

✓ Your win for today

You can import a module and reuse its procedures from another file, and you know the trade-off between the two import forms. That is how a program grows past one file without copying code. The next lesson is about where this whole style starts to strain.
