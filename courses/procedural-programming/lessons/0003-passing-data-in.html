Lesson 03 · Data

Passing data in

A step with no data is a step that always does the same thing. Parameters are how you hand a procedure the values it needs, so one procedure can work on many inputs instead of one.

Time ~10 min Win Write a procedure that takes a parameter Mission link Pass data into a procedure

1Parameters and arguments

A parameter is a name in the definition. An argument is the value you pass at the call. The argument fills the parameter, and the body sees it as an ordinary variable. 

def greet(name):
    print("Hello, " + name)

greet("Ada")     # name is "Ada"
greet("Grace")   # name is "Grace"

One procedure, two different outputs. The parameter name is a placeholder; each call supplies a real value. This is what makes a procedure reusable instead of a one-off.

2More than one parameter

A procedure can take several parameters, separated by commas. The arguments are matched to them by position, left to right. 

def describe(name, age):
    print(name + " is " + str(age))

describe("Ada", 36)   # name="Ada", age=36

Order matters. describe(36, "Ada") would set name to 36 and age to "Ada" — the values are matched by position, not by meaning.

Watch out Positional arguments are matched left to right. If two parameters have the same type, swapping the arguments will not raise an error — it will just give the wrong answer.

3Defaults and keywords

A parameter can have a default value, used when the caller does not supply that argument. And an argument can be passed by name, so its position no longer matters. 

def greet(name, greeting="Hello"):
    print(greeting + ", " + name)

greet("Ada")                  # Hello, Ada
greet("Ada", "Hi")            # Hi, Ada
greet("Ada", greeting="Hey")  # Hey, Ada

Defaults make a parameter optional; keyword arguments make a call readable. Both are ways of saying "this value is data the caller supplies", which is the whole point of parameters.
