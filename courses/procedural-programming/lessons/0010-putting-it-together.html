Putting it together

You have all the pieces: named steps, data in and out, one job each, no hidden state, grouped into modules. This lesson is about the shape they make when you put them together — and how to read a program at a glance.

Time ~10 min Win Read a whole program as a pipeline of steps Mission link See the shape of a program

1Program shape

A well-built procedural program has a recognisable shape: a short entry point at the bottom that reads like a sentence, and a set of named steps above it that each do one job. 

def load_prices():
    return [4, 8, 15]

def total(prices):
    result = 0
    for p in prices:
        result = result + p
    return result

def print_report(total):
    print("Total:", total)

if __name__ == "__main__":
    print_report(total(load_prices()))

The entry point is one line. Everything above it is a named step you can read on its own. That is the shape: a pipeline at the bottom, a toolbox above it.

2Entry point and helpers

The entry point is where the program starts — the main guard, or a main() procedure it calls. The helper functions are the named steps it uses. Keeping the entry point short is what makes the shape readable. 

def main():
    print_report(total(load_prices()))

if __name__ == "__main__":
    main()

main() is a helper like any other: one job, a clear name, no hidden state. The only thing special about it is that the main guard calls it.

Key idea Read the entry point first. If you can follow it without opening any helper, the program's shape is good.

3A pipeline of steps

When each step takes the previous step's output, the program becomes a pipeline: data flows in one end and a result comes out the other. Each stage is a named procedure, and each stage can be tested on its own. 

prices  = load_prices()      # stage 1: get the data
summed  = total(prices)      # stage 2: compute
report  = format_report(summed)  # stage 3: shape it
print(report)                # stage 4: show it

This is the same data contract from Lessons 03 and 04, repeated. Pass in, return out, pass in, return out. A pipeline is just that contract applied in a line.
