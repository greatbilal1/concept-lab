Lesson 07 · Modules

Grouping steps into a module

A file full of procedures is already a module. This lesson is about making that grouping deliberate: related steps together, a clear namespace, and a main guard so the file can be both run and imported.

Time ~10 min Win Move related procedures into their own file Mission link Group steps into modules

1A file is a module

In Python, every .py file is a module. Its name is the file name without the extension. The procedures inside it live in that module's namespace, which is why two modules can both define total without clashing. 

# prices.py
def load():
    return [4, 8, 15]

def total(prices):
    result = 0
    for p in prices:
        result = result + p
    return result

Grouping by job is the point. prices.py holds everything about prices; a reader looking for price logic knows exactly which file to open.

2The main guard

A module can be run directly and imported. The main guard is how you tell the two apart: code inside it runs only when the file is run directly, not when it is imported. 

# prices.py
def load():
    return [4, 8, 15]

if __name__ == "__main__":
    print(load())

When you run python prices.py, __name__ is "__main__" and the print runs. When another file imports prices, __name__ is "prices" and the print is skipped. That is the whole trick.

Key idea The main guard separates "what this module provides" from "what happens when you run it". Importing a module should never have side effects.

3What belongs in a module

A good module groups procedures that change together and are used together. If two procedures always appear in the same places, they probably belong in the same file. If a procedure is used everywhere, it may belong in a shared module. 

# prices.py — everything about prices
def load(): ...
def total(prices): ...
def average(prices): ...

# report.py — everything about printing
def header(): ...
def row(label, value): ...
def footer(): ...

The test is the same as Lesson 05, one level up: can you name the module in a few words, and does everything in it serve that name?
