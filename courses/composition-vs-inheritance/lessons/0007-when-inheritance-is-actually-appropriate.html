Lesson 07 · LSP & Legitimate Inheritance

When inheritance is actually appropriate

Inheritance isn't evil; misapplied inheritance is evil. Discover the rare, legitimate use cases for class inheritance: Framework base classes, Template Method, and AST nodes.

Time ~10 min Win Identify the specific architectural scenarios where inheritance is genuinely superior to composition Mission link Prevents dogmatic over-correction into 'anti-inheritance' extremes

1The legitimate realm of inheritance

'Favor composition over inheritance' does not mean 'never use inheritance'. Inheritance is an extraordinarily powerful language feature when applied correctly.

When is inheritance appropriate? 1. True 'is-a' relationships that are immutable: an AST BinaryExpression is genuinely an AST Node. 2. Framework base classes: React's Component or Django's View. 3. The Template Method pattern: where an abstract algorithm skeleton is fixed, and subclasses fill in specific steps.

Key idea Inheritance shines in framework hooks, immutable syntax tree nodes, and the Template Method pattern.
