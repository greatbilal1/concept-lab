Lesson 03 · The Fragile Base Class Problem

The Deadly Diamond of Death

What happens when Class D inherits from both Class B and Class C, which both inherit from Class A? Discover the Deadly Diamond of multiple inheritance and Method Resolution Order.

Time ~10 min Win Explain the multiple inheritance Diamond Problem and Python's C3 Method Resolution Order Mission link Explains why most modern programming languages forbid multiple class inheritance

1The ambiguity of the diamond

In languages that support multiple class inheritance (like C++ or Python), a classic architectural trap emerges: The Deadly Diamond of Death.

Class A defines a method save(). Class B and Class C both inherit from A and both override save() with different logic. Now, Class D inherits from both B and C. When you call d.save(), which version executes? B's or C's? The ambiguity creates chaos.

Key idea The Diamond Problem creates method ambiguity when multiple parent classes inherit from a common ancestor.
