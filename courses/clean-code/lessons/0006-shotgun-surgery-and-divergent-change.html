Lesson 06 · Recognizing Code Smells

Shotgun surgery and divergent change

One change, twenty files. Master the twin architectural smells: Shotgun Surgery (one change forces edits across many files) and Divergent Change (one file changes for many reasons).

Time ~10 min Win Differentiate Shotgun Surgery from Divergent Change and consolidate fragmented responsibilities Mission link Prevents high coupling and fragmented domain logic across backend modules

1The twin coupling smells

Two classic smells represent opposite sides of the same coupling coin: Divergent Change happens when one file suffers many different kinds of edits. You edit User.py when database schemas change, when HTTP JSON formatting changes, AND when tax calculation rules change.

Shotgun Surgery is the opposite: one single business change forces you to make tiny edits across twenty different files! Add a new user role, and you must edit the controller, the database model, the view template, the permission check, and the billing service.

Key idea Divergent Change: one class has many reasons to change. Shotgun Surgery: one change touches many classes.
