Lesson 05 · Recognizing Code Smells

Classic code smells and heuristics

Code doesn't stink; it smells. Learn Martin Fowler's classic code smells: Long Method, Large Class, Primitive Obsession, Feature Envy, and Data Clumps.

Time ~10 min Win Detect classic code smells in code reviews and identify the refactorings that fix them Mission link The diagnostic vocabulary for identifying architectural rot before bugs appear

1Smells are symptoms, not bugs

Kent Beck coined the term Code Smell: a surface indication that usually corresponds to a deeper problem in the system. A code smell is not an error (the code still runs and passes tests), but it indicates an architectural weakness that will slow down development or breed future bugs.

Learning to recognize smells gives your team a shared diagnostic vocabulary: Feature Envy (a class calling methods on another object more than its own), Data Clumps (three variables that always travel together), and Primitive Obsession.

Key idea A code smell is a surface symptom that signals underlying architectural rot.
