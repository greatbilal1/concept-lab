Lesson 01 · Meaningful Names & Simplicity

Meaningful names and intention

You read names hundreds of times a day. Learn how intention-revealing, pronounceable, and searchable names make code self-documenting without comments.

Time ~10 min Win Select intention-revealing names that eliminate the need for explanatory comments Mission link The single highest-leverage readability improvement you can make to any codebase

1Names reveal intent

Choosing good names takes time, but it saves vastly more time than it costs. A name should tell you why it exists, what it does, and how it is used. If a variable requires a comment to explain what it holds, the name has failed.

Avoid cryptic abbreviations (hp vs hit_points), avoid mental mappings (using i, j, k for nested domain data), and replace Magic Numbers with named constants: const MAX_LOGIN_ATTEMPTS = 5;.

Key idea If a variable or function requires a comment to explain what it is, its name has failed.
