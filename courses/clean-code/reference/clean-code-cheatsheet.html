1Intention-Revealing Naming

Pronounceable, searchable, explicit
// BAD: Cryptic abbreviations and mental mapping
const d = 86400; // time?
const fn = u.n.split(' ')[0];

// GOOD: Explicit intent and units
const SECONDS_PER_DAY = 86400;
const firstName = user.fullName.split(' ')[0];

See Lesson 01 — Meaningful names and intention.

2Guard Clauses & Flattening

Eliminating arrow anti-patterns
// BAD: Nested pyramid of doom
if (user) {
  if (user.isActive) {
    if (user.hasPermission) {
      proceed();
    }
  }
}

// GOOD: Guard clauses (return early)
if (!user || !user.isActive || !user.hasPermission) return;
proceed();

See Lesson 03 — Guard clauses and reducing nesting.

3Classic Code Smells

Diagnostic indicators of architectural debt
1. Long Method: Functions > 25 lines doing multiple things
2. Primitive Obsession: Using strings for currencies/zipcodes
3. Feature Envy: A function calls methods on another class more than its own
4. Shotgun Surgery: One change forces tiny edits across 10 different files

See Lesson 05 — Classic code smells and heuristics.

4The Boy Scout Rule

Continuous micro-refactoring
// Always leave the code cleaner than you found it.
// Don't wait for a dedicated "refactoring sprint".
// On every ticket:
// - Rename 1 confusing variable
// - Extract 1 small helper function
// - Delete 1 block of commented-out dead code

See Lesson 08 — The Boy Scout rule and continuous refactoring.
