High Performance: SIMD & Web Workers

Unlock the full power of modern CPU silicon: process 4 or 8 numbers simultaneously with SIMD and run parallel threads with Web Workers.

Time ~10 min Win Leverage WebAssembly SIMD vectorization and multithread with Web Workers and SharedArrayBuffer Mission link Achieve maximum floating-point and media throughput on modern multi-core devices

1SIMD: Single Instruction, Multiple Data

Standard CPU instructions process one number at a time (Scalar arithmetic). Modern CPU hardware (Intel SSE/AVX, ARM NEON) features vector registers (128-bit) that can perform arithmetic across multiple values in a single hardware cycle.

WebAssembly Fixed-width SIMD introduces the v128 type. A single i32x4.add instruction adds four 32-bit integers simultaneously, delivering immediate 2x to 8x speedups for image filters, matrix math, physics, and machine learning.

Key idea Fixed-width SIMD (v128) processes four 32-bit floats or integers in a single CPU cycle.

2Multithreading with Web Workers and SharedArrayBuffer

By default, WebAssembly runs on the browser's main thread. If you run a 5-second computation, the UI freezes.

To achieve true parallel multithreading, you spawn Web Workers and share a single WebAssembly.Memory instance backed by a SharedArrayBuffer. Multiple worker threads execute compiled Wasm code across different CPU cores while sharing the same memory space, using atomic instructions (i32.atomic.rmw.add) to prevent race conditions.
