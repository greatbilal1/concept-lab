Lesson 05 · Compiling Systems Languages (Rust/C)

Compiling Rust & C to Wasm

Nobody writes raw WAT by hand for large applications. Learn how modern toolchains compile Rust and C/C++ to WebAssembly.

Time ~10 min Win Compile C/C++ using Emscripten and Rust using wasm-pack and wasm-bindgen Mission link Port existing mature C/Rust libraries (FFmpeg, SQLite, OpenCV) directly to the web browser

1The two compilation giants: C/C++ vs Rust

WebAssembly was born to bring high-performance systems code to the web. Two ecosystems lead the industry:

  • C / C++ (Emscripten): Uses emcc to compile massive legacy codebases (AutoCAD, Unreal Engine, SQLite, FFmpeg) to Wasm. Emscripten provides a virtual POSIX layer, translating OpenGL to WebGL and files to an in-memory virtual filesystem (MEMFS).
  • Rust (wasm-pack): The modern darling of Wasm development. Rust's zero-cost abstractions, lack of garbage collection, and safety guarantees align perfectly with Wasm. Tools like wasm-bindgen generate seamless JavaScript glue code automatically.
Key idea Emscripten ports legacy C/C++ projects with POSIX simulation; Rust produces lean, modern, type-safe Wasm packages.

2The role of wasm-bindgen

Because Wasm only understands numbers, passing a JavaScript string "Hello" into Rust requires allocating memory, copying UTF-8 bytes, and passing a pointer. Doing this manually is tedious and error-prone.

wasm-bindgen automates this entirely: annotating a Rust function with #[wasm_bindgen] generates JavaScript glue code that serializes strings, objects, and arrays across the boundary invisibly.
