Lesson 02 · Wasm Architecture & Stack VM

WAT & The Stack Machine

WebAssembly is binary, but it has a human-readable counterpart: WAT. Learn how stack operations push and pop operands.

Time ~10 min Win Read and write WebAssembly Text format (WAT) and understand stack-based bytecode evaluation Mission link Understand the raw execution model underpinning every compiled Wasm module

1The stack machine paradigm

Most modern hardware CPUs are register-based (they operate on named registers like RAX, RBX). WebAssembly is designed as a stack machine because stack bytecode is compact, fast to transmit, and easy to validate.

In a stack machine, instructions push numbers onto an evaluation stack, operations pop their arguments from the stack, compute the result, and push the result back onto the stack.

Key idea A stack machine pushes values onto an evaluation stack and pops them to compute results.

2WebAssembly Text format (WAT)

Because binary .wasm files are unreadable by humans, the W3C defined WAT (WebAssembly Text Format) using Lisp-style S-expressions (parentheses). The wat2wasm tool from the WABT toolkit compiles WAT text into binary Wasm.
