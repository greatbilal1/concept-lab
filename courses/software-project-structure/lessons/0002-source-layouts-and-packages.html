Source layouts and packages

Flat layout versus src-layout: why nesting your code under src/ protects you from accidental import bugs and broken packaging.

Time ~10 min Win Implement a robust src-layout package structure for modern applications Mission link Prevents insidious import masking and packaging failures

1The problem with flat layouts

In a flat layout, your package directory sits directly in the project root alongside setup.py or package.json. When you run tests from the root, the interpreter imports your local uninstalled source files directly from the working directory.

This causes bugs that pass locally but fail in production: you test against raw local files, not the packaged and installed artifact. The src-layout forces tests to import the properly installed package.

Key idea The src-layout guarantees that tests execute against the installed package rather than local working directory files.
