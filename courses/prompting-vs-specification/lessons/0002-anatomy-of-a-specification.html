Anatomy of a Software Specification

Structuring an engineering specification: Context, Functional Requirements, Invariants, and Verification Gates.

Time ~10 min Win You know how to author structured, unambiguous specifications for AI agents. Mission link Mastering anatomy of a software specification across modern software engineering

1Core principles of Anatomy of a Software Specification

A technical specification for an AI agent is not an essay; it is a structured contract. When an agent receives a well-structured spec, it can parse requirements systematically and evaluate its own progress.

Key idea Structuring an engineering specification: Context, Functional Requirements, Invariants, and Verification Gates.

2Four Pillars of an Agent Spec

A comprehensive agent-ready specification contains four essential sections:

3Constraint Boundary Wall

  • 1. Goal & Context: Why this change is needed and how it fits into the surrounding architecture.
  • 2. Functional Requirements: What the software must do, expressed as inputs, outputs, schemas, and state changes.
  • 3. Constraints & Non-Goals: What the agent must not do (e.g. 'Do NOT modify database migration 0014', 'Do NOT introduce third-party npm packages').
  • 4. Verification Criteria: The exact commands the agent must run to verify success (e.g. `pytest tests/test_orders.py`).
# Specification: Add User Avatar Upload

## 1. Goal
Allow authenticated users to upload PNG/JPEG avatars up to 2MB.

## 2. Requirements
- Endpoint: POST /api/v1/users/me/avatar (multipart/form-data)
- Storage: Save to local directory 'uploads/avatars/'
- DB: Update User.avatar_url with the relative path

## 3. Constraints & Non-Goals
- Do NOT use AWS S3 (local filesystem storage only for this ticket).
- Reject files > 2MB with HTTP 413 Payload Too Large.
- Do NOT alter existing User authentication middleware.

## 4. Verification
- Run `pytest tests/test_avatar.py` (all tests must pass with 0 warnings).

Power of Non-Goals: Stating what NOT to do is often more impactful than stating what to do. It prevents agent scope creep.
