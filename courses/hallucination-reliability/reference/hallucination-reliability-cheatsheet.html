1NLI Hallucination Verification Pattern

DeBERTa entailment check
from transformers import pipeline
nli = pipeline("text-classification", model="cross-encoder/nli-deberta-v3-base")
# Check if source text entails the generated claim:
res = nli({"text": source_doc, "text_pair": generated_claim})
if res['label'] == 'contradiction': raise HallucinationError('Contradicted!')
if res['label'] == 'neutral': raise HallucinationError('Unsupported claim!')

See Lesson 02 — Detecting Hallucinations: Entailment, Self-Check, and Consistency.

2Grounding by Construction Schema

Zero-hallucination Literal enums
from typing import Literal
from pydantic import BaseModel

class BoundedSelection(BaseModel):
    # Model is grammatically blocked from inventing fake IDs:
    selected_id: Literal["DOC_1", "DOC_2", "DOC_3", "NONE"]
    category: Literal["billing", "technical", "compliance"]

See Lesson 03 — Grounding by Construction: Constraining Search Spaces.

3Quotes-First Defensive Prompt

Anchoring attention in verbatim text
prompt = f"""Answer the question using the <document> below.
Step 1: Extract verbatim quotes that answer the question into <quotes>...</quotes>.
Step 2: If no quotes exist, reply: 'Information not found.'
Step 3: Synthesize your answer strictly from those quotes.

<document>
{context_text}
</document>
"""

4High-Risk Audit Table Schema

Human verification tracking
CREATE TABLE medical_reports (
    id UUID PRIMARY KEY,
    generated_text TEXT NOT NULL,
    unverified_claims INT DEFAULT 0,
    physician_id UUID REFERENCES doctors(id),
    approved_at TIMESTAMPTZ,
    status VARCHAR(20) DEFAULT 'PENDING_APPROVAL'
);
