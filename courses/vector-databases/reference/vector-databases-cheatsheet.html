1PostgreSQL HNSW Index Creation (pgvector)

Production vector index setup
-- Increase maintenance memory for fast build:
SET maintenance_work_mem = '8GB';
-- Create HNSW index with cosine distance (<=>):
CREATE INDEX CONCURRENTLY ON document_chunks
USING hnsw (embedding vector_cosine_ops)
WITH (m = 16, ef_construction = 64);

2Reciprocal Rank Fusion (RRF) Formula

Merging hybrid search rankings
def rrf_score(ranks_dict, k=60):
    # ranks_dict = {doc_id: [rank_in_bm25, rank_in_vector]}
    return sum(1.0 / (k + rank) for rank in ranks_dict.values())

3ChromaDB Local Embedded Query

Zero-infrastructure local store
import chromadb
client = chromadb.PersistentClient(path="./chroma_db")
collection = client.get_or_create_collection("documents")
results = collection.query(query_texts=["my query"], n_results=5)

See Lesson 07 — Popular Vector Stores: pgvector, Chroma, Qdrant, Pinecone.

4Single-Stage Filtered SQL Query

Metadata filter + HNSW search
SELECT id, content, 1 - (embedding <=> :query_vec) AS sim
FROM documents
WHERE tenant_id = 'org_42' AND status = 'active'
ORDER BY embedding <=> :query_vec
LIMIT 5;
