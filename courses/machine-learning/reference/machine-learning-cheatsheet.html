1Train-Validation-Test Data Split

Standard scikit-learn split
from sklearn.model_selection import train_test_split
# 1. Split off test set (15%)
X_temp, X_test, y_temp, y_test = train_test_split(X, y, test_size=0.15, random_state=42)
# 2. Split train and validation (70% / 15%)
X_train, X_val, y_train, y_val = train_test_split(X_temp, y_temp, test_size=0.176, random_state=42)

2Gradient Descent Parameter Update

The universal learning rule
# Update weights by stepping opposite the gradient:
w_new = w - (learning_rate * dw)
b_new = b - (learning_rate * db)

4XGBoost Baseline on Tabular Data

The gold standard for tabular data
import xgboost as xgb
model = xgb.XGBClassifier(n_estimators=100, learning_rate=0.05, max_depth=6)
model.fit(X_train, y_train, eval_set=[(X_val, y_val)], early_stopping_rounds=10)
predictions = model.predict(X_test)
