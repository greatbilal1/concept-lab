Notation Classes Simplifying Space Cases Choosing

1Notation

The three symbols
O(g)   upper bound   work grows no faster than g
Ω(g)   lower bound   work grows no slower than g
Θ(g)   tight bound   work grows exactly like g

Unqualified "Big O" means the worst case.

See Lesson 03 — Reading Big O notation.

2The six classes

Cheapest to most expensive
O(1)        constant      no loop, fixed work
O(log n)    logarithmic   halve the input each step
O(n)        linear        one pass over the input
O(n log n)  linearithmic  a pass with log work per item
O(n²)       quadratic     nested loops, every pair
O(2ⁿ)       exponential   doubles work per extra item

See Lesson 05 — The common complexity classes.

3Simplifying to Big O

Two moves
1. Drop constant factors.   3n → n
2. Keep the biggest term.   n² + n + 5 → n²

3n² + 10n + 42  →  O(n²)
100             →  O(1)

See Lesson 04 — Dropping the constants.

4Space and trade-offs

Two axes of cost
scanning loop        O(n) time   O(1) space
building a new list  O(n) time   O(n) space
memoisation          O(n) time   O(n) space  (buys speed)
naive recursion      O(2ⁿ) time  O(1) space

See Lesson 06 — Space and trade-offs.

5Best, worst, average

Linear search, three answers
best     target first    1 comparison
average  target middle   about n/2
worst    target last     n comparisons

Quote the worst case — it is the only promise.

See Lesson 07 — Best, worst, average.

6Choosing between two solutions

State three things first
1. input size      how big does it get?
2. memory budget   how much space can I spend?
3. case            which case must I guarantee?

list     O(n) lookup   O(1) space   wins when small
hash set O(1) lookup   O(n) space   wins when large

See Lesson 08 — Choosing between two solutions.
