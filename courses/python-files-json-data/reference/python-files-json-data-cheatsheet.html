1Files

Modes
"r"  read — file must exist
"w"  write — TRUNCATES the file first
"a"  append — adds to the end
"x"  create — fails if it exists

The with statement
with open("a.txt") as src, open("b.txt", "w") as dst:
    for line in src:
        dst.write(line.upper())
# both handles close here — even if the block raises

pathlib
from pathlib import Path

here = Path(__file__).parent      # anchor to the script
data = here / "data" / "rows.csv" # join with /

data.exists()
data.parent.mkdir(parents=True, exist_ok=True)
data.read_text(encoding="utf-8")

2Formats

JSON — the six types
object  { "key": "value" }   keys are always strings
array   [1, 2, 3]            ordered
string  "double quotes only"
number  42  3.14
boolean true  false          lowercase
null    null                 absence

See Lesson 05 — JSON: the format.

JSON in Python — four functions
import json

text = json.dumps(data)              # dict -> str
back = json.loads(text)              # str  -> dict

json.dump(data, f, indent=2)         # dict -> file
loaded = json.load(f)                # file -> dict

# the trailing "s" means STRING

3Together

CSV to JSON
with open("rows.csv", newline="") as f:
    records = list(csv.DictReader(f))

with open("rows.json", "w") as f:
    json.dump(records, f, indent=2, sort_keys=True)

Validate at the boundary
try:
    data = json.loads(text)
except json.JSONDecodeError as e:
    raise ValueError(f"bad JSON at line {e.lineno}") from e

missing = {"name", "score"} - data.keys()
if missing:
    raise ValueError(f"missing fields: {missing}")
