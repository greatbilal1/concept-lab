Converting between formats

CSV and JSON describe the same data in different shapes. Converting between them is the first genuinely useful thing you can build with everything so far.

Time ~12 min Win Move data between shapes Mission link Data that fits its destination

1Two shapes, one dataset

CSV is tabular: rows and columns, every row the same shape. JSON is nested: objects can contain objects, and rows can differ. Converting means choosing a shape, not just changing punctuation.

The most common conversion is a list of records: CSV rows become a JSON array of objects, one object per row, keyed by the header.

2CSV to JSON

DictReader does most of the work — it already gives you one dictionary per row, which is exactly the JSON shape you want: 

import csv, json

with open("rows.csv", newline="") as f:
    records = list(csv.DictReader(f))

with open("rows.json", "w") as f:
    json.dump(records, f, indent=2)

Two lines of real work. The header row became the keys, and the file became an array of objects.

3JSON to CSV

Going back needs one decision: which keys become columns. You must declare them, because JSON objects are allowed to differ from each other. 

with open("rows.json") as f:
    records = json.load(f)

fields = ["name", "score", "city"]

with open("out.csv", "w", newline="") as f:
    writer = csv.DictWriter(f, fieldnames=fields)
    writer.writeheader()
    writer.writerows(records)

If a record is missing a field, DictWriter raises. That is the format telling you the data is not as uniform as you assumed — which is information you want, not an obstacle.

Key idea Converting formats is really choosing a shape. CSV forces uniformity; JSON allows variation. Pick the one your consumer can actually handle.

4Verify the round trip

After any conversion, read the output back and compare it to the input. If the round trip is not identical, you have lost data — and you want to know now, not in production. 

assert json.load(open("rows.json")) == records
Why this matters later Every pipeline you build from here on is a chain of conversions. Checking the round trip at each step is what turns a script that usually works into one you can trust.
