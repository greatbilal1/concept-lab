JSON: the format

JSON is the lingua franca of data on the web. Before you write a line of code, you need to know exactly what it can and cannot represent — because the gaps are where bugs live.

Time ~10 min Win Read and write JSON by hand Mission link Data that travels between systems

1Six types, no more

JSON has exactly six kinds of value: object, array, string, number, boolean and null. That is the whole language. Anything else you want to store has to be built from these.

Notice what is missing: no dates, no sets, no tuples, no comments, no functions. A date is stored as a string and parsed back by convention, not by the format.

2Objects and arrays

An object is a set of key-value pairs in braces. Keys are always strings. An array is an ordered list in brackets. They nest freely: 

{
  "name": "Ada",
  "active": true,
  "score": 42.5,
  "tags": ["math", "code"],
  "address": { "city": "London", "zip": null }
}

That is a valid JSON document. It is also, almost exactly, a Python dictionary — which is why the two map onto each other so cleanly.

3The rules that trip people up

JSON looks like Python and is not Python. Four differences cause most of the pain:

Double quotes only, no trailing commas, no comments, and true / false / null in lowercase. A single stray comma makes the whole document invalid — JSON has no partial success.

Key idea JSON is strict. One syntax error and the entire document fails to parse; there is no "read what you can".

4Why it won

JSON is text, so it survives email, HTTP, and copy-paste. It is readable by humans and trivial for machines. And because it maps onto the two most common data shapes — dictionaries and lists — almost every language can handle it without a schema.

Why this matters later Every API you will ever call returns JSON. Every config file you will ever write is probably JSON. Knowing the six types cold means you always know what can be stored and what has to be encoded.

✓ Your win for today

You can now read a JSON document and say whether it is valid, name all six value types, and explain why a date has to be a string. That is the format understood, before any code touches it.

6Do this next

  1. Write a small JSON document by hand with an object, an array and a nested object.
  2. Break it deliberately — a trailing comma, then single quotes — and note how completely it fails.
  3. Find a JSON file on your machine and identify every value type it uses.
