Lesson 06 · Formats

JSON in Python

Four functions do all the work, and the only real difficulty is remembering which one takes a string and which one takes a file. This lesson fixes that permanently.

Time ~10 min Win Never mix up dumps and dump Mission link Move data in and out of Python

1Four functions, two directions

The json module gives you two pairs. The s in dumps and loads stands for string — those work on text in memory. Without the s, they work on files.

That single letter is the whole distinction. dumps returns a string; dump writes to a file object. Mixing them up is the most common JSON mistake in Python.

2Serialising and deserialising

Turning Python objects into JSON text is serialisation. Turning JSON text back into Python objects is deserialisation. The mapping is almost one-to-one: 

import json

data = {"name": "Ada", "tags": ["math"], "active": True}

text = json.dumps(data)          # dict -> str
back = json.loads(text)          # str  -> dict

with open("out.json", "w") as f:
    json.dump(data, f, indent=2) # dict -> file

with open("out.json") as f:
    loaded = json.load(f)        # file -> dict

3The type mapping

Python and JSON agree on most things, and the disagreements are worth knowing before they surprise you.

None becomes null, True becomes true, and a tuple becomes an array — it does not come back as a tuple. That last one is a real trap: the round trip is not always identity.

Key idea dumps/loads work on strings; dump/load work on files. The trailing s is the only difference.

4Making it readable

By default dumps produces one long line. indent=2 pretty-prints it, and sort_keys=True makes the output stable so diffs are meaningful: 

print(json.dumps(data, indent=2, sort_keys=True))
Why this matters later Stable, indented output is what makes JSON files reviewable in version control. A one-line dump produces a diff that shows everything changed when only one value did.

6Do this next

  2. Write the same dictionary to a file with dump and read it back with load.
  3. Serialise a tuple and observe what type comes back. Note the difference.
