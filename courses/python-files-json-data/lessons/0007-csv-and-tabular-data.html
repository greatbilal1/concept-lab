Lesson 07 · Formats

CSV and tabular data

CSV looks like the simplest format in the world until a value contains a comma. The csv module exists precisely because splitting on commas is not enough.

Time ~10 min Win Read and write rows safely Mission link Handle real-world messy data

1Rows, not lines

A CSV file is a table: the first row is usually the header, and every row after it is a record. The csv module reads it as lists of strings.

Every value comes back as a string. "42" is not the number 42, and "3.14" is not a float. Converting is your job, and forgetting it is the classic CSV bug.

2reader and writer

The basic pair works on lists. Note the newline="" argument — it is required on the file handle, not optional: 

import csv

with open("rows.csv", newline="") as f:
    reader = csv.reader(f)
    header = next(reader)          # consume the header row
    for row in reader:
        print(row)                 # ['Ada', '42', 'London']

with open("out.csv", "w", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(["name", "score"])
    writer.writerow(["Ada", 42])

3DictReader and DictWriter

Working with column names is far less error-prone than counting positions. DictReader gives you a dictionary per row, keyed by the header: 

with open("rows.csv", newline="") as f:
    for row in csv.DictReader(f):
        print(row["name"], row["score"])

DictWriter is the mirror: you declare the field names once and write dictionaries. It will raise if you forget a field, which is a feature.

Key idea Never split CSV on commas yourself. Quoting, embedded commas and embedded newlines are all legal, and only the csv module handles them.

4Quoting and dialects

When a value contains a comma, the writer wraps it in quotes. When it contains a quote, it doubles it. This is automatic — and it is exactly what a naive split(",") gets wrong. 

writer.writerow(["Ada, Jr.", 'He said "hi"'])
# -> "Ada, Jr.","He said ""hi"""
Why this matters later Real exports from spreadsheets and databases contain quoted fields, stray whitespace and inconsistent headers. Using the csv module means you inherit correct parsing instead of reimplementing it badly.
