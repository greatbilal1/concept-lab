Lesson 03 · DOM Events & Delegation

DOM event propagation: capturing and bubbling

When you click a button, the event does not start at the button. Explore the three phases of DOM event propagation: capturing down, target, and bubbling up.

Time ~10 min Win Explain event propagation phases and control flow with stopPropagation Mission link The mechanism underlying all interactive browser UI event handling

1The three phases of an event

When an event occurs (e.g. clicking a nested <button>), the browser dispatches the event through three distinct phases: 1. Capturing Phase (travels from window down through ancestors to the target), 2. Target Phase (reaches the element clicked), and 3. Bubbling Phase (ascends back up from target to window).

By default, addEventListener listens only during the bubbling phase. Calling event.stopPropagation() stops the event from ascending further up the tree.

Key idea Events travel down during capturing, reach the target, then bubble back up to window.
