Lesson 01 · The Event Loop & Queues

The single-threaded call stack

JavaScript has one thread and one call stack. Understand how synchronous code runs to completion and why blocking the thread freezes the entire browser.

Time ~10 min Win Trace synchronous call stack execution and identify thread-blocking bottlenecks Mission link The foundation for understanding why asynchronous execution exists

1One thing at a time

The JavaScript engine operates on a single execution thread. It contains a single Call Stack: a data structure that pushes function frames when entered and pops them when returning.

Because there is only one thread, JavaScript exhibits run-to-completion behavior: the currently executing function cannot be interrupted by other JavaScript. If you run a heavy synchronous calculation that takes 5 seconds, the browser cannot scroll, click, or animate during those 5 seconds — the entire page freezes.

Key idea JavaScript runs synchronously on one thread; blocking the call stack freezes the browser UI.
