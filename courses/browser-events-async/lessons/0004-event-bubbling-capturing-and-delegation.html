Lesson 04 · DOM Events & Delegation

Event delegation in practice

Do not attach 1,000 event listeners to 1,000 list items. Master event delegation: attaching one smart listener to a parent to manage dynamic children.

Time ~10 min Win Implement event delegation to manage dynamic list items using element.closest() Mission link Dramatically reduces memory consumption and handles dynamically added elements

1The power of event delegation

If you have a list of 500 items, attaching an event listener to every individual <li> consumes memory and breaks when new items are added dynamically via JavaScript.

Because events bubble upward, you can attach a single event listener to the parent container. When any child is clicked, the event bubbles to the parent. Using event.target.closest('li'), the parent easily identifies which child was clicked.

Key idea Event delegation leverages bubbling to handle events for all children with one parent listener.
