1Navigation & Files

Movement and inspection
pwd                 # print working directory
ls -la              # detailed list including hidden files
cd -                # jump back to previous directory
find . -name "*.py" # search filesystem tree

See Lesson 01 — Navigating the filesystem.

2Streams & Redirection

Connecting inputs and outputs
command > file.txt   # redirect stdout (overwrite)
command >> file.txt  # redirect stdout (append)
command 2> err.log   # redirect stderr
cmd1 | cmd2          # pipe stdout of cmd1 to stdin of cmd2

See Lesson 03 — Standard streams and redirection.

3Process Control

Managing running jobs
ps aux | grep node   # find process ID (PID)
kill -15 <PID>       # graceful shutdown (SIGTERM)
kill -9 <PID>        # forced termination (SIGKILL)
jobs                 # list background jobs
fg %1                # bring job 1 to foreground

See Lesson 05 — Processes and signals.

4Permissions & PATH

Security and execution
chmod +x script.sh   # make executable
chmod 755 script.sh  # rwxr-xr-x
export PATH="$HOME/bin:$PATH"  # prepend to PATH
echo $?              # exit code of previous command

See Lesson 06 — Permissions and ownership.
