Lesson 04 · Streams & Pipes

Pipes and text processing

The UNIX philosophy: write programs that do one thing well, and connect them with pipes. Combine grep, awk, cut, and sort into powerful processing pipelines.

Time ~10 min Win Build multi-stage text processing pipelines using pipes and core utilities Mission link Enables immediate text analysis without writing custom scripts

1The pipeline operator

A pipe (|) connects the standard output of one command directly to the standard input of the next. The data never touches disk; the operating system streams bytes through a memory buffer in real time.

By combining small, focused filters — like grep (search lines), cut (extract columns), sort (order lines), and uniq -c (count duplicates) — you can analyze gigabytes of log data with a single line of shell.

Key idea Pipes stream data directly through memory buffers between concurrent processes.
