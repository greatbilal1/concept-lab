Lesson 02 · Filesystem & Navigation

Manipulating files and directories

Creating, copying, moving, and removing files is the core of terminal productivity. Learn safe habits and powerful shell wildcard matching.

Time ~10 min Win Manage files and directories safely using cp, mv, rm, and wildcards Mission link Prevents accidental data loss during file management

1The atomic file verbs

UNIX provides single-purpose file utilities: touch to create empty files or update timestamps, mkdir -p to create nested directory trees, cp -r to recursively copy folders, and mv to move or rename files.

Notice that mv handles both renaming and moving: in the UNIX filesystem, renaming a file is simply moving it to a new name in the same directory.

Key idea In UNIX, renaming a file and moving a file are the exact same operation.

2Shell glob wildcards

The shell expands wildcards before passing arguments to commands: * matches any characters, ? matches single characters, and *.{jpg,png} matches braces.

3Tracing directory tree creation

Trace how mkdir -p creates multiple nested folder levels in a single operation.
