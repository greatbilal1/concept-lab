Lesson 06 · Processes & Permissions

Permissions and ownership

UNIX security starts at the file mode. Learn how read, write, and execute bits protect files, and how to configure them using octal masks.

Time ~10 min Win Calculate and set file permissions using chmod and octal notation Mission link Prevents permission denied errors and security vulnerabilities

1The rwx permission triad

Every file and directory in a UNIX filesystem belongs to an owner user and a group, and maintains a 9-bit permission mask. The mask is divided into three triads: user (owner), group, and others (world).

Each triad has three bits: r (read, value 4), w (write, value 2), and x (execute, value 1). Adding the values produces the octal permission code (e.g. 7 = 4+2+1 for read/write/execute).

Key idea Permissions define who can read, modify, or execute a file across user, group, and others.

2Octal values reference

Memorise the additive binary values that compose every permission number.
