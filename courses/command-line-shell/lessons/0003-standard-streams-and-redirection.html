Lesson 03 · Streams & Pipes

Standard streams and redirection

Everything in UNIX is a stream of bytes. Learn how file descriptors 0, 1, and 2 allow you to redirect inputs and outputs anywhere.

Time ~10 min Win Redirect standard output and standard error to files and /dev/null Mission link Mastery of I/O streams is the foundation of composable toolchains

1The three standard file descriptors

Every process launched in a POSIX system starts with three standard I/O streams open: standard input (stdin, fd 0), standard output (stdout, fd 1), and standard error (stderr, fd 2).

By default, stdin comes from the keyboard, while stdout and stderr both print to the terminal screen. Redirection operators allow you to detach these streams and connect them to files or null devices.

Key idea Standard error is separated from standard output so diagnostics never corrupt data streams.
