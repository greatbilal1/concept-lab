Lesson 08 · Environment & Scripting

Shell scripting and aliases

If you run a command sequence more than twice, automate it. Learn to create aliases, write shell scripts with shebang lines, and handle exit codes.

Time ~10 min Win Write repeatable shell automation scripts and custom workflow aliases Mission link Transforms manual command-line tasks into robust automation

1From interactive commands to scripts

A shell script is simply a text file containing the exact same commands you would type into a terminal prompt. The first line is the shebang (#!/bin/bash or #!/usr/bin/env bash), telling the operating system which interpreter to execute.

Every command exits with an integer exit code stored in $?. An exit code of 0 signals success; any non-zero value signals an error. Using set -e ensures your script halts immediately if any command fails.

Key idea A script is a sequence of terminal commands with automatic error checking and a shebang.

2Conditionals and chaining

Chain commands using logical operators based on exit codes: && runs on success; || runs on failure.

✓ Your win for today

You can write safe, robust shell scripts and custom aliases to automate repetitive developer workflows.

  2. Write a 5-line bash script with a shebang, make it executable, and run it.
  3. Inspect the exit code of successful and failing commands using echo $?.
