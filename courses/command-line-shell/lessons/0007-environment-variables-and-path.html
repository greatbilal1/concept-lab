Environment variables and PATH

How does the shell know where to find 'python' or 'git'? Master the PATH variable, environment inheritance, and configuration dotfiles.

Time ~10 min Win Configure shell environment variables and modify $PATH resolution Mission link Eliminates 'command not found' errors across all developer tooling

1Environment variable inheritance

When a process spawns a child process, the child inherits a copy of the parent's environment variables. Variables created in a shell session remain private to that shell unless marked for export with export KEY=value.

The most important variable is PATH: a colon-separated list of directories. When you type python, the shell searches each directory in $PATH from left to right until it finds an executable binary named python.

Key idea The shell finds executables by scanning the colon-separated directory list in $PATH from left to right.
