Lesson 01 · Filesystem & Navigation

Navigating the filesystem

The terminal sees your computer as a single hierarchical tree. Learn to move with speed, understanding relative versus absolute coordinates.

Time ~10 min Win Navigate nested directories with cd, pwd, and path shortcuts Mission link Forms the bedrock of all command-line operations

1The root and working directory

In graphical user interfaces, folders appear as visual windows. In the shell, your session always has a single current working directory. Every command you run without a full path is resolved relative to this location.

An absolute path starts at the root slash (/) and specifies the exact location regardless of where you are. A relative path starts from your current position. The symbol . means current directory; .. means parent directory.

Key idea Absolute paths start from root slash; relative paths compute coordinates from where you stand right now.
