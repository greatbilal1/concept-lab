Lesson 05 · Processes & Permissions

Processes and signals

Every running program is a process managed by the operating system kernel. Learn to inspect process states, control jobs, and send termination signals.

Time ~10 min Win Monitor running processes with ps and manage execution using UNIX signals Mission link Provides essential system control over running background software

1The anatomy of a process

A process is an instance of a running program. The kernel assigns each process a unique numerical Process ID (PID), an allocated memory space, and parent-child hierarchy tracking.

You inspect running processes with ps aux or interactive monitors like top and htop. When you need to communicate with a process, you send an asynchronous signal using the kill utility.

Key idea A process is a container of state; signals are notifications sent by the kernel to that container.
