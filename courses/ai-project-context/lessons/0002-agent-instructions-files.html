# .github/copilot-instructions.md Example
## Architecture & Frameworks
- Backend: FastAPI 0.110+ with Python 3.12 syntax (use type | None, not Optional[type]).
- Database: PostgreSQL with SQLAlchemy 2.0 (use AsyncSession and select()).
- Validation: Pydantic v2 (use @field_validator, never @validator).

## Testing Rules
- Always run tests with: `pytest tests/`.
- Every new endpoint must have a corresponding test in tests/api/.
- Never mock database queries in integration tests; use ephemeral containers.

Keep these files actionable and bulleted. Avoid narrative essays; agents respond best to crisp, declarative rules.

Format Tip: Use imperative mood ('Use X', 'Never do Y') and categorize rules by topic (Architecture, Testing, Git, Security).
