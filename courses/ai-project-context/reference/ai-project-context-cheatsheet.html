1Universal copilot-instructions.md

Standard configuration template
## Architecture & Tech Stack
- Python 3.12+ with FastAPI and SQLAlchemy 2.0 (async).
- Pydantic v2 schemas in src/schemas/.
## Testing & Verification
- Run tests with: `make test-unit`.
- Run full verification: `make check`.
## Non-Negotiable Rules
- Never mock database queries in integration tests.
- Never commit credentials or API keys.

See Lesson 02 — Agent Instructions Files (.cursorrules, copilot-instructions.md).

2Minimal Architecture Decision Record

Documenting design intent
# docs/adr/005-use-postgres-jsonb.md
## Context
Need to store flexible customer metadata without schema migrations.
## Decision
Use PostgreSQL JSONB column with Pydantic validation on read/write.
## Consequences
Fast schema flexibility; requires PG 15+.

See Lesson 03 — Architecture Decision Records (ADRs) as Agent Context.

3Repository Map Template

Orienting agents in seconds
## Directory Map & Invariants
- `src/domain/`   -> Pure business rules (NEVER imports api/ or storage/).
- `src/storage/`  -> PostgreSQL models & SQL migrations.
- `src/api/`      -> FastAPI endpoints calling domain via DI.
- `tests/`        -> Mirrors src/ directory structure.

See Lesson 05 — Repository Maps and Architecture Guides.
