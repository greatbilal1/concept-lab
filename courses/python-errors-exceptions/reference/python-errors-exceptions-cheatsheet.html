2Catch narrowly and clean up

See Lesson 03 and Lesson 04.

Specific handler, success path, guaranteed cleanup
try:
    age = int(raw_age)
except ValueError:
    print("Enter a whole number")
else:
    save_age(age)
finally:
    release_temporary_resource()

# Avoid bare except: and silent pass.

3Raise at the cause

See Lesson 05 — Raising your own.

Guard clauses make the contract explicit
def split_bill(total, people):
    if people <= 0:
      raise ValueError("people must be greater than zero")
    return total / people

  try:
    share = split_bill(60, 0)
  except ValueError as error:
    print(error)

4Give domain failures a type

See Lesson 06 — Custom exception types.

Subclass Exception for ordinary application failures
class OutOfStockError(Exception):
    """Raised when an item cannot be supplied."""

  def reserve(item):
    if item.stock == 0:
      raise OutOfStockError(f"{item.name} is unavailable")

  try:
    reserve(item)
  except OutOfStockError as error:
    show_unavailable(error)

6One clear error boundary

See Lesson 08 — Putting it together.

Cleanup and exception chaining
def read_number(path):
      with open(path) as file:
        try:
          return int(file.read())
        except ValueError as error:
          raise ValueError("file must contain an integer") from error

    try:
      value = read_number("count.txt")
    except (FileNotFoundError, ValueError) as error:
      print(f"Cannot load count: {error}")

    # Retry only plausibly transient failures, and set a limit.
