1Cosine Similarity Calculation

Normalized directional similarity
import numpy as np
def cosine_sim(u, v):
    return np.dot(u, v) / (np.linalg.norm(u) * np.linalg.norm(v))
# For unit-normalized vectors: sim = np.dot(u, v)

3Matryoshka Dimension Slicing

80% RAM and storage reduction
# Truncate 3,072D vector down to 512D:
full_vector = get_embedding(text) # 3072 dims
sliced_vector = full_vector[:512]
# Re-normalize to unit length:
sliced_vector = sliced_vector / np.linalg.norm(sliced_vector)
