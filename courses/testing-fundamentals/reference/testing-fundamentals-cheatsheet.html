1AAA Test Template (pytest)

Universal test structure
def test_transfer_funds():
    # 1. Arrange
    acc1, acc2 = Account(500), Account(100)
    # 2. Act
    transfer(acc1, acc2, 200)
    # 3. Assert
    assert acc1.balance == 300
    assert acc2.balance == 300

See Lesson 02 — The Anatomy of a Test: Arrange, Act, Assert.

2Exception Assertions

Verifying errors and messages
import pytest

with pytest.raises(ValueError, match="Insufficient balance"):
    account.withdraw(99999)

4Freezing Time Deterministically

Eliminating clock-based flakiness
from freezegun import freeze_time

with freeze_time("2026-01-01 12:00:00") as frozen:
    cache.set("k", "v", ttl=60)
    frozen.tick(delta=timedelta(seconds=61))
    assert cache.get("k") is None

See Lesson 07 — Flaky Tests and Non-Determinism.
