Lesson 05 · Hooks & Side Effects

Mastering useEffect: synchronization, not lifecycle

Stop thinking in componentDidMount. Master useEffect as a synchronization engine: connecting your component to external systems, cleanup functions, and dependency rules.

Time ~10 min Win Write correct useEffect synchronization logic with proper dependency arrays and cleanup functions Mission link Eliminates infinite loops and memory leaks in React side effect handling

1Synchronization, not lifecycle

Thinking of useEffect as 'lifecycle methods' (componentDidMount, componentDidUpdate) causes endless bugs. useEffect is not a lifecycle tool: it is a Synchronization Engine.

Its purpose is to synchronize your component with an external system outside of React (a browser window listener, a WebSocket connection, a canvas element, or an external API). The dependency array tells React: 'Re-run this synchronization whenever these external values change.'

Key idea useEffect synchronizes your component with an external system; it is not a lifecycle method.
