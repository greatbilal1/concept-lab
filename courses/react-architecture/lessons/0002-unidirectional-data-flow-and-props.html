Lesson 02 · Components & Unidirectional Flow

Unidirectional data flow and props

Data flows down; events flow up. Master unidirectional data flow: how passing props down and callbacks up makes complex UI systems easy to debug.

Time ~10 min Win Implement unidirectional data flow using props and event callbacks Mission link The architectural rule that prevents spaghetti state synchronization bugs

1The one-way street of data

In older frameworks (like AngularJS 1.x), two-way data binding meant child inputs could silently mutate parent state from anywhere. When a bug occurred, finding which component caused the change was nearly impossible.

React mandates Unidirectional Data Flow: data flows in strictly one direction: Downwards via props. When a child needs to communicate a change (e.g. user toggled a checkbox), it cannot mutate the parent. It calls an event callback function passed down from the parent: onChange(newValue).

Key idea Data flows down as props; actions flow up as event callbacks.
