Lesson 04 · State & The Render Cycle

The React render cycle and reconciliation

What happens when you call setState? Explore the two phases of React: the Render Phase (pure calculation, virtual DOM diffing) and the Commit Phase (mutating the real DOM).

Time ~10 min Win Explain the Render and Commit phases, Virtual DOM diffing, and derived state Mission link Demystifies how React updates the screen and optimizes DOM operations

1Render phase versus Commit phase

Many developers think calling setState immediately updates the physical DOM on screen. In reality, React operates in two distinct phases: 1. The Render Phase and 2. The Commit Phase.

During the Render Phase, React calls your component functions to build a new Virtual DOM tree, comparing (reconciling) it with the previous snapshot. During the Commit Phase, React applies only the minimal necessary differences to the real browser DOM (e.g. changing one text node) and schedules painting.

Key idea Render phase computes the virtual DOM diff; Commit phase applies minimal mutations to the real DOM.
