1Hardened Docker Code Sandbox Execution

Isolated non-root ephemeral runner
docker run --rm -i \
    --network none \
    --read-only \
    --tmpfs /tmp:rw,noexec,size=64m \
    --user 1000:1000 \
    --cap-drop ALL \
    python:3.12-slim python -c "print('Secure execution')"

2SSRF IP Protection Validation

Blocking internal metadata and private ranges
import ipaddress, socket, urllib.parse
def verify_safe_url(url):
    ip_str = socket.gethostbyname(urllib.parse.urlparse(url).netloc)
    ip = ipaddress.ip_address(ip_str)
    if ip.is_private or ip.is_loopback or ip_str == '169.254.169.254':
        raise SecurityException(f'Blocked internal IP {ip_str}!')

See Lesson 04 — Network Egress Filtering: Preventing SSRF and Exfiltration.

3PostgreSQL Agent Read-Only Role

Database-level mutation prevention
CREATE USER agent_reader WITH PASSWORD 'secure_pass';
GRANT CONNECT ON DATABASE prod TO agent_reader;
GRANT USAGE ON SCHEMA public TO agent_reader;
GRANT SELECT ON v_sanitized_customer_orders TO agent_reader;
-- DROP, INSERT, and UPDATE attempts are rejected by engine!

See Lesson 03 — Scoping Tool Permissions: Read-Only Databases and Parameter Allow-Lists.
