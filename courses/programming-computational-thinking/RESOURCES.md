# Resources — Programming & Computational Thinking

## Knowledge

Primary sources for the ideas in this course. Each lesson cites exactly one.

1. **Jeannette Wing — "Computational Thinking" (Communications of the ACM, 2006).**
   The paper that named the field. Defines computational thinking as the
   *thought processes* involved in formulating problems and their solutions so
   that the solutions are represented in a form a computer can carry out.
   <https://dl.acm.org/doi/10.1145/1118178.1118215>

2. **BBC Bitesize — "Decomposition" (KS3 Computer Science).**
   A short, plain-language explanation of decomposition aimed at beginners,
   with worked examples. Good for the "break it into parts" lesson.
   <https://www.bbc.co.uk/bitesize/guides/z8qymsg/revision/1>

3. **BBC Bitesize — "Pattern recognition" (KS3 Computer Science).**
   Companion page on spotting repetition and similarity. Pairs directly with
   Lesson 3.
   <https://www.bbc.co.uk/bitesize/guides/z8qymsg/revision/2>

4. **BBC Bitesize — "Abstraction" (KS3 Computer Science).**
   Explains removing unnecessary detail and keeping only what matters.
   <https://www.bbc.co.uk/bitesize/guides/z8qymsg/revision/3>

5. **BBC Bitesize — "Algorithms" (KS3 Computer Science).**
   What an algorithm is, why order matters, and how to write one as clear steps.
   <https://www.bbc.co.uk/bitesize/guides/z8qymsg/revision/4>

6. **David J. Malan — CS50, Lecture 0 (Harvard, free on edX/YouTube).**
   The best live demonstration of computational thinking in practice: taking a
   phone book, a set of names, and turning "find a person" into a precise,
   repeatable procedure. Watch the first 40 minutes.
   <https://cs50.harvard.edu/x/>

7. **George Pólya — _How to Solve It_ (1945).**
   The original four-step method for problem solving (understand, plan, carry
   out, look back). Predates computing but is the intellectual ancestor of
   decomposition. Chapter 1 is enough.

8. **Bhargava — _Grokking Algorithms_ (2nd ed., Manning).**
   Visual, beginner-friendly introduction to algorithms. Useful as the *next*
   step after this course, not during it.

## Wisdom (Communities)

- **r/learnprogramming** — beginner questions answered patiently; good for
  "is my decomposition reasonable?" sanity checks.
- **CS50's discussion forums** — active, moderated, beginner-safe.
- **Stack Overflow** — for later, once you are writing code. Not useful yet.

## Gaps

- No single source covers all six moves *in this order* for a complete
  beginner. The course is therefore synthesised from the BBC Bitesize set
  (which covers the core moves separately), Pólya's *How to Solve It* (which
  supplies evaluation as a stage), Bhargava's *Grokking Algorithms* (which
  supplies generalisation), plus Wing's framing (which explains why they belong
  together).
- There is no widely-agreed "canonical" set of exercises for computational
  thinking at beginner level. The exercises in this course are original and
  deliberately use everyday situations.
