Annotations Generics Checking Together

1Annotations

The three positions
def area(w: float, h: float) -> float:   # parameter, return
    return w * h

total: int = 0        # variable
pending: str          # declared, not assigned

See Lesson 02 — Annotating variables and functions.

Common scalar types
name: str = "Ada"
age: int = 36
ratio: float = 0.75
active: bool = True     # bool is a subtype of int

See Lesson 03 — The common types.

Unions and Optional
def find(name: str) -> str | None: ...   # modern pipe
def find(name: str) -> Optional[str]: ...  # same thing

def parse(v: str | int) -> int: ...      # any number of types

See Lesson 04 — Optional and Union.

2Generics

Collections carry their contents
names: list[str] = ["Ada"]
ages: dict[str, int] = {"Ada": 36}
tags: set[str] = {"python"}
point: tuple[float, float] = (1.0, 2.0)
many: tuple[int, ...] = (1, 2, 3)

See Lesson 05 — Collections and generics.

TypeVar links positions
T = TypeVar("T")

def first(items: list[T]) -> T:
    return items[0]

See Lesson 05 — Collections and generics.

Aliases, NewType, Literal, TypedDict
UserId = int                       # alias: a nickname
UserId = NewType("UserId", int)    # distinct type, no cost
Mode = Literal["read", "write"]    # exact values only

class Row(TypedDict):
    name: str
    age: int

See Lesson 06 — Type aliases and NewType.

Protocols and Callables
class Sized(Protocol):
    def __len__(self) -> int: ...

def apply(f: Callable[[int], str], n: int) -> str:
    return f(n)

See Lesson 07 — Protocols and Callables.

3Checking

Run a checker
pip install mypy
mypy src/

# src/app.py:12: error: Argument 1 to "greet" has
# incompatible type "int"; expected "str"  [arg-type]

See Lesson 08 — Static checking with mypy.

Annotations are stored
def greet(name: str) -> str: ...
greet.__annotations__
# {'name': <class 'str'>, 'return': <class 'str'>}

class Node:
    def next(self) -> "Node": ...   # forward reference

from __future__ import annotations   # all lazy strings

See Lesson 09 — Annotations at runtime.

4Together

Adoption order
1. annotate the boundaries (public functions, handlers)
2. run a checker, record the error count as baseline
3. tighten strictness one flag at a time
4. stop where annotations stop catching real mistakes

See Lesson 10 — Typing in a real project.

Any vs object
x: Any      # checking disabled — use deliberately
y: object   # accepts everything — narrow before use

See Lesson 03 — The common types.
