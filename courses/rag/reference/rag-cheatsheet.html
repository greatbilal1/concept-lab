1Minimal RAG Ingestion Pipeline

Chunking and vectorizing
from langchain_text_splitters import RecursiveCharacterTextSplitter
# 1. Chunk document:
splitter = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50)
chunks = splitter.split_text(raw_document)
# 2. Vectorize and insert into database:
vector_db.add(documents=chunks, ids=[f'doc_{i}' for i in range(len(chunks))])

See Lesson 03 — Document Parsing and Chunking Strategies.

3Metadata Filtered Query

Multi-tenant tenant isolation
# Enforce tenant boundary during vector query:
results = collection.query(
    query_texts=["company vacation policy"],
    n_results=3,
    where={"tenant_id": current_user.tenant_id} # Hard security boundary!
)
