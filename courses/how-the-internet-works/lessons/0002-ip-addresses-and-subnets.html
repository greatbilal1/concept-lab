Lesson 02 · The Physical & Network Layer

IP addresses and subnets

Every machine on the internet needs an address. Learn how 32-bit IPv4 numbers, 128-bit IPv6 identifiers, and CIDR subnet masks carve up the global address space.

Time ~10 min Win Calculate IP address ranges and subnet boundaries using CIDR notation Mission link The foundation for all network routing and cloud infrastructure configuration

1The digital mailing address

Just as a postal letter needs a street and zip code, every packet on the internet needs a source and destination IP address. IPv4 addresses are 32-bit numbers traditionally written as four dot-separated octets (e.g. 192.168.1.1).

Because 32 bits yield only 4.3 billion addresses — fewer than the number of smartphones on earth — IPv6 was created with 128-bit addresses, offering 340 undecillion unique addresses.

Key idea An IP address specifies the logical location of a network interface card on the internet.

2CIDR subnet notation

Subnets divide the IP address into a Network Prefix (identifying the subnet) and a Host Identifier (identifying the machine).

3Tracing subnet mask bitwise filtering

Trace how a router uses a subnet mask bitwise AND operation to decide if an IP is local or remote.

4Practice

Test your memory of IP addressing and subnetting.

✓ Your win for today

You can read, calculate, and configure IP address ranges and CIDR subnets in cloud networks and local routers.
