Lesson 07 · Global Infrastructure & Clients

The client-server model

How do billions of phones and laptops talk to cloud servers behind home routers? Learn about the client-server architecture, NAT gateways, and private addressing.

Time ~10 min Win Explain Network Address Translation (NAT) and the asymmetric client-server paradigm Mission link Explains how home devices communicate bidirectionally with public internet services

1The asymmetric web

The dominant architecture of the internet is the client-server model. Servers have public, static IP addresses and run continuously, waiting to accept incoming connections. Clients (laptops, phones) have private, dynamic IP addresses and initiate requests when needed.

Because IPv4 addresses are scarce, almost all home and office devices sit behind a NAT (Network Address Translation) gateway. Your home router shares a single public IP address across dozens of private phones, TVs, and laptops.

Key idea Clients initiate connections from behind private NATs; servers listen on stable public addresses.

2How Network Address Translation (NAT) works

Understand how a home router rewrites packet headers so multiple private devices share one public IP address.
