Lesson 04 · Packets & Routing

Routing and hops across the globe

How does a packet find its way from London to Tokyo in 150 milliseconds? Master router hops, the BGP routing protocol, and the diagnostic power of traceroute.

Time ~10 min Win Diagnose network latency bottlenecks and packet loss using traceroute and ping Mission link Provides concrete diagnostic capability during network outages

1Hop-by-hop forwarding

No single router knows the entire global path between you and a distant server. Instead, routing is hop-by-hop: each router inspects a packet's destination IP, consults its internal routing table, and forwards the packet to the next closest neighbor router.

The global coordination protocol binding the internet together is BGP (Border Gateway Protocol). Autonomous Systems (ISPs, universities, cloud providers) use BGP to announce which IP ranges they can reach.

Key idea Routers forward packets hop-by-hop using routing tables populated by BGP announcements.

2How traceroute works with TTL

Traceroute is a stroke of engineering genius. It intentionally sends packets with TTL=1 to discover the first router, TTL=2 to discover the second, and so on.
