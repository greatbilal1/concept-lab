Lesson 05 · Transport Layer & Protocols

TCP versus UDP

Reliable stream versus fast datagrams: understand why the web runs on TCP, while voice calls, streaming, and gaming choose UDP.

Time ~10 min Win Contrast TCP and UDP trade-offs and explain the TCP three-way handshake Mission link Guides protocol selection when architecting network applications

1The two fundamental transport protocols

The IP layer provides only 'best effort' packet delivery: packets can be dropped, duplicated, delayed, or arrive completely out of order. Layer 4 protocols decide what to do about this.

TCP (Transmission Control Protocol) builds a reliable, in-order byte stream: it tracks sequence numbers, retransmits lost packets, and manages flow control. UDP (User Datagram Protocol) is a bare-bones wrapper: it fires packets with zero guarantees, minimizing latency and overhead.

Key idea TCP guarantees reliable in-order delivery through acknowledgments; UDP delivers raw speed with zero guarantees.

2The TCP 3-way handshake

Before any application data can travel over TCP, client and server must establish sequence synchronisation.
