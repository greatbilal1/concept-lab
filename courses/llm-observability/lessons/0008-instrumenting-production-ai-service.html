3From Black Box to Glass Box

  • 1. Traced Entrypoint: Every incoming HTTP request starts a root trace with `trace_id`, `user_id`, and `tenant_id`.
  • 2. Nested Spans: Every RAG retrieval, tool execution, and LLM call creates a child span with standardized attributes (`llm.model_name`, `tokens`).
  • 3. PII Sanitization: All prompt text and responses are scrubbed before export.
  • 4. Real-Time Metrics: Emits latency histograms (TTFT, total) and cost metrics to Prometheus/Datadog.
  • 5. Automated Incident Gates: Fallback invocations and schema parse errors trigger alert webhooks.
# The Complete Instrumented Endpoint Pattern (FastAPI + Langfuse):
@router.post("/api/v1/research-agent")
async def research_agent_endpoint(request: AgentRequest, user: User = Depends(get_user)):
    # 1. Initialize root trace with metadata
    trace = langfuse.trace(name="ResearchAgent", user_id=user.id, metadata={"tenant": user.org_id})
    
    # 2. Instrument RAG span
    with trace.span(name="RetrieveDocs") as span:
        docs = await vector_db.search(request.query)
        span.set_attribute("docs_retrieved", len(docs))
        
    # 3. Instrument LLM generation
    with trace.generation(name="SynthesizeAnswer", model="gpt-4o-mini") as gen:
        response = await llm_client.generate(request.query, docs)
        gen.end(usage=response.usage, output=scrub_pii(response.text))
        
    return {"answer": response.text}
