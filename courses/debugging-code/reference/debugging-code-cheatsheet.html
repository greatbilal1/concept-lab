1Reproduction & Isolation

Minimize the reproduction case
# 1. Strip external dependencies and network calls
# 2. Find the smallest input that triggers the failure
python -c "from app import calc; print(calc(-1))"

See Lesson 02 — Making bugs reproducible.

2Bisecting Search

Find the introducing commit
git bisect start
git bisect bad                 # current commit fails
git bisect good v1.4.0         # known good release
git bisect run pytest test_bug.py

See Lesson 04 — Binary search and git bisect.

3Stack Inspection

Reading tracebacks and frame state
import pdb; pdb.set_trace()
# Navigation commands:
# n (next line)
# s (step into call)
# c (continue execution)
# p variable_name (print value)

See Lesson 06 — Using breakpoints and inspectors.

4Verification & Regression

Preventing recurrence
def test_negative_quantity_raises_value_error():
    with pytest.raises(ValueError):
        calculate_total(price=10, quantity=-1)

See Lesson 08 — Fixing the cause, not the symptom.
