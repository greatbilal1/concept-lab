Instance, class, static

Not every method needs an object. Python gives you three kinds, and picking the right one tells the reader exactly what the method depends on — the object, the class, or nothing at all.

Time ~10 min Win Choose the right method kind every time Mission link Methods that say what they need

1Three kinds, three meanings

The first parameter tells you what the method depends on.

KindFirst parameterDepends on
InstanceselfOne specific object
ClassclsThe class itself
StaticnoneNothing — just a helper
Key idea The first parameter is a signal. self means "I need an object". cls means "I need the class". Nothing means "I need neither".

2All three in one class

class Book:
    library_name = "City Library"          # class attribute

    def __init__(self, title):
        self.title = title

    def describe(self):                    # instance method
        return f"{self.title} at {self.library_name}"

    @classmethod
    def from_string(cls, text):            # class method
        title, copies = text.split("|")
        return cls(title, int(copies))

    @staticmethod
    def is_valid_title(title):             # static method
        return bool(title and title.strip())
Why this matters from_string is a common pattern: an alternative constructor. It uses cls so subclasses get the right type back automatically.

3Choosing between them

Ask one question: does this method need the object's data?

QuestionAnswer
Does it use self?Instance method
Does it use the class, not an object?Class method
Does it use neither?Static method
Do not overuse static A static method that never touches the class is really just a function. If it does not belong to the class conceptually, move it out to module level.

4Check yourself

Answer from memory. Every option has the same number of words.

✓ Your win for today

You can now read a method's first parameter and know what it depends on, write an alternative constructor with @classmethod, and use @staticmethod for genuine helpers. Your method signatures now document themselves.

  2. Add a @staticmethod is_valid_title(title) helper.
  3. Call all three kinds and print what each returns. Note which ones you call on the class and which on an object.
