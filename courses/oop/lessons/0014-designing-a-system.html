Lesson 14 · Putting it together

Designing a system

You have every tool now. This lesson is about the order you reach for them: start from the nouns, decide the relationships, protect the state, then add the Python conveniences. Design is a sequence of small decisions, not one big one.

Time ~15 min Win Design a small system end to end Mission link Your real project

1Start from the nouns

Read the requirement and underline the nouns. They are your candidate classes.

The requirement "A library lends books to members. Each book has a title and a number of copies. A member can borrow a book if a copy is available. The library should be able to list what is currently on loan."

Nouns: library, book, member, loan. Verbs: lend, borrow, list. Nouns become classes; verbs become methods.

2Decide the relationships

For each pair, ask is-a or has-a.

PairRelationshipTool
Library / Bookhas-aComposition
Member / Loanhas-aComposition
Ebook / Bookis-aInheritance

The rule of thumb Default to composition. Reach for inheritance only when the is-a test clearly passes and you genuinely want the parent's behaviour.

3The finished design

from abc import ABC, abstractmethod
from dataclasses import dataclass, field

class Item(ABC):
    @abstractmethod
    def describe(self): ...

@dataclass
class Book(Item):
    title: str
    copies: int = 0

    def describe(self):
        return f"{self.title} ({self.copies} copies)"

class Library:
    def __init__(self, name):
        self.name = name
        self._items = []
        self._loans = []

    def add(self, item):
        self._items.append(item)

    def borrow(self, title, member):
        for item in self._items:
            if item.title == title and item.copies > 0:
                item.copies -= 1
                self._loans.append((title, member))
                return True
        return False

    @property
    def on_loan(self):
        return [title for title, _ in self._loans]
Read it back Abstraction (Item), dataclass (Book), composition (Library holds items), encapsulation (_items, _loans), properties (on_loan), and polymorphism (describe). Every lesson is in this one file.
