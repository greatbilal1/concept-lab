Dataclasses

Most classes you write are mostly boilerplate: store some values, print them, compare them. @dataclass writes that boilerplate for you, so you can spend your lines on the parts that are actually interesting.

Time ~10 min Win Delete boilerplate without losing clarity Mission link Less code, same behaviour

1Boilerplate you have written before

Look at how much of this class is just plumbing. 

class Book:
    def __init__(self, title, copies):
        self.title = title
        self.copies = copies

    def __repr__(self):
        return f"Book(title={self.title!r}, copies={self.copies!r})"

    def __eq__(self, other):
        if not isinstance(other, Book):
            return NotImplemented
        return (self.title, self.copies) == (other.title, other.copies)

Three methods, and only one line of it is a real decision. The rest is mechanical.

The failure Boilerplate is not just noise — it is a place for bugs. Forget one field in __eq__ and equality silently becomes wrong.

2Let the decorator write it

from dataclasses import dataclass

@dataclass
class Book:
    title: str
    copies: int = 0

That is the whole class. You get __init__, __repr__, and __eq__ for free, generated from the field declarations.

Key idea A dataclass is a class whose fields are declared as typed attributes. The decorator reads those declarations and generates the boring methods.

3Mutable defaults and frozen

Two details that catch everyone at least once. 

from dataclasses import dataclass, field

@dataclass
class Shelf:
    name: str
    books: list = field(default_factory=list)   # NOT books: list = []

@dataclass(frozen=True)
class Point:
    x: int
    y: int
Two gotchas Never use a mutable default like [] — every instance would share the same list. Use field(default_factory=list). And frozen=True makes the object immutable, which also makes it hashable.

✓ Your win for today

You can now replace three methods of boilerplate with a decorator and two typed lines, avoid the mutable-default trap, and make immutable value objects with frozen=True. Less code, fewer bugs.
