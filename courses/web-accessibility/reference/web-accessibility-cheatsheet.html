1Semantic Landmarks

Page structure skeleton
<body>
  <header>
    <a href="#main" class="skip-link">Skip to main content</a>
    <nav aria-label="Main Navigation">...</nav>
  </header>
  <main id="main">
    <h1>Page Title</h1>
    <section aria-labelledby="sec1">
      <h2 id="sec1">Section Title</h2>
    </section>
  </main>
  <footer>...</footer>
</body>

2Accessible Form Field

Label, description, and error wiring
<div class="form-group">
  <label for="user-email">Email Address</label>
  <input 
    id="user-email" 
    type="email" 
    aria-describedby="email-hint email-error"
    aria-invalid="true" 
    required
  />
  <span id="email-hint" class="hint">We never share your email.</span>
  <span id="email-error" class="error" role="alert">Please enter a valid email address.</span>
</div>

See Lesson 04 — Accessible Forms & Error States.

3ARIA Live Region

Dynamic update announcements
<!-- Polite: waits until screen reader is idle -->
<div aria-live="polite" aria-atomic="true" id="cart-status">
  3 items in shopping cart
</div>

<!-- Assertive (role="alert"): interrupts immediately -->
<div role="alert" id="error-banner">
  Connection lost. Please retry.
</div>

See Lesson 06 — ARIA Live Regions & Dynamic Content.

4Modal Focus Trap

Keyboard confinement pattern
// Keyboard listener for dialog
modal.addEventListener("keydown", (e) => {
  if (e.key === "Escape") closeModal();
  if (e.key === "Tab") {
    const focusables = modal.querySelectorAll("button, [href], input, [tabindex='0']");
    const first = focusables[0];
    const last = focusables[focusables.length - 1];
    if (e.shiftKey && document.activeElement === first) {
      last.focus(); e.preventDefault();
    } else if (!e.shiftKey && document.activeElement === last) {
      first.focus(); e.preventDefault();
    }
  }
});

See Lesson 07 — Keyboard Navigation & Focus Traps.
