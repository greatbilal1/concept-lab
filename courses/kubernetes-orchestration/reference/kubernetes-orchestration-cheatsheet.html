1Essential kubectl Commands

Cluster inspection and troubleshooting
# Inspect cluster status
kubectl get nodes -o wide
kubectl get pods -A

# Investigate pod failures
kubectl describe pod <pod-name>
kubectl logs <pod-name> --previous
kubectl exec -it <pod-name> -- /bin/sh

# Imperative port-forwarding for debugging
kubectl port-forward svc/my-service 8080:80

See Lesson 01 — Control Plane, etcd & Worker Architecture.

2Deployment Manifest

Declarative stateless workload
apiVersion: apps/v1
kind: Deployment
metadata:
  name: api-server
spec:
  replicas: 3
  selector:
    matchLabels:
      app: api
  template:
    metadata:
      labels:
        app: api
    spec:
      containers:
      - name: api
        image: api:v1.2.0
        ports:
        - containerPort: 3000
        resources:
          limits:
            memory: "256Mi"
            cpu: "500m"

See Lesson 03 — Deployments, ReplicaSets & Rolling Updates.

3Service & Ingress

Internal and external routing
apiVersion: v1
kind: Service
metadata:
  name: api-service
spec:
  type: ClusterIP
  selector:
    app: api
  ports:
  - port: 80
    targetPort: 3000
---
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: api-ingress
spec:
  rules:
  - host: api.example.com
    http:
      paths:
      - path: /
        pathType: Prefix
        backend:
          service:
            name: api-service
            port:
              number: 80

See Lesson 05 — Services, ClusterIP & Ingress.

4Health Probes

Automated container self-healing
livenessProbe:
  httpGet:
    path: /healthz
    port: 3000
  initialDelaySeconds: 5
  periodSeconds: 10
readinessProbe:
  httpGet:
    path: /ready
    port: 3000
  periodSeconds: 5
