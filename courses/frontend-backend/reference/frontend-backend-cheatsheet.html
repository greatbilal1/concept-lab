1CORS Header Matrix

Cross-Origin configuration
// Simple Requests vs Preflight (OPTIONS)
Access-Control-Allow-Origin: https://app.example.com
Access-Control-Allow-Methods: GET, POST, PUT, DELETE, OPTIONS
Access-Control-Allow-Headers: Content-Type, Authorization
Access-Control-Allow-Credentials: true
Access-Control-Max-Age: 86400  # cache preflight for 24h

2The 4-State UI Machine

Component lifecycle states
type AsyncState<T> =
  | { status: 'idle' }
  | { status: 'loading' }
  | { status: 'success', data: T }
  | { status: 'error', error: Error };

See Lesson 03 — Loading states, empty states, and errors.

3Optimistic UI Update

Update visually first, rollback on error
const previousList = currentList;
setList(list => [...list, newItem]); // optimistic update
try {
  await api.addItem(newItem);
} catch (err) {
  setList(previousList); // rollback on error!
  showErrorBanner("Could not save item.");
}

See Lesson 04 — Optimistic updates and rollback patterns.

4Real-Time Protocols

Polling vs SSE vs WebSockets
Short Polling: setInterval(() => fetch('/updates'), 5000)
Server-Sent Events: const es = new EventSource('/stream') (1-way server->client)
WebSockets: const ws = new WebSocket('wss://api/ws') (full duplex 2-way)

See Lesson 07 — Real-time communication: SSE and WebSockets.
