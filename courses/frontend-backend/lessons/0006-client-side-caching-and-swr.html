1The Stale-While-Revalidate pattern

In traditional data fetching, every screen transition shows a loading spinner while waiting for fresh data. This feels slow even on fast connections.

The Stale-While-Revalidate (SWR) strategy (pioneered by HTTP RFC 5861 and popularized by tools like React Query and SWR) solves this: 1. Serve cached (stale) data immediately in 0ms, 2. Send a background fetch to revalidate with the server, and 3. Silently update the UI if the fresh data has changed.

Key idea Serve cached data immediately in 0ms, then silently revalidate in the background.
