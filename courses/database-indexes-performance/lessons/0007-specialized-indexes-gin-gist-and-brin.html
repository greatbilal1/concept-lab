Lesson 07 · Specialized Indexes & Maintenance

Specialized indexes: GIN, GiST, and BRIN

B-trees cannot index JSON arrays, full-text words, or geographic coordinates. Discover specialized index types: GIN for JSONB and search, GiST for GIS, and BRIN for terabytes of time-series data.

Time ~10 min Win Select between B-tree, GIN, GiST, and BRIN index types based on data structures Mission link Expands indexing capabilities beyond scalar numbers and strings

1When B-trees fall short

A B-tree index maps one scalar value per row. But what if a column holds an array of tags, a JSONB document, a full-text document, or a geographic polygon?

PostgreSQL provides specialized index access methods: GIN (Generalized Inverted Index) decomposes arrays and JSONB documents into individual components, indexing each element separately. BRIN (Block Range Index) indexes massive time-series tables (terabytes in size) in just a few kilobytes of index space.

Key idea Use GIN for JSONB and multi-value arrays; use BRIN for massive time-ordered datasets.
