Lesson 03 · Query Plans & Execution

The query planner: cost and statistics

How does the database choose between an index and a table scan? Discover the cost-based query optimizer, table statistics, and the EXPLAIN command.

Time ~10 min Win Inspect query execution plans using EXPLAIN and understand planner cost calculations Mission link Reveals how the database optimizer makes physical execution decisions

1The cost-based optimizer

When you send an SQL query, the database does not execute it immediately. The Query Optimizer (Planner) analyzes multiple candidate execution strategies, calculates an estimated Cost for each, and picks the cheapest plan.

Cost is measured in arbitrary units modeling disk I/O page fetches and CPU computations. The planner bases its estimates on internal Table Statistics (tracked by ANALYZE), such as row counts, null fractions, and data distribution histograms.

Key idea The query planner uses statistical histograms to estimate cost and select the optimal plan.
