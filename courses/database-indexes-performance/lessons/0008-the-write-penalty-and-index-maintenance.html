Lesson 08 · Specialized Indexes & Maintenance

The write penalty and index maintenance

Indexes are not free. Every index imposes a tax on every INSERT, UPDATE, and DELETE. Learn how to audit unused indexes, detect index bloat, and perform online reindexing.

Time ~10 min Win Audit database systems to identify and drop unused indexes and manage write overhead Mission link Protects database write throughput and memory cache efficiency

1The index write tax

If a table has 10 indexes, every single INSERT must write to the table heap AND update all 10 physical B-tree indexes across disk. Every single UPDATE that touches indexed columns must modify those indexes, triggering B-tree page splits and write amplification.

Furthermore, indexes consume RAM in the buffer pool. If you have 20 gigabytes of unused indexes, they push active table pages out of memory, slowing down your entire database. Unused indexes are pure overhead with zero benefit.

Key idea Every index adds write latency and memory overhead; audit and drop unused indexes regularly.
