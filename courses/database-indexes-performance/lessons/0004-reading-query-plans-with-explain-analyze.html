Lesson 04 · Query Plans & Execution

Reading query plans with EXPLAIN ANALYZE

Stop guessing why queries are slow. Learn how to run EXPLAIN (ANALYZE, BUFFERS) to see actual execution times, memory usage, and the exact node where time is lost.

Time ~10 min Win Diagnose query performance bottlenecks using EXPLAIN (ANALYZE, BUFFERS) Mission link The primary diagnostic tool for optimizing slow database queries

1From estimates to ground truth

EXPLAIN shows what the planner thinks will happen. But to see what actually happened, you must run EXPLAIN (ANALYZE, BUFFERS). This command executes the query in real time and reports actual elapsed time (in milliseconds) and actual row counts.

WARNING: EXPLAIN ANALYZE actually executes the statement! If you run EXPLAIN ANALYZE DELETE FROM users;, you will actually delete all your users! Always wrap mutations in a transaction and rollback when testing.

Key idea EXPLAIN ANALYZE actually runs the query and reports true execution times and buffer hits.
