1Mechanical Syntax Modernization Prompt

Bulk typing & syntax upgrade
"Modernize syntax across src/models/:
1. Replace Optional[T] with T | None.
2. Replace Union[A, B] with A | B.
3. Run `mypy src/` and `pytest tests/` to verify zero regressions."

See Lesson 02 — Mechanical Refactorings: Renames, Modernizations, Type Additions.

2Backward-Compatible Re-Export Seam

Decomposing monoliths safely
# In legacy_service.py:
# Extract logic to new file, but re-export to keep callers working:
from src.services.billing import calculate_invoice
# Callers importing legacy_service.calculate_invoice continue to work!

See Lesson 04 — Step-by-Step Monolith Decomposition.

3Multi-File Verification Chain

Three-tier consistency audit
# Run after any multi-file refactoring:
mypy src/ tests/ && ruff check src/ tests/ && pytest
# Only commit when all three exit with code 0!

See Lesson 06 — Verifying Invariants Across Large Multi-File Diffs.

4Atomic Refactoring Git Cycle

Small reversible steps
# 1. Make 1 small refactoring
# 2. Verify: pytest (PASS)
# 3. Commit: git commit -m 'refactor: Extract TaxService'
# If tests fail: git reset --hard HEAD (Instant rollback!)

See Lesson 07 — Rollback Strategies and Atomic Commit Discipline.
