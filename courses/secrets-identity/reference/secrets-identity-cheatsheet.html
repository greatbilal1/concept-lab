1GitHub Actions Keyless AWS OIDC

Zero static credentials in CI/CD
permissions:
  id-token: write # Request OIDC JWT from GitHub
  contents: read
steps:
  - uses: aws-actions/configure-aws-credentials@v4
    with:
      role-to-assume: arn:aws:iam::123456789012:role/DeployRole
      aws-region: us-east-1

See Lesson 06 — Workload Identity Federation (IAM Roles for Service Accounts).

2Gitleaks Pre-Commit Hook Configuration

Blocking secret commits locally
# .pre-commit-config.yaml
repos:
  - repo: https://github.com/gitleaks/gitleaks
    rev: v8.18.2
    hooks:
      - id: gitleaks

See Lesson 07 — Automated Secret Scanning in Git (TruffleHog, Gitleaks).

3AWS Secrets Manager Runtime Fetch

In-memory credential retrieval
import boto3, json
client = boto3.client('secretsmanager', region_name='us-east-1')
secret_dict = json.loads(client.get_secret_value(SecretId='prod/db')['SecretString'])
# Use secret_dict in memory without writing to disk!

See Lesson 02 — Environment Variables vs Dedicated Secret Managers.

4Least-Privilege Scoped IAM Statement

Zero-wildcard S3 read permission
{
  "Effect": "Allow",
  "Action": ["s3:GetObject"],
  "Resource": "arn:aws:s3:::company-invoices-prod/inbound/*",
  "Condition": { "Bool": { "aws:SecureTransport": "true" } }
}

See Lesson 04 — The Principle of Least Privilege: Scoping IAM Roles.
