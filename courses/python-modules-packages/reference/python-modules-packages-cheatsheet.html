Python Modules & Packages — Cheat Sheet

The whole course on one page. Every snippet links back to the lesson that teaches it.

Imports Packages Environments Together

1Imports

A module is a file
# helpers.py  ->  importable as "helpers"
def clean(rows):
    return [r for r in rows if r]

# main.py
import helpers
helpers.clean(rows)

See Lesson 01 — A module is just a file.

Three ways to import
import helpers                 # module.attr
from helpers import clean      # clean()
from helpers import clean as c # c()

See Lesson 02 — Three ways to import.

Where Python looks
import sys
print(sys.path)      # search order, script dir first
print(sys.modules)   # cache of already-imported modules

See Lesson 03 — Where Python looks for modules.

2Packages

A package is a folder
myapp/
  __init__.py      # marks the folder as a package
  models.py
  utils.py

import myapp.models

See Lesson 04 — Packages and __init__.py.

Absolute vs relative
from myapp import utils     # absolute — preferred
from . import utils         # relative — same package
from ..core import base     # relative — parent package

See Lesson 05 — Relative vs absolute imports.

The __main__ guard
def main():
    ...

if __name__ == "__main__":   # only when run, not imported
    main()

See Lesson 06 — The __main__ guard.

3Environments

Create, activate, verify
python -m venv .venv
source .venv/bin/activate     # macOS / Linux
# .venv\Scripts\activate      # Windows
which python                  # must point inside .venv

See Lesson 07 — Virtual environments.

Pin and rebuild
pip install requests pandas
pip freeze > requirements.txt
pip install -r requirements.txt

# specifiers
requests==2.32.3      # exact
pandas>=2.0,<3.0     # range
pytest                # any

See Lesson 08 — Installing and pinning dependencies.

4Together

The three traps
# 1. circular import  -> extract a third module
# 2. shadowing        -> never name a file json.py
# 3. star import      -> name the module instead
from helpers import *   # don't

See Lesson 09 — Import traps.

Ship a package
# pyproject.toml
[project]
name = "myapp"
version = "0.1.0"
dependencies = ["requests>=2.28"]

[project.scripts]
myapp = "myapp.cli:main"

# build
python -m build
pip install dist/myapp-0.1.0-py3-none-any.whl

See Lesson 10 — Shipping a package.
