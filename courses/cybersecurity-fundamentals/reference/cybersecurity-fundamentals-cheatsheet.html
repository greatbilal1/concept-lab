1Argon2 Secure Password Hashing

Modern memory-hard password storage
from argon2 import PasswordHasher
ph = PasswordHasher()
hash_str = ph.hash("correct_horse_battery_staple")
# Verify password:
ph.verify(hash_str, "correct_horse_battery_staple") # True

2STRIDE Threat Modeling Mapping

Six core threat categories
# S: Spoofing        -> Mitigate with MFA & Signed JWTs
# T: Tampering       -> Mitigate with TLS 1.3 & SHA-256 Checksums
# R: Repudiation     -> Mitigate with Immutable Append-Only Audit Logs
# I: Info Disclosure -> Mitigate with AES-256 Encryption at Rest
# D: Denial of Svc   -> Mitigate with Redis Token Bucket Rate Limits
# E: Elev. Privilege -> Mitigate with Strict RBAC & Least Privilege

See Lesson 03 — Threat Modeling with STRIDE and Attack Trees.

3AES-256-GCM Symmetric Encryption

Authenticated data encryption at rest
from cryptography.hazmat.primitives.ciphers.aead import AESGCM
key = AESGCM.generate_key(bit_length=256)
aesgcm = AESGCM(key)
nonce = os.urandom(12)
encrypted_data = aesgcm.encrypt(nonce, b"sensitive_financial_record", None)
