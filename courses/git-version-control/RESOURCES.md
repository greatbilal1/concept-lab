# Resources — Git & Version Control

## Knowledge (primary sources)

- *Pro Git* (2nd ed.) — Scott Chacon & Ben Straub — the canonical free book,
  written by Git maintainers and contributors. Chapters 1–3 cover the model,
  the three trees, and branching; Chapter 7 covers reset and the reflog.
  https://git-scm.com/book/en/v2
- *Git Reference Manual* — the official `git help` pages — authoritative for
  exact command behaviour and flags. https://git-scm.com/docs
- *Git Glossary* — the official definitions of terms like "index", "HEAD",
  "fast-forward", and "detached HEAD". https://git-scm.com/docs/gitglossary

## Wisdom (practitioner insight)

- *Think Like (a) Git* — Sam Livingston-Gray — a practitioner's guide to the
  graph model, useful for the "a branch is a pointer" framing.
  https://think-like-a-git.net/
- *Oh Shit, Git!?!* — Katie Sylor-Miller — the recovery recipes that inform
  Lesson 7's "undo depends on where you are" structure.
  https://ohshitgit.com/
- *Learn Git Branching* — Peter Cottle — an interactive visualiser that
  demonstrates pointer movement and merges; the mental model behind the
  diagram widgets. https://learngitbranching.js.org/

## Gaps

- No single source teaches the three-trees model as a *decision frame* for
  choosing undo commands; that synthesis is this course's own contribution.
- Hosting-platform workflows (pull requests, review, protected branches) are
  documented per-platform and change often, so they are described generically
  here rather than cited.
