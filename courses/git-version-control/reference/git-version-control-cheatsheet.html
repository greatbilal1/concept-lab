Git & Version Control — Cheat Sheet

The whole course on one page. Every snippet links back to the lesson that teaches it.

Basics Three trees History Branches Merging Undo Workflow

1Repository basics

Start a repository and record a snapshot
git init
git status
git add README.md
git commit -m "Add project overview"

# A commit records a project snapshot and metadata.
# It is not just a saved diff.

See Lesson 01 — What version control is for and Lesson 02 — Your first commit.

2The three trees

See Lesson 03 — The three trees.

Working tree, index, repository
git status
git diff              # working tree compared with index
git diff --staged     # index compared with HEAD
git add file.py       # working tree -> index
git commit            # index -> repository

3Read history

See Lesson 04 — Reading history.

Inspect commits and changes
git log --oneline --decorate
git show HEAD
git show <commit>
git diff HEAD~1..HEAD

# HEAD names the commit currently checked out.
# Use status and log to re-orient before acting.

4Branch and switch

See Lesson 05 — Branching.

A branch is a movable name for a commit
git branch
git switch -c add-search
# make and commit focused changes
git switch main
git branch -d add-search

# -d refuses to delete an unmerged branch.

5Merge and resolve conflicts

See Lesson 06 — Merging and conflicts.

Bring a branch into the current branch
git switch main
git merge add-search

# If Git reports conflicts:
# 1. Open each conflicted file and choose the intended result.
# 2. Remove conflict markers and save.
# 3. Run tests, then stage the resolved files.
git add path/to/resolved-file
git commit

6Undo with the right tool

See Lesson 07 — Undoing things.

Choose by where the change lives
git restore file.py             # discard unstaged working-tree edits
git restore --staged file.py    # unstage; keep working-tree edits
git revert <commit>             # new commit that reverses an old commit
git reflog                      # find recent local HEAD positions

# git reset moves a branch/HEAD; inspect its mode and target first.
# Avoid destructive reset commands until you understand the state.

7Feature-branch workflow

See Lesson 08 — A workflow that works.

Small commits, shared branch, review
git switch -c fix-empty-search
# edit, inspect, and test
git status
git diff
git add src/search.py
git commit -m "Handle empty search query"
git push -u origin fix-empty-search

# Open a pull request for review, then merge by team policy.
