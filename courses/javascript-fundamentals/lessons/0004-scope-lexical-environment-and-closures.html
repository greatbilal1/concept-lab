Lesson 04 · Functions & Scope

Scope, lexical environment, and closures

Closures are the secret weapon of JavaScript. Learn how functions remember the scope in which they were born, enabling private state and factory functions.

Time ~10 min Win Explain and implement lexical closures for data encapsulation and state management Mission link The single most tested conceptual topic in professional JavaScript

1Lexical scope and closures

JavaScript uses lexical scoping: a function's scope is determined by where it is written in the physical source code, not where it is called. Inner functions have access to variables declared in their outer enclosing scopes.

A closure is formed when an inner function is returned or passed out of its parent scope, yet retains access to the parent's variables. Even though the parent function finished executing, its variables stay alive in memory because the inner function still references them.

Key idea A closure is a function that remembers its outer lexical environment even after the parent returns.
