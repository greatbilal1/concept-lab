Lesson 06 · Objects & Collections

Arrays and modern array methods

Stop writing manual for-loops. Master declarative, immutable array pipelines using map, filter, reduce, find, and some.

Time ~10 min Win Transform collections declaratively using pure array methods and reduce Mission link The core functional style of modern idiomatic JavaScript

1Imperative loops versus declarative pipelines

In older code, transforming a list meant declaring an empty array, writing a for (let i = 0; i < len; i++) loop, and pushing mutated values. This is imperative: it details every step of how to do it.

Modern JavaScript uses declarative higher-order array methods: map (transform each item), filter (keep matching items), and reduce (aggregate into a single value). They produce new arrays without mutating the original, preventing side-effect bugs.

Key idea map transforms; filter selects; reduce accumulates; all three leave the original array untouched.
