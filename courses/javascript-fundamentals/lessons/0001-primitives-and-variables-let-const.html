Lesson 01 · Primitives & Variables

Primitives and variables: let vs const

Stop using var. Master the modern let and const keywords, the Temporal Dead Zone, and the fundamental boundary between primitives and objects.

Time ~10 min Win Choose appropriately between let, const, and JavaScript primitive types Mission link Forms the foundational variable model of modern ECMAScript

1The seven primitive types

JavaScript values fall into two categories: Primitives and Objects. There are seven primitive types: number, string, boolean, null, undefined, symbol, and bigint.

Primitives are strictly immutable: you cannot add properties to them or mutate their internal contents. Variables hold primitive values directly by value; objects are held by memory reference.

Key idea Primitives are immutable values copied by value; objects are mutable structures accessed by reference.
