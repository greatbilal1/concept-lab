Set operations: UNION, INTERSECT, EXCEPT

Joins combine columns horizontally; set operators combine rows vertically. Master UNION, UNION ALL, INTERSECT, and EXCEPT.

Time ~10 min Win Combine and compare query results vertically using UNION ALL, INTERSECT, and EXCEPT Mission link The fundamental set-theoretic tools for combining multi-table row sets

1Horizontal versus vertical combination

A JOIN combines tables horizontally: it adds columns from Table B onto rows from Table A. In contrast, Set Operations combine queries vertically: they stack rows from Query B on top of rows from Query A.

SQL provides four standard set operations: UNION (combines rows, removing duplicates), UNION ALL (combines all rows rapidly without deduplication), INTERSECT (returns rows present in both), and EXCEPT / MINUS (returns rows in A but not B).

Key idea Joins append columns horizontally; set operations stack rows vertically.
