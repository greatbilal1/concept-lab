Lesson 04 · Subqueries & CTEs

Subqueries in SELECT, FROM, and WHERE

A query inside a query. Learn how scalar subqueries, table-derived subqueries, and correlated subqueries allow you to solve multi-stage questions in a single query.

Time ~10 min Win Compose scalar, derived-table, and correlated subqueries without performance traps Mission link Expands query thinking beyond flat single-table lookups

1Queries inside queries

A Subquery is an SQL query nested inside another query. Depending on where it is placed, a subquery serves different roles:

In WHERE: Filters by computed values (e.g. WHERE price > (SELECT AVG(price) FROM products)). In FROM: Acts as an on-the-fly temporary table (a derived table). In SELECT: Calculates a single scalar value per output row.

Key idea Subqueries nest queries inside SELECT, FROM, or WHERE clauses to solve multi-step problems.
