Lesson 06 · Subqueries & CTEs

Self-joins and hierarchical trees

How do you query a table that points to itself? Master self-joins to find managers and employees, and recursive CTEs to traverse nested categories of arbitrary depth.

Time ~10 min Win Query hierarchical organizational charts and category trees using self-joins and recursive CTEs Mission link Enables modeling and querying of parent-child trees and category hierarchies

1A table that references itself

In an organization, managers are also employees. In an e-commerce catalog, parent categories contain child categories. Instead of creating two identical tables, relational design uses a self-referential foreign key: employees.manager_id references employees.id.

To query employee and manager names together, you perform a Self-Join: joining the employees table to itself using two distinct aliases (employees e LEFT JOIN employees m ON e.manager_id = m.id).

Key idea A self-join pairs a table with itself using distinct aliases to model parent-child hierarchies.
