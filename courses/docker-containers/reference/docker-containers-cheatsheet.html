1Production Multi-Stage Python Dockerfile

Lean, non-root production pattern
FROM python:3.12-slim AS builder
WORKDIR /build
COPY requirements.txt .
RUN pip wheel --no-cache-dir --wheel-dir=/build/wheels -r requirements.txt

FROM python:3.12-slim
WORKDIR /app
RUN useradd -u 1000 appuser
COPY --from=builder /build/wheels /wheels
RUN pip install --no-cache /wheels/* && rm -rf /wheels
COPY --chown=appuser:appuser . .
USER appuser
CMD ["python", "main.py"]

See Lesson 03 — Writing Production Dockerfiles: Multi-Stage Builds & Non-Root Users.

2Docker Compose with Service Healthcheck

Declarative stack orchestration
services:
  api:
    build: .
    ports: ["8000:8000"]
    depends_on:
      db: { condition: service_healthy }
  db:
    image: postgres:16-alpine
    volumes: [pgdata:/var/lib/postgresql/data]
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U postgres"]
volumes:
  pgdata:

3Automated Trivy Container Security Scan

Blocking critical CVEs in CI
# Scan image and exit 1 if Critical vulnerabilities found:
trivy image --exit-code 1 --severity CRITICAL company/api:latest

4Isolated Docker Run Command

Hardened container execution
docker run --rm -i \
    --network none \
    --read-only \
    --tmpfs /tmp:rw,size=64m \
    --user 1000:1000 \
    --cap-drop ALL \
    python:3.12-slim python app.py
