Lesson 06 · Headers & Payloads

Headers, content types, and metadata

Headers are the envelope of the web. Learn how Content-Type, Accept, Authorization, and CORS headers negotiate formats and secure communication.

Time ~10 min Win Configure content negotiation and authentication headers for HTTP communications Mission link Ensures seamless interoperability between heterogeneous clients and servers

1Content negotiation

The internet connects computers running different operating systems, languages, and formats. How do a Python backend and an iOS client agree on data serialization?

Through Content Negotiation headers. The client sends Accept: application/json to specify what format it wants. The server replies with Content-Type: application/json; charset=utf-8 to declare what format it delivered.

Key idea Accept declares what the client wants; Content-Type declares what the sender provided.
