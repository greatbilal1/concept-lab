Lesson 07 · State, Cookies & Caching

Caching and conditional requests

The fastest request is the one you never make. Master Cache-Control, max-age, ETags, and 304 Not Modified conditional requests.

Time ~10 min Win Implement efficient HTTP caching strategies using Cache-Control and ETag validation Mission link Dramatically reduces server load and optimizes client performance

1The hierarchy of web caching

Every network request consumes bandwidth and introduces latency. HTTP provides built-in caching primitives that allow browsers and CDNs to serve copies of resources without contacting the origin server.

Caching is controlled by Cache-Control. Directives like max-age=3600 declare how long a resource is fresh. When fresh, the browser serves it directly from local memory or disk without sending any network packets.

Key idea Cache-Control directs browsers and CDNs whether, where, and how long to store copies of responses.

2Conditional validation with ETags

When a cached item expires, the browser doesn't need to download it again if it hasn't changed. It sends a conditional check.
