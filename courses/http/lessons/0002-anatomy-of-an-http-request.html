Lesson 02 · The Request-Response Cycle

Anatomy of an HTTP request

Every web request is a three-part letter: request line, headers, and an optional body. Learn how to construct and read raw HTTP requests.

Time ~10 min Win Dissect and construct raw HTTP requests containing methods, headers, and payloads Mission link Enables manual API debugging and low-level HTTP client authoring

1The three parts of an HTTP request

An HTTP request is human-readable plaintext divided into three parts: the Request Line, the Headers, and the Body.

The request line contains three space-separated tokens: the method (GET, POST), the URI path (/api/users), and the protocol version (HTTP/1.1). Headers follow as Key: Value lines, concluded by an empty blank line before the body.

Key idea A request consists of a request line, header key-value pairs, an empty line, and the body payload.
