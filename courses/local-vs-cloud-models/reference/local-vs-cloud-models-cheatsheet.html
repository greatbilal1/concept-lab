1Local Model Invocation with Ollama

OpenAI-compatible local endpoint
from openai import OpenAI
# Point client to local Ollama server:
client = OpenAI(base_url="http://localhost:11434/v1", api_key="ollama")
response = client.chat.completions.create(
    model="llama3:8b",
    messages=[{"role": "user", "content": "Hello local AI!"}]
)

2Inference VRAM Sizing Formula

Quick memory estimation
# Formula: VRAM_GB ≈ (Parameters_in_Billions * Bytes_per_Weight) * 1.2
# 4-bit (0.5 bytes): 8B * 0.5 * 1.2 ≈ 4.8 GB VRAM
# 4-bit (0.5 bytes): 70B * 0.5 * 1.2 ≈ 42.0 GB VRAM
# 16-bit (2.0 bytes): 70B * 2.0 * 1.2 ≈ 168.0 GB VRAM

See Lesson 02 — Hardware Requirements: VRAM, Unified Memory, and Quantization.

3vLLM High-Throughput Serving Command

Production server deployment
# Serve Llama 3 70B sharded across 2 GPUs with vLLM:
python3 -m vllm.entrypoints.openai.api_server \
    --model meta-llama/Meta-Llama-3-70B-Instruct \
    --tensor-parallel-size 2 \
    --gpu-memory-utilization 0.95 \
    --max-model-len 8192

4Hybrid Privacy Masking Architecture

Sanitizing prompts locally before cloud dispatch
# 1. Local Model scrubs PII:
clean_prompt = local_model.scrub_pii(user_raw_input)
# 2. Cloud Model processes clean prompt:
cloud_response = cloud_client.generate(clean_prompt)
# 3. Local Model restores entities:
final_text = local_model.restore_pii(cloud_response)
