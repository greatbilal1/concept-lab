Lesson 01 · The Relational Model & Tables

The relational model and tables

Why have relational databases outlived every competing technology for 50 years? Discover Codd's relational model: tables, rows, columns, and declarative sets.

Time ~10 min Win Explain the mathematical relational model of tables, tuples, and attributes Mission link The architectural foundation of all relational data storage

1Codd's mathematical breakthrough

In 1970, IBM researcher Edgar F. Codd published a revolutionary paper proposing the relational model. Before Codd, databases were hierarchical trees or network graphs where programmers had to navigate pointers by hand.

Codd proposed that all data should be represented in Relations (Tables), consisting of unordered Tuples (Rows) and typed Attributes (Columns). Because the model is based on mathematical set theory, you query data declaratively without caring how data is physically arranged on disk.

Key idea The relational model separates logical data representation from physical disk storage using set theory.
