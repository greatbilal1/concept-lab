Lesson 03 · Declarative Querying & Filtering

Querying data with SELECT and WHERE

How do you ask the database for exactly what you need? Master the SELECT projection, filtering with WHERE, sorting with ORDER BY, and pagination with LIMIT/OFFSET.

Time ~10 min Win Write expressive declarative SQL queries with precise filtering and sorting Mission link The primary daily tool for extracting business data from relational databases

1The clauses of a query

A basic SQL query contains four clauses: SELECT (which columns to return), FROM (which table to read), WHERE (which rows to include), and ORDER BY (how to sort them).

A critical insight: The database does NOT execute clauses in the order you write them! Although you write SELECT first, the database evaluates FROM first, then WHERE, then aggregates, then SELECT, and finally ORDER BY and LIMIT.

Key idea SQL is written SELECT -> FROM -> WHERE, but executed FROM -> WHERE -> SELECT -> ORDER BY.

2SQL execution order versus written order

Memorise the actual order in which the database engine processes query clauses.
