Lesson 08 · Aggregations & Analytics

Filtering groups with HAVING

Why can't you use 'WHERE COUNT(*) > 5'? Learn the crucial difference between WHERE (filtering rows before grouping) and HAVING (filtering groups after aggregation).

Time ~10 min Win Filter aggregated datasets using HAVING clauses and optimize analytical queries Mission link Completes the logical SQL execution pipeline for advanced data analysis

1WHERE filters rows; HAVING filters groups

A common beginner mistake is writing WHERE COUNT(*) > 5. The database immediately throws an error: 'aggregate functions are not allowed in WHERE'.

Why? Because the WHERE clause runs before rows are grouped! To filter aggregated buckets, SQL provides the HAVING clause. WHERE filters individual rows before grouping; HAVING filters summary groups after grouping.

Key idea WHERE filters raw rows before grouping; HAVING filters aggregated groups after grouping.
