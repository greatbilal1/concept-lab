1Token-Bounded Sliding Window

FIFO buffer with system pinning
def get_active_window(system_prompt, history, max_tokens=6000):
    budget = max_tokens - count_tokens(system_prompt)
    window, total = [], 0
    for msg in reversed(history):
        t = count_tokens(msg['content'])
        if total + t <= budget:
            window.append(msg); total += t
        else: break
    return [{'role': 'system', 'content': system_prompt}] + list(reversed(window))

3Long-Term Memory Schema (PostgreSQL)

GDPR-compliant memory table
CREATE TABLE user_memories (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    fact TEXT NOT NULL,
    embedding vector(1536),
    expires_at TIMESTAMPTZ,
    created_at TIMESTAMPTZ DEFAULT NOW()
