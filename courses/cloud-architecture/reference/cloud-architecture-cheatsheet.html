1AWS S3 Pre-Signed Upload URL (Python)

Direct-to-S3 client upload delegation
import boto3
s3 = boto3.client('s3')
url = s3.generate_presigned_url(
    ClientMethod='put_object',
    Params={'Bucket': 'company-assets', 'Key': 'uploads/doc.pdf'},
    ExpiresIn=3600
) # Client uploads directly to URL without hitting app server!

See Lesson 04 — Cloud Storage Hierarchy: Object, Block, and File Storage.

2Terraform Multi-AZ VPC Subnet (HCL)

Declarative network subnet definition
resource "aws_subnet" "private_app_a" {
  vpc_id            = aws_vpc.main.id
  cidr_block        = "10.0.2.0/24"
  availability_zone = "us-east-1a"
  tags = { Name = "private-app-us-east-1a" }
}

See Lesson 02 — Virtual Private Clouds (VPC): Subnets, Gateways, and Route Tables.

3AWS Service Control Policy (SCP)

Restricting allowed geographic cloud regions
{
  "Effect": "Deny",
  "NotAction": ["iam:*", "organizations:*", "route53:*", "cloudfront:*"],
  "Resource": "*",
  "Condition": { "StringNotEquals": { "aws:RequestedRegion": ["us-east-1"] } }
}

See Lesson 05 — IAM and Identity Federation at Enterprise Scale.

4RDS PostgreSQL Multi-AZ Terraform

Synchronous cross-AZ database replication
resource "aws_db_instance" "database" {
  allocated_storage = 50
  engine            = "postgres"
  instance_class    = "db.m6g.large"
  multi_az          = true # Automated synchronous cross-AZ failover!
  skip_final_snapshot = false
}

See Lesson 08 — Architecting a Highly Available, Fault-Tolerant Cloud Infrastructure.
